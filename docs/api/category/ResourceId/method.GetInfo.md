# ResourceId:GetInfo

Извлекает информацию о ресурсном файле объекта.

## Описание

```lua
ResourceId:GetInfo(): table
```

Функция возвращает таблицу с полями, набор которых определяется типом объекта. Метод реализован для всех типов `ResourceId` и для `WidgetSafe` (базовый тип для виджетов).

## Список параметров

Параметры отсутствуют.

## Возвращаемые значения

Возвращает `table` - таблицу с полями, набор которых определяется типом объекта.

## Примеры

### Получение информации о ресурсе

```lua
local currencyCategoryInfo = currencyInfo.category:GetInfo()
```
