# ResourceId:GetPath

Возвращает путь к ресурсному файлу объекта.

## Описание
```lua
ResourceId:GetPath()
```

Функция возвращает строковый путь к файлу ресурса, виджета или иного поддерживаемого типа. Метод реализован для всех типов `ResourceId`, включая пользовательские ресурсы и виджеты. Доступен исключительно в версии клиента для разработчиков.

::: warning Замечание
Метод доступен только в версии для разработчиков.
:::

## Список параметров

Параметры отсутствуют.

## Возвращаемые значения

Возвращает `string` | `nil` - путь к ресурсному файлу, если он определен, иначе `nil`.

## Примеры

### Получение пути к ресурсу виджета

```lua
local widgetResource = widget1:GetPath()
```
