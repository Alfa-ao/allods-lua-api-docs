# Sound2DLua:GetVolume

Возвращает текущую громкость звука.

## Описание

```lua
Sound2DLua:GetVolume(): number
```

Возвращает текущую громкость звука в диапазоне от 0.0 до 1.0.

::: warning Замечание
Корректность данных гарантируется только для тех звуков, для которых был вызван `Play`. Возвращается состояние данного конкретного звука. Итоговое состояние может отличаться в зависимости от настройки вышележащих групп звуков.
:::

::: info Примечание
Для пользовательских дополнений все звуки относятся к группе Интерфейс, опция `interfaceVolume` / `audio_option_interface_volume`.
:::

## Возвращаемые значения

Возвращает `number` - текущую громкость звука в диапазоне от 0.0 до 1.0.

## Примеры

### Получение громкости звука

```lua
LogInfo("Current sound volume is", sound:GetVolume())
```
