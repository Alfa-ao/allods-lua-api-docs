# Sound2DLua:IsMuted

Возвращает `true`, если данный звук заглушен в момент вызова.

## Описание

```lua
boolean Sound2DLua:IsMuted(): boolean
```

Функция возвращает состояние заглушения данного конкретного звука.

::: warning Замечание
Итоговое состояние может отличаться в зависимости от настройки вышележащих групп звуков.
:::

::: tip Примечание
Для пользовательских дополнений все звуки относятся к группе «Интерфейс» (опция `interfaceVolume` / `audio_option_interface_volume`).
:::

## Список параметров

Параметры отсутствуют.

## Возвращаемые значения

Возвращает `boolean` - `true`, если звук заглушен.

## Примеры

### Проверка состояния звука

```lua
if sound:IsMuted() then
    LogInfo("Sound is muted")
end
```
