# Sound2DLua:IsPaused

Определяет, находится ли данный звук на паузе.

## Описание

```lua
Sound2DLua:IsPaused(): boolean
```

Функция возвращает `true`, если данный звук находится на паузе в момент вызова.

## Список параметров

Параметры отсутствуют.

## Возвращаемые значения

Возвращает `boolean` - `true`, если звук на паузе.

## Примеры

### Проверка паузы звука

```lua
if sound:IsPaused() then
    LogInfo("Sound is paused")
end
```
