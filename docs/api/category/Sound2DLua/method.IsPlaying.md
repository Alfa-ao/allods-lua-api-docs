# Sound2DLua:IsPlaying

Возвращает `true`, если данный звук воспроизводится в момент вызова.

## Описание

```lua
Sound2DLua:IsPlaying(): boolean
```

Функция возвращает `true`, если звук воспроизводится в момент вызова.

::: warning Замечание
Воспроизведение не обязательно обозначает слышимость, у звука может быть нулевая громкость или в записи может быть тишина.
:::

## Список параметров

Параметры отсутствуют.

## Возвращаемые значения

Возвращает `boolean` - `true`, если звук воспроизводится.

## Примеры

### Проверка воспроизведения звука

```lua
if sound:IsPlaying() then
    LogInfo("Sound is playing")
end
```
