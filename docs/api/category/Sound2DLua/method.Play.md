# Sound2DLua:Play

Запускает проигрывание звука.

## Описание

```lua
Sound2DLua:Play()
```

Если звук уже играется, то функция ничего не делает. Если звук еще не загружен, то, после подгрузки, он, плавно увеличивая громкость, проиграется с учетом времени запуска.

::: tip Совет
Ресурс для звука начинает грузиться, когда вызывается `common.CreateSound( soundId )`, поэтому рекомендуется звук создавать заранее.
:::

## Возвращаемые значения

Возвращаемое значение отсутствует.

## Примеры

### Базовый вызов

```lua
sound:Play()
```
