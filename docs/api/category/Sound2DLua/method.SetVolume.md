# Sound2DLua:SetVolume

Устанавливает громкость звука.

## Описание

```lua
Sound2DLua:SetVolume( volume: number )
```

Устанавливает громкость звука в диапазоне от 0.0f (нет звука) до 1.0f (максимальная громкость).

::: warning Замечание
Корректность установки гарантируется только для тех звуков, для которых был вызван `Play`.
:::

## Список параметров

- **`volume`** (`number`) - Громкость звука в диапазоне от 0.0f до 1.0f.

## Возвращаемые значения

Возвращаемое значение отсутствует.

## Примеры

### Установка громкости

```lua
sound:SetVolume( 0.5 )
```
