# Sound2DLua:Stop

Останавливает воспроизведение звука.

## Описание

```lua
Sound2DLua:Stop( immediate: boolean )
```

Если звук не воспроизводится, функция ничего не делает.

## Список параметров

- **`immediate`** (`boolean`) - Определяет, нужно ли немедленно остановить звук. Если `false`, то остановка происходит с учетом настроек самого звука (например, времени плавного уменьшения громкости).

## Возвращаемые значения

Возвращаемое значение отсутствует.

## Примеры

### Остановка звука

```lua
sound:Stop( false )
```
