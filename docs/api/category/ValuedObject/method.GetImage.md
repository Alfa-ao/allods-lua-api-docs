# ValuedObject:GetImage

Возвращает изображение объекта ValuedObject.

## Описание

```lua
ValuedObject:GetImage(): TextureId
```

Функция возвращает идентификатор текстуры, представляющий обёртываемый объект в UI.

## Список параметров

Параметры отсутствуют.

## Возвращаемые значения

Возвращает `TextureId` - идентификатор текстуры, представляющий обёртываемый объект в UI.

## Примеры

### Получение изображения

```lua
local texture = itemValObj:GetImage()
```
