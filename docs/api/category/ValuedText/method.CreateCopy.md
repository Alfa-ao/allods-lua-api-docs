# ValuedTextSafe:CreateCopy

Создает копию для данного ValuedText.

## Описание

```lua
ValuedTextSafe:CreateCopy(): ValuedText
```

Функция возвращает копию для данного ValuedText.

## Список параметров

Параметры отсутствуют.

## Возвращаемые значения

Возвращает `ValuedText` - копию для данного ValuedText.

## Примеры

### Создание копии

```lua
local copy = valuedText:CreateCopy()
```
