# ValuedTextSafe:IsEmpty

Проверяет, является ли текст пустым.

## Описание

```lua
ValuedTextSafe:IsEmpty(): boolean
```

Функция возвращает логическое значение, указывающее на наличие отображаемых символов в объекте `ValuedText`. Текст, содержащий только теги форматирования, считается пустым.

::: warning Замечание
На сложных текстах данная функция работает существенно быстрее, чем проверка длины через `#text == 0`.
:::

## Список параметров

Параметры отсутствуют.

## Возвращаемые значения

Возвращает `boolean` - `true`, если текст пустой, и `false` в противном случае.

## Примеры

### Проверка текста на пустоту

```lua
if IsVt( object.desc ) and not object.desc:IsEmpty() then -- (HELP) IsVt
    LogInfo( "Object description:", object.desc )
end
```
