# ValuedTextSafe:SetFormat

Меняет формат текста для данного ValuedText.

## Описание

```lua
ValuedTextSafe:SetFormat( format: string|WString )
```

Устанавливает указанный формат для текстового содержимого объекта ValuedText.

::: warning Замечание
Изменение формата непустого ValuedText не рекомендуется
:::

::: danger Внимание
Если вам потребовалась эта API, то скорее всего что-то пошло не так
:::

## Список параметров

- **`format`** (`string`| `WString`) - Устанавливаемый формат.

## Возвращаемые значения

Возвращаемое значение отсутствует.

## Примеры

### Установка формата текста

```lua
valuedText:SetFormat( userMods.ToWString( "<h1>отформатированный текст</h1>" ) )
```
