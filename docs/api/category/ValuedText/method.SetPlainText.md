# ValuedTextSafe:SetPlainText

Задает неформатированный текст для данного ValuedText.

## Описание

```lua
ValuedTextSafe:SetPlainText( text: string | WString )
```

Текст выводится как есть, без попытки парсинга.

::: warning Замечание
Изменение формата непустого ValuedText не рекомендуется.
:::

::: danger Внимание
Если вам потребовалась эта API, то скорее всего что-то пошло не так
:::

## Список параметров

- **`text`** (`string` | `WString`) - Устанавливаемый текст.

## Возвращаемые значения

Возвращаемое значение отсутствует.

## Примеры

### Установка неформатированного текста

```lua
valuedText:SetPlainText( userMods.ToWString( "<h1>неотформатированный текст</h1>" ) )
```
