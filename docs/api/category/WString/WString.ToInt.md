# WStringSafe:ToInt

Конвертирует строку в целое число.

## Описание

```lua
WStringSafe:ToInt(): number | nil
```

Конвертирует строку в целое число, если парсинг не удался возвращает `nil`.

## Список параметров

Параметры отсутствуют.

## Возвращаемые значения

Возвращает `number` или `nil` - результат конвертации (`nil` при невозможности конвертации).

## Примеры

### Успешная конвертация

```lua
userMods.ToWString( "1234" ):ToInt() -- 1234
```

### Возврат nil при невозможности конвертации

```lua
userMods.ToWString( "text" ):ToInt() -- nil
```
