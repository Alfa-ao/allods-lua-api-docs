# common.SetCursor

Устанавливает текущий курсор, получая его из ресурсной системы по указанному псевдониму.

## Описание

```lua
common.SetCursor( name: string )
```

Функция устанавливает текущий курсор интерфейса, получая его из ресурсной системы по указанному псевдониму (alias). См. названия курсоров "Аллоды Онлайн/data/Packs/Interface.Mini.pak/Interface/System/Cursors".

## Список параметров

- **`name`** (`string`) - Псевдоним (alias) курсора, используемый для поиска в ресурсной системе. Название курсора в нижнем регистре.

## Возвращаемые значения

Возвращаемое значение отсутствует.

## Примеры

### Установка курсора по умолчанию

```lua
common.SetCursor( "default" )
```
