# remort.CanGetRemortsList

Определяет возможность получения списка альтернативных персонажей, на которых может переключиться главный игрок.

## Описание

```lua
remort.CanGetRemortsList(): boolean
```

Функция возвращает признак возможности получения списка альтернативных персонажей, на которых может переключиться главный игрок.

## Список параметров

Параметры отсутствуют.

## Возвращаемые значения

Возвращает `boolean` - `true`, если можно получить список альтернативных персонажей, и `false` в противном случае.

## Примеры

### Проверка доступности и перебор списка альтернативных персонажей

```lua
if remort.CanGetRemortsList() then
    local remorts = remort.GetRemortsList()
    for i = 0, GetTableSize( remorts ) - 1 do
        local remort = remorts[ i ]
        LogInfo( remort.name )
    end
end
```

::: info Описание примера
В примере выполняется проверка доступности получения списка альтернативных персонажей с помощью функции `remort.CanGetRemortsList()`. При положительном результате извлекается список посредством вызова `remort.GetRemortsList()`, после чего производится перебор элементов с выводом имени каждого персонажа в лог.
:::
