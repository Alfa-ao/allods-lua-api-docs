# remort.GetMainName

Возвращает имя основного персонажа, если игрок является альтернативным персонажем.

## Описание

```lua
remort.GetMainName( unitId ): WString | nil
```

Функция возвращает имя основного персонажа игрока, если игрок является неанонимным альтернативным персонажем. В противном случае функция возвращает `nil`.

## Список параметров

- **`unitId`** (`ObjectId`) - Идентификатор игрока.

## Возвращаемые значения

Возвращает `WString` | `nil` - имя основного персонажа игрока, если игрок является неанонимным альтернативным персонажем. Иначе `nil`.

## Примеры

### Получение имени основного персонажа

```lua
if remort.IsAlt( unitId ) then
    local mainName = remort.GetMainName( unitId )
end
```

::: info Описание примера
В примере проверяется, является ли игрок альтернативным персонажем. Если условие выполняется, извлекается и сохраняется имя основного персонажа.
:::
