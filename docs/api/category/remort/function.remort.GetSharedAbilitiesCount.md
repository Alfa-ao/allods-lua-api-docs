# remort.GetSharedAbilitiesCount

Возвращает количество умений, доступных для передачи альтернативному персонажу.

## Описание

```lua
remort.GetSharedAbilitiesCount(): number
```

Функция возвращает количество умений, которые главный персонаж может передать для использования своему альтернативному персонажу (реморту).

## Список параметров

Параметры отсутствуют.

## Возвращаемые значения

Возвращает `number` - количество умений, доступных для передачи альтернативному персонажу.

## Примеры

### Получение количества доступных умений

```lua
local sharedCount = remort.GetSharedAbilitiesCount()
```
