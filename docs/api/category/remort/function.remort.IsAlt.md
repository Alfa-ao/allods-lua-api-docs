# remort.IsAlt

Проверяет, является ли игрок альтернативным персонажем.

## Описание

```lua
remort.IsAlt( unitId: ObjectId ): boolean
```

Функция определяет, является ли указанный игрок альтернативным персонажем.

## Список параметров

- **`unitId`** (`ObjectId`) - Идентификатор игрока.

## Возвращаемые значения

Возвращает `boolean` - `true`, если игрок является альтернативным персонажем.

## Примеры

### Проверка альтернативного персонажа

```lua
if remort.IsAlt( unitId ) then
    local mainName = remort.GetMainName( unitId )
end
```

::: info Описание примера
В примере проверяется, является ли игрок альтернативным персонажем. Если условие выполняется, извлекается имя основного персонажа с помощью функции `remort.GetMainName`.
:::
