# remortCreation.ChargenShowHelm

Выставляет признак отображения шлемов на персонажах в окне создания персонажа.

## Описание

```lua
remortCreation.ChargenShowHelm( show: boolean )
```

Функция управляет видимостью шлемов на моделях персонажей в окне их создания. По умолчанию персонажи отображаются без шлемов.

::: warning Замечание
Рекомендуется состояние показа или скрытия шлема всегда задавать явно из скрипта.
:::

## Список параметров

- **`show`** (`boolean`) - Флаг, определяющий необходимость отображения шлема на персонаже.

## Возвращаемые значения

Возвращаемое значение отсутствует.

## Примеры

### Включение отображения шлемов

```lua
remortCreation.ChargenShowHelm( true )
```
