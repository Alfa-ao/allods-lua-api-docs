# remortCreation.CreateAvatar
Функция создает аватара с указанным именем, шаблоном, вариантом внешнего вида и другими параметрами, включая основного и дополнительных персонажей, а также питомца.

## Описание

```lua
remortCreation.CreateAvatar( avatarName: WString, template: table, primary: table, trio2: table | nil, trio3: table | nil, petIndex: number | nil, petVariation: table | nil )
```

Функция инициирует создание аватара, описывая как основного персонажа, так и дополнительных (при наличии), включая питомца, на основе заданных шаблонов и вариаций внешнего вида.

::: tip Совет
Функция реализована в пользовательском интерфейсе.
:::

## Список параметров

- **`avatarName`** (`WString`) - Имя создаваемого аватара.

- **`template`** (`table`) - Таблица с информацией, задающей шаблон для аватара. Поля таблицы: 
    - `faction` (`number`) - индекс фракции
    - `race` (`number`) - индекс расы
    - `class` (`number`) - индекс класса
    - `sex` (`number`) - индекс пола.

- **`primary`** (`table`) - Таблица с информацией, задающей вариацию для основного персонажа игрока. Поля таблицы: 
    - `skinTexture` (`number`) - индекс вариации тела `[0..]`.
    - `skinColor` (`number`) - индекс вариации цвета тела `[0..]`.
    - `hairType` (`number`) - индекс типа волос `[0..]`.
    - `hairColor` (`number`) - индекс цвета волос (может игнорироваться для некоторых рас) `[0..]`.
    - `face` (`number`) - индекс типа лица `[0..]`.
    - `facialType` (`number`) - индекс типа особенностей лица или украшений `[0..]`.
    - `additional` (`number`) - индекс варианта татуировки `[0..]`.
    - `morphPresetIndex` (`number`) - индекс варианта пропорций персонажа `[0..]`.

- **`trio2`** (`table` | `nil`) - Таблица с информацией, задающей вариацию для второго дополнительного персонажа игрока. Если создание трио не предполагается, передается `nil`.
    - `name` (`WString`) - имя второго персонажа.
    - `isMale` (`boolean`) - пол второго персонажа.
    - `skinTexture` (`number`) - индекс вариации тела `[0..]`.
    - `skinColor` (`number`) - индекс вариации цвета тела `[0..]`.
    - `hairType` (`number`) - индекс типа волос `[0..]`.
    - `hairColor` (`number`) - индекс цвета волос (может игнорироваться для некоторых рас) `[0..]`.
    - `face` (`number`) - индекс типа лица `[0..]`.
    - `facialType` (`number`) - индекс типа особенностей лица или украшений `[0..]`.
    - `additional` (`number`) - индекс варианта татуировки `[0..]`.
    - `morphPresetIndex` (`number`) - индекс варианта пропорций персонажа `[0..]`.

- **`trio3`** (`table` | `nil`) - Таблица с информацией, задающей вариацию для третьего дополнительного персонажа игрока. Если создание трио не предполагается, передается `nil`.
    - `name` (`WString`) - имя третьего персонажа.
    - `isMale` (`boolean`) - пол третьего персонажа.
    - `skinTexture` (`number`) - индекс вариации тела `[0..]`.
    - `skinColor` (`number`) - индекс вариации цвета тела `[0..]`.
    - `hairType` (`number`) - индекс типа волос `[0..]`.
    - `hairColor` (`number`) - индекс цвета волос (может игнорироваться для некоторых рас) `[0..]`.
    - `face` (`number`) - индекс типа лица `[0..]`.
    - `facialType` (`number`) - индекс типа особенностей лица или украшений `[0..]`.
    - `additional` (`number`) - индекс варианта татуировки `[0..]`.
    - `morphPresetIndex` (`number`) - индекс варианта пропорций персонажа `[0..]`.

- **`petIndex`** (`number` | `nil`) - Индекс облика питомца, начиная с `0`.

- **`petVariation`** (`table` | `nil`) - Таблица с информацией, задающей вариацию для питомца. Если настраиваемый питомец отсутствует, передается `nil`.
    - `name` (`WString`) - имя питомца.
    - `skinTexture` (`number`) - индекс вариации тела `[0..]`.
    - `skinColor` (`number`) - индекс вариации цвета тела `[0..]`.
    - `hairType` (`number`) - индекс типа волос `[0..]`.
    - `hairColor` (`number`) - индекс цвета волос (может игнорироваться для некоторых рас) `[0..]`.
    - `face` (`number`) - индекс типа лица `[0..]`.
    - `facialType` (`number`) - индекс типа особенностей лица или украшений `[0..]`.
    - `additional` (`number`) - индекс варианта татуировки `[0..]`.
    - `morphPresetIndex` (`number`) - индекс варианта пропорций персонажа `[0..]`.

## Возвращаемые значения

Возвращаемое значение отсутствует.

## Примеры

### Создание аватара без дополнительных персонажей
```lua
remortCreation.CreateAvatar( avatarName, template, primary, nil, nil, 1, petVariation )
```
