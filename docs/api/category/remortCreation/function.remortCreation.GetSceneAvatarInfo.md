# remortCreation.GetSceneAvatarInfo

Возвращает информацию о персонаже игрока, выставленном на сцене.

## Описание

```lua
remortCreation.GetSceneAvatarInfo(): table|nil
```

Функция возвращает таблицу с информацией о персонаже игрока, выставленном на сцене. Для персонажа игрока может быть один основной персонаж (модель) и несколько дополнительных (например, для гибберлингов), включая питомца.

## Список параметров

Параметры отсутствуют.

## Возвращаемые значения

Возвращает `table` | `nil`.
Если персонаж присутствует на сцене, возвращается таблица со следующими полями:
- **`primaryId`** (`ObjectId` | `nil`) - Идентификатор основного персонажа.

- **`trio2Id`** (`ObjectId` | `nil`) - Идентификатор второго (дополнительного) персонажа (только для троицы).

- **`trio3Id`** (`ObjectId` | `nil`) - Идентификатор третьего (дополнительного) персонажа (только для троицы).

- **`petId`** (`ObjectId` | `nil`) - Идентификатор питомца.

## Примеры

### Получение информации и установка позиции питомца

```lua
local avatarInfo = remortCreation.GetSceneAvatarInfo()
if avatarInfo.petId then
    remortCreation.SetSceneCharacterPos( avatarInfo.petId, { posX = 1.0; posY = 2.0; posZ = 0.0 } )
end
```

::: info Описание примера
В примере запрашивается информация о персонаже на сцене. При наличии питомца вызывается функция для установки его координат.
:::
