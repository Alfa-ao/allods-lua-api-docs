# remortCreation.GetVariationsStatus

Возвращает информацию о состоянии запроса вариаций персонажей.

## Описание

```lua
remortCreation.GetVariationsStatus(): table
```

Функция возвращает таблицу, содержащую информацию о состоянии запроса вариаций персонажей.

## Список параметров

Параметры отсутствуют.

## Возвращаемые значения

Возвращает `table`.
Описание о таблице:
- **`isActual`** (`boolean`) - Флаг актуальности информации.

- **`isInProgress`** (`boolean`) - Флаг, указывающий на то, что информация запрошена с сервера.

## Примеры

### Получение состояния запроса

```lua
local status = remortCreation.GetVariationsStatus()
```
