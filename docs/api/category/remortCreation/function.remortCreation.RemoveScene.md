# remortCreation.RemoveScene

Убирает ранее созданную сцену, если таковая была создана.

## Описание

```lua
remortCreation.RemoveScene()
```

Функция убирает ранее созданную сцену, если таковая была создана. Реализована в UI и может использоваться при работе с несколькими Control3DSafe, например в разных аддонах.

## Список параметров

Параметры отсутствуют.

## Возвращаемые значения

Возвращаемое значение отсутствует.

## Примеры

### Удаление сцены

```lua
remortCreation.RemoveScene()
```
