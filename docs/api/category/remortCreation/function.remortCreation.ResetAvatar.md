# remortCreation.ResetAvatar

Функция сбрасывает параметры имеющегося альтернативного персонажа на новые имя, шаблон, вариант внешнего вида и другие характеристики, включая дополнительных персонажей и питомца.

## Описание

```lua
remortCreation.ResetAvatar( avatarName: WString, template: table, primary: table, trio2: table | nil, trio3: table | nil, petIndex: number | nil, petVariation: table | nil, resetedAvatarId: PersistentId )
```

Функция инициирует попытку сброса параметров имеющегося альтернативного персонажа с указанным именем на новое имя, шаблон (фракция/раса/класс/пол), вариант внешнего вида и другие характеристики. Описывается как основной персонаж, так и дополнительные (при наличии), включая питомца.

::: warning Замечание
Функция реализована в UI.
:::

## Список параметров

- **`avatarName`** (`WString`) - Новое имя альтернативного персонажа.

- **`template`** (`table`) - Таблица с информацией, задающей шаблон для аватара.
    - **`faction`** (`number`) - Индекс фракции [0..].

    - **`race`** (`number`) - Индекс расы [0..].

    - **`class`** (`number`) - Индекс класса [0..].

    - **`sex`** (`number`) - Индекс пола [0..].

- **`primary`** (`table`) - Таблица с информацией, задающей вариацию для основного персонажа игрока.
    - **`skinTexture`** (`number`) - Индекс вариации тела [0..].

    - **`skinColor`** (`number`) - Индекс вариации цвета тела [0..].

    - **`hairType`** (`number`) - Индекс типа волос [0..].

    - **`hairColor`** (`number`) - Индекс цвета волос [0..]. Может игнорироваться (например, для гибберлингов).

    - **`face`** (`number`) - Индекс типа лица [0..].

    - **`facialType`** (`number`) - Индекс типа особенностей (лица или украшений) [0..].

    - **`additional`** (`number`) - Индекс варианта татуировки [0..].

    - **`morphPresetIndex`** (`number`) - Индекс варианта пропорций персонажа [0..].

- **`trio2`** (`table` | `nil`) - Таблица с информацией, задающей вариацию для второго (дополнительного) персонажа игрока и некоторые дополнительные параметры, или `nil`, если не трио. Содержит те же поля, что и `primary`, а также дополнительные:
    - **`name`** (`WString`) - Имя персонажа.

    - **`isMale`** (`boolean`) - Пол персонажа.

- **`trio3`** (`table` | `nil`) - Таблица с информацией, задающей вариацию для третьего (дополнительного) персонажа игрока и некоторые дополнительные параметры, или `nil`, если не трио. Содержит те же поля, что и `primary`, а также дополнительные:
    - **`name`** (`WString`) - Имя персонажа.

    - **`isMale`** (`boolean`) - Пол персонажа.

- **`petIndex`** (`number` | `nil`) - Индекс облика питомца, начиная с `0`, или `nil`, если питомец отсутствует.

- **`petVariation`** (`table` | `nil`) - Таблица с информацией, задающей вариацию для питомца, или `nil`, если настраиваемый питомец отсутствует. Содержит те же поля, что и `primary`, а также дополнительное:
    - **`name`** (`WString`) - Имя питомца.

- **`resetedAvatarId`** (`PersistentId`) - Идентификатор имеющегося альтернативного персонажа.

## Возвращаемые значения

Возвращаемое значение отсутствует.

## Примеры

### Сброс параметров с проверкой списка ремортов

```lua
if remort.CanGetRemortsList() then
    local remorts = remort.GetRemortsList()
    if remorts[ 1 ] then
        remortCreation.CreateAvatar( avatarName, template, primary, nil, nil, 1, petVariation, remorts[ 1 ].avatarServerId )
    end
end
```

::: info Описание примера
В примере проверяется возможность получения списка ремортов. Если список доступен и содержит хотя бы один элемент, вызывается функция создания аватара с передачей параметров из первого элемента списка.
:::
