# remortCreation.SetChargenEquipType

Задает вид показываемой экипировки на экране создания персонажа.

## Описание

```lua
remortCreation.SetChargenEquipType( equipType: number )
```

Функция определяет вид отображаемой экипировки на экране создания персонажа. По умолчанию персонажи показываются в специальной высокоуровневой экипировке.

::: warning Замечание
Рекомендуется вид показываемой экипировки всегда задавать явно из скрипта.
:::

::: info Перечисление
- `CHARGEN_EQUIP_TYPE_NONE` - показывать без экипировки.
- `CHARGEN_EQUIP_TYPE_HIGH_LEVEL` - показывать в специальной высокоуровневой экипировке.
:::

## Список параметров

- **`equipType`** (`number`(`CHARGEN_EQUIP_TYPE_*`)) - Вид показываемой экипировки.

## Возвращаемые значения

Возвращаемое значение отсутствует.

## Примеры

### Установка высокоуровневой экипировки

```lua
remortCreation.SetChargenEquipType( CHARGEN_EQUIP_TYPE_HIGH_LEVEL )
```
