# remortCreation.SetSceneAvatar

Выставляет в сцене указанного аватара из списка аватаров на шарде.

## Описание

```lua
remortCreation.SetSceneAvatar( avatarServerId: number )
```

Функция размещает в сцене указанного аватара из списка доступных аватаров на шарде.

## Список параметров

- **`avatarServerId`** (`number`) - Серверный идентификатор аватара.

## Возвращаемые значения

Возвращаемое значение отсутствует.

## Примеры

### Выставление аватара в сцену

```lua
remortCreation.SetSceneAvatar( firstAvatarId )
```
