# remortCreation.SetSceneAvatarByTemplate

Выставляет аватара в сцене по заданному шаблону.

## Описание

```lua
remortCreation.SetSceneAvatarByTemplate( template: table, isTrio2Male: boolean, isTrio3Male: boolean, petIndex: number | nil, growthIndex: number )
```

Функция выставляет в сцене аватара по заданной информации о шаблоне. Шаблон задается набором индексов в таблице ресурсной системы с информацией о шаблонах. Также задается информация о поле дополнительных персонажей (например, для гибберлингов), которая используется только в том случае, если дополнительные персонажи действительно присутствуют.

## Список параметров

- **`template`** (`table`) - Таблица с информацией, задающей шаблон для аватара. Поля таблицы:

    - **`faction`** (`number`) - Индекс фракции.

    - **`race`** (`number`) - Индекс расы.

    - **`class`** (`number`) - Индекс класса.

    - **`sex`** (`number`) - Индекс пола.

    - **`avatarId`** (`number` | `nil`) - Серверный id аватара. Если указан, текущий пет аватара учитывается при формировании сцены, иначе на сцене присутствует только дефолтный пет.

- **`isTrio2Male`** (`boolean`) - Пол второго (дополнительного) персонажа. Игнорируется, если персонаж не трио.

- **`isTrio3Male`** (`boolean`) - Пол третьего (дополнительного) персонажа. Игнорируется, если персонаж не трио.

- **`petIndex`** (`number` | `nil`) - Индекс облика пета, начиная с `0`.

- **`growthIndex`** (`number`) - Номер стадии развития персонажа, начиная с `0`.

## Возвращаемые значения

Возвращаемое значение отсутствует.

## Примеры

### Установка аватара по шаблону

```lua
remortCreation.SetSceneAvatarByTemplate( template, true, true, 1, 0 )
```
