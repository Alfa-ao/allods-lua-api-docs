# remortCreation.SetSceneCharacterVariation

Выставляет указанную вариацию для выбранного персонажа в сцене.

## Описание

```lua
remortCreation.SetSceneCharacterVariation( characterId: ObjectId, variation: table )
```

Функция устанавливает указанную вариацию для выбранного персонажа (основного, дополнительного из трио или питомца) в сцене посредством задания набора индексов.

::: warning Замечание
Изменение вариации допускается только для персонажей, созданных на сцене по шаблону аватара. Для персонажей, созданных на сцене по имени аватара, изменение запрещено и вариация выставляется автоматически.
:::

## Список параметров

- **`characterId`** (`ObjectId`) - Идентификатор персонажа в сцене.

- **`variation`** (`table`) - Таблица с информацией, задающей вариацию для аватара.

    - `skinTexture` (`number`) - Индекс вариации тела [0..].

    - `skinColor` (`number`) - Индекс вариации цвета тела [0..].

    - `hairType` (`number`) - Индекс типа волос [0..].

    - `hairColor` (`number`) - Индекс цвета волос [0..]. Игнорируется для некоторых рас, например для гибберлингов.

    - `face` (`number`) - Индекс типа лица [0..].

    - `facialType` (`number`) - Индекс типа особенностей лица или украшений [0..].

    - `additional` (`number`) - Индекс варианта татуировки [0..].

    - `morphPresetIndex` (`number`) - Индекс варианта пропорций персонажа [0..].

## Возвращаемые значения

Возвращаемое значение отсутствует.

## Примеры

### Установка вариации для основного персонажа

```lua
remortCreation.SetSceneCharacterVariation( primaryCharacterId, variation )
```
