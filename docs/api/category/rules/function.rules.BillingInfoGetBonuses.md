# rules.BillingInfoGetBonuses
Получает список бонусов, имеющихся в данный момент у аккаунта.

## Описание

```lua
rules.BillingInfoGetBonuses(): table | nil
```

Функция возвращает список бонусов, имеющихся в данный момент у аккаунта. Если информация не получена или список бонусов пуст, возвращается `nil`. В противном случае возвращается таблица, индексируемая с `0`, содержащая идентификаторы бонусов.

## Список параметров

Параметры отсутствуют.

## Возвращаемые значения

Возвращает `table` | `nil` - таблица (индексируется с `0`), содержащая идентификаторы бонусов (`BillingBonusId`), или `nil`, если информация не получена или список бонусов пуст.

## Примеры

### Получение информации о первом бонусе
```lua
local bonuses = rules.BillingInfoGetBonuses()
if bonuses and bonuses[0] then
    local bonusInfo = rules.BillingInfoGetBonusInfo( bonuses[0] )
end
```

::: info Описание примера
В примере запрашивается список доступных бонусов аккаунта. При успешном получении списка и наличии хотя бы одного бонуса извлекается подробная информация о первом бонусе.
:::
