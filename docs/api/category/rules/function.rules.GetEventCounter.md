# rules.GetEventCounter

Возвращает значения счётчика игрового события.

## Описание

```lua
rules.GetEventCounter( eventRuleId: ObjectId ): table|nil
```

Функция возвращает таблицу с информацией о текущем и максимальном значении счётчика игрового события. Для обычных событий максимальное значение счётчика равно `0`. Текущее значение счётчика может превышать максимальное значение.

## Список параметров

- **`eventRuleId`** (`ObjectId`) - Идентификатор описания правил события.

## Возвращаемые значения

Возвращает `table` | `nil` - таблица с описанием счётчика, если информация успешно получена:

- **`value`** (`number`) - Текущее значение счётчика.

- **`limit`** (`number`) - Максимальное значение счётчика.

## Примеры

### Получение значений счётчика события

```lua
local eventRuleInfo = rules.GetEventInfo( eventRuleId )
if eventRuleInfo then
    local counter = rules.GetEventCounter( eventRuleId )
    LogInfo( counter.value, " / ", counter.limit )
end
```

::: info Описание примера
В примере запрашивается информация о правилах события. Если данные успешно получены, извлекаются текущее и максимальное значения счётчика с последующим выводом в лог.
:::
