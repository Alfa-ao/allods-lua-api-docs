# rules.GetEventTimeIntervals
Получает описание времени срабатывания правил игрового ивента.

## Описание

```lua
rules.GetEventTimeIntervals( eventRuleId: ObjectId ): table
```

Функция возвращает список различных интервалов, в которых проходит ивент. В списке могут присутствовать интервалы разного типа, например, пять ежедневных часовых интервалов через каждые два часа и один еженедельный интервал, занимающий всё воскресенье. Элементом основной таблицы является таблица `TimeInterval`, представляющая собой описание одного временного интервала, в котором проходит ивент. Так как сам интервал может быть только одного типа, в таблице заполнено только одно поле из представленных ниже. В заполненном поле содержится таблица с описанием данных для этого типа интервала.

::: warning Замечание
Время и дата требуют переделки на использование локализуемого формата и локального времени игрока.
:::

## Список параметров

- **`eventRuleId`** (`ObjectId`) - Идентификатор правил ивента.

## Возвращаемые значения

Возвращает `table` - индексированная с 0 таблица с отдельными временными интервалами. Элементом основной таблицы является таблица `TimeInterval`, в которой заполнено только одно поле в зависимости от типа интервала:


- **`hourly`** (`table` | `nil` ) - если интервал ежечасный, то таблица с полями:
    - `start` (`table`) - таблица, описывающая начало интервала. Поля:
        - `minute` (`number`) - минута начала события, начиная с 0
    - `finish` (`table`) - таблица, описывающая конец интервала. Поля, такие же как в `start`.
    - `durationMs` (`number`) - длина интервала в миллисекундах

- **`daily`** (`table` | `nil` ) - если интервал ежедневный, то таблица с полями:
    - `start` (`table`) - таблица, описывающая начало интервала. Поля:
        - `hour` (`number`) - час начала события, начиная с 0
        - `minute` (`number`) - минута начала события, начиная с 0
    - `finish` (`table`) - таблица, описывающая конец интервала. Поля, такие же как в `start`.
    - `durationMs` (`number`) - длина интервала в миллисекундах

- **`weekly`** (`table` | `nil` ) - если интервал еженедельный, то таблица с полями:
    - `start` (`table`) - таблица, описывающая начало интервала. Поля:
        - `day` (`number`(`ENUM_DayOfWeek...`)) - день недели начала события, начиная с 1 ( 1 - понедельник, 7 - воскресенье )
        - `hour` (`number`) - час начала события, начиная с 0
        - `minute` (`number`) - минута начала события, начиная с 0
    - `finish` (`table`) - таблица, описывающая конец интервала. Поля, такие же как в `start`.
    - `durationMs` (`number`) - длина интервала в миллисекундах

- **`monthly`** (`table` | `nil` ) - если интервал ежемесячный, то таблица с полями:
    - `start` (`table`) - таблица, описывающая начало интервала. Поля:
        - `day` (`number`) - день месяца начала события, начиная с 1
        - `hour` (`number`) - час начала события, начиная с 0
        - `minute` (`number`) - минута начала события, начиная с 0
    - `finish` (`table`) - таблица, описывающая конец интервала. Поля, такие же как в `start`.
    - `durationMs` (`number`) - длина интервала в миллисекундах

- **`monthly_reverse`** (`table` | `nil` ) - если интервал ежемесячный, заканчивающийся к определённому времени, то таблица с полями:
    - `start` (`table`) - таблица, описывающая начало интервала. Поля:
        - `day` (`number`) - день месяца начала события, начиная с 1
        - `hour` (`number`) - час начала события, начиная с 0
        - `minute` (`number`) - минута начала события, начиная с 0
    - `finish` (`table`) - таблица, описывающая конец интервала. Поля, такие же как в `start`.
    - `durationMs` (`number`) - длина интервала в миллисекундах

- **`yearly`** (`table` | `nil` ) - если интервал ежегодный, то таблица с полями:
    - `start` (`table`) - таблица, описывающая начало интервала. Поля:
        - `sysMonth` (`string`(`ENUM_Month...`)) - месяц начала события
        - `month` (`number`(`ENUM_Month...`)) - месяц начала события
        - `day` (`number`) - день месяца начала события, начиная с 1
        - `hour` (`number`) - час начала события, начиная с 0
        - `minute` (`number`) - минута начала события, начиная с 0
    - `finish` (`table`) - таблица, описывающая конец интервала. Поля, такие же как в `start`.
    - `durationMs` (`number`) - длина интервала в миллисекундах

- **`now`** (`table` | `nil` ) - если интервал "сейчас", то таблица с полями:
    - `start` (`table`) - пустая таблица
    - `finish` (`table`) - пустая таблица
    - `durationMs` (`number`) - длина интервала в миллисекундах

- **`never`** (`table` | `nil` ) - если интервал "никогда", то таблица с полями:
    - `start` (`table`) - пустая таблица
    - `finish` (`table`) - пустая таблица
    - `durationMs` (`number`) - длина интервала в миллисекундах

- **`once`** (`table` | `nil` ) - если интервал однократный, то таблица с полями:
    - `start` (`table`) - таблица, описывающая начало интервала. Поля:
        - `year` (`number`) - год начала события
        - `sysMonth` (`string`(`ENUM_Month...`)) - месяц начала события
        - `month` (`number`(`ENUM_Month...`)) - месяц начала события
        - `day` (`number`) - день месяца начала события, начиная с 1
        - `hour` (`number`) - час начала события, начиная с 0
        - `minute` (`number`) - минута начала события, начиная с 0
    - `finish` (`table`) - таблица, описывающая конец интервала. Поля, такие же как в `start`.
    - `durationMs` (`number`) - длина интервала в миллисекундах

- **`fromTime`** (`table` | `nil` ) - если интервал начинается в какой-то момент и не имеет конца, то таблица с полями:
    - `start` (`table`) - таблица, описывающая начало интервала. Поля:
        - `year` (`number`) - год начала события
        - `sysMonth` (`string`(`ENUM_Month...`)) - месяц начала события
        - `month` (`number`(`ENUM_Month...`)) - месяц начала события
        - `day` (`number`) - день месяца начала события, начиная с 1
        - `hour` (`number`) - час начала события, начиная с 0
        - `minute` (`number`) - минута начала события, начиная с 0
    - `finish` (`table`) - таблица, описывающая конец интервала. Поля, такие же как в `start` с теми же значениями.
    - `durationMs` (`number`) - длина интервала в миллисекундах

- **`cyclic`** (`table` | `nil` ) - если интервал длиться и повторяется через фиксированный период, то таблица с полями:
    - `start` (`table`) - таблица, описывающая начало интервала. Поля:
        - `year` (`number`) - год начала события
        - `sysMonth` (`string`(`ENUM_Month...`)) - месяц начала события
        - `month` (`number`(`ENUM_Month...`)) - месяц начала события
        - `day` (`number`) - день месяца начала события, начиная с 1
        - `hour` (`number`) - час начала события, начиная с 0
        - `minute` (`number`) - минута начала события, начиная с 0
    - `finish` (`table`) - таблица, описывающая конец интервала. Поля, такие же как в `start`.
    - `durationMs` (`number`) - длина интервала в миллисекундах

## Примеры

### Получение временного интервала
```lua
local interval = rules.GetEventTimeIntervals( eventRuleId )[ 0 ]
if interval then
    if interval.daily then
        LogInfo( "hour: ", interval.daily.hour )
    end
end
```
