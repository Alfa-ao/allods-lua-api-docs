# runeLib.Combine

Соединяет одинаковые руны для получения рун более высокого уровня.

## Описание

```lua
runeLib.Combine( runeId: ObjectId, instrumentId: ObjectId, crystalCrumbBonus: number, count: number )
```

Функция производит соединение одинаковых рун для получения рун более высокого уровня.

## Список параметров

- **`runeId`** (`ObjectId`) - Идентификатор руны в контейнере.

- **`instrumentId`** (`ObjectId`) - Идентификатор инструмента в контейнере.

- **`crystalCrumbBonus`** (`number`) - Бонус в оплате кристаллической крошкой. Принимает значения от `-7` до `7`, где `0` - дефолтная цена, `1` - увеличение цены на `10%`, `-1` - уменьшение цены на `10%`.

- **`count`** (`number`) - Требуемое количество новых рун.

## Возвращаемые значения

Возвращаемое значение отсутствует.

## Примеры

### Соединение рун

```lua
runeLib.Combine( runeId, instrumentId, 3 )
```
