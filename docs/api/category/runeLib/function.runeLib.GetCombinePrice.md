# runeLib.GetCombinePrice

Возвращает стоимость попытки соединения одинаковых рун.

## Описание

```lua
runeLib.GetCombinePrice( runeId: ObjectId, crystalCrumbBonus: number, count: number ): table
```

Функция возвращает таблицу, содержащую стоимость соединения рун с учетом бонуса оплаты кристаллической крошкой и требуемого количества новых рун.

## Список параметров

- **`runeId`** (`ObjectId`) - Идентификатор руны в контейнере.

- **`crystalCrumbBonus`** (`number`) - Бонус в оплате кристаллической крошкой от `-7` до `+7`. Значение `0` устанавливает дефолтную цену, положительные значения увеличивают оплату крошкой, отрицательные - уменьшают.

- **`count`** (`number`) - Требуемое количество новых рун.

## Возвращаемые значения

Возвращает `table` - таблицу со следующими полями:

- **`goldDust`** (`number`) - Количество золотой пыли.

- **`crystalCrumb`** (`number`) - Количество кристаллической крошки.

## Примеры

### Расчет стоимости соединения рун

```lua
local price = runeLib.GetCombinePrice( runeId, -5, 3 )
LogInfo( "gold dust = ", price.goldDust )
LogInfo( "crystal crumb = ", price.crystalCrumb )
```
