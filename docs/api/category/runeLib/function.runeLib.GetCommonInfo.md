# runeLib.GetCommonInfo

Возвращает информацию общего характера, неспецифичную для аватара и не меняющуюся со временем.

## Описание

```lua
runeLib.GetCommonInfo(): table
```

Функция возвращает таблицу с информацией общего характера, неспецифичной для аватара и не меняющейся со временем.

## Список параметров

Параметры отсутствуют.

## Возвращаемые значения

Возвращает `table` - таблицу с информацией общего характера.

- **`goldDust`** (`ObjectId`) - Идентификатор предмета-образца золотой пыли.

- **`crystalCrumb`** (`ObjectId`) - Идентификатор предмета-образца кристаллической крошки.

## Примеры

### Получение информации о предмете-образце

```lua
local info = runeLib.GetCommonInfo()
LogInfo( itemLib.GetItemInfo( info.goldDust ) )
```

::: info Описание примера
В примере запрашивается общая информация, после чего из полученной таблицы извлекается идентификатор предмета золотой пыли и передается в функцию получения информации о предмете для вывода в лог.
:::
