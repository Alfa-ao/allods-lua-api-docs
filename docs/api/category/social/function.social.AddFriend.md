# social.AddFriend

Добавляет персонажа в список друзей текущего аватара игрока.

## Описание

```lua
social.AddFriend( name: WString, description: WString )
```

Функция предпринимает попытку добавления персонажа в список друзей текущего аватара игрока.

## Список параметров

- **`name`** (`WString`) - Имя персонажа.

- **`description`** (`WString`) - Собственный комментарий игрока.

## Возвращаемые значения

Возвращаемое значение отсутствует.

## Примеры

### Добавление персонажа в друзья

```lua
social.AddFriend( name, description )
```
