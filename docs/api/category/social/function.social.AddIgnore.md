# social.AddIgnore

Добавляет персонажа в список игнорирования текущего аватара игрока.

## Описание

```lua
social.AddIgnore( name: WString, description: WString )
```

Функция добавляет персонажа в список игнорирования текущего аватара и сохраняет собственный комментарий игрока.

## Список параметров

- **`name`** (`WString`) - Имя персонажа, которого необходимо добавить в список игнорирования.

- **`description`** (`WString`) - Собственный комментарий игрока, привязываемый к игнорируемому персонажу.

## Возвращаемые значения

Возвращаемое значение отсутствует.

## Примеры

### Добавление персонажа в список игнорирования

```lua
social.AddIgnore( playerName, comment )
```
