# social.CanSocialize

Определяет возможность социального взаимодействия с юнитом, включая добавление в друзья или список игнора.

## Описание

```lua
social.CanSocialize( unitId: ObjectId ): boolean
```

Функция выполняет проверку возможности социального взаимодействия с юнитом для добавления в друзья или список игнора.

## Список параметров

- **`unitId`** (`ObjectId`) - Уникальный идентификатор юнита.

## Возвращаемые значения

Возвращает `boolean` - `true`, если социальное взаимодействие возможно, и `false` в противном случае.

## Примеры

### Проверка возможности взаимодействия

```lua
local canSocialize = social.CanSocialize( unitId )
```
