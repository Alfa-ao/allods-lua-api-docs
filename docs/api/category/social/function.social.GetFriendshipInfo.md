# social.GetFriendshipInfo

Возвращает параметры дружбы с побратимами.

## Описание

```lua
social.GetFriendshipInfo(): table | nil
```

Функция возвращает таблицу с параметрами дружбы с побратимами или `nil` в случае ошибки в данных.

## Список параметров

Параметры отсутствуют.

## Возвращаемые значения

Возвращает `table` или `nil`.
В случае ошибки в данных возвращается `nil`, иначе таблица со следующими полями:

- **`bestFriendsLimit`** (`number`) - Максимальное количество лучших друзей.
- **`maxMountGrade`** (`number`) - Максимальный грейд маунта, которого можно передать.

## Примеры

### Получение параметров дружбы

```lua
local bestfriendsInfo = social.GetFriendshipInfo()
```
