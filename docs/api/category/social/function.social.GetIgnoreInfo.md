# social.GetIgnoreInfo

Возвращает информацию о персонаже из списка игнорирования главного игрока.

## Описание

```lua
social.GetIgnoreInfo( ignoreId: ObjectId ): table | nil
```

Функция возвращает информацию о персонаже из списка игнорирования главного игрока. Если персонаж из списка игнорирования не найден, возвращается `nil`. В противном случае возвращается таблица с информацией о персонаже.

## Список параметров

- **`ignoreId`** (`ObjectId`) - Идентификатор персонажа из списка игнорирования. Внимание: это не обычный идентификатор игрока.

## Возвращаемые значения

Возвращает `table` | `nil` - информация о персонаже из списка игнорирования или `nil`, если персонаж не найден.

При успешном получении информации возвращается таблица со следующими полями:

- **`id`** (`ObjectId`) - Идентификатор элемента из списка игнорирования.

- **`name`** (`WString`) - Имя персонажа.

- **`description`** (`WString`) - Комментарий главного игрока, оставленный для данного персонажа.

## Примеры

### Получение информации из списка игнорирования

```lua
local ignoreList = social.GetIgnoreList()
for i = 0, GetTableSize(ignoreList) - 1 do
    local ignoreInfo = social.GetIgnoreInfo(ignoreList[i])
    if ignoreInfo then
        local ignoreName = ignoreInfo.name
    end
end
```

::: info Описание примера
В примере извлекается список идентификаторов игнорируемых персонажей. Затем в цикле перебираются все элементы списка, и для каждого идентификатора запрашивается подробная информация. Если информация успешно получена, извлекается имя персонажа.
:::
