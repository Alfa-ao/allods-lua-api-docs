# social.GetRevivalRollInfo
Возвращает информацию о параметрах системы приглашений возврата в игру.

## Описание

```lua
social.GetRevivalRollInfo(): table|nil
```

Функция возвращает информацию о параметрах системы приглашений возврата в игру. Если информация недоступна, возвращается `nil`.

## Список параметров

Параметры отсутствуют.

## Возвращаемые значения

Возвращает `table` | `nil`.
Если информация успешно получена, возвращается таблица со следующими полями:

- **`maxActiveRolls`** (`number`) - Максимальное количество активных заявок.

## Примеры

### Получение информации о системе возврата

```lua
local info = social.GetRevivalRollInfo()
if info then
    LogInfo( "Максимальное количество активных заявок: " .. info.maxActiveRolls )
end
```
