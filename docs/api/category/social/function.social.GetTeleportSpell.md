# social.GetTeleportSpell

Возвращает идентификатор ресурса спелла для перемещения к побратиму.

## Описание

```lua
social.GetTeleportSpell(): SpellId
```

Функция возвращает идентификатор ресурса спелла для перемещения к побратиму. Полученный идентификатор не предназначен для прямого запуска умения, однако может быть использован для проверки времени восстановления.

## Список параметров

Параметры отсутствуют.

## Возвращаемые значения

Возвращает `SpellId` - идентификатор ресурса спелла.

## Примеры

### Получение идентификатора спелла

```lua
local spellId = social.GetTeleportSpell()
```
