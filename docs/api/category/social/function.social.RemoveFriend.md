# social.RemoveFriend

Удаляет персонажа из списка друзей текущего аватара игрока.

## Описание

```lua
social.RemoveFriend( name: WString )
```

Функция удаляет указанного персонажа из списка друзей текущего аватара игрока.

## Список параметров

- **`name`** (`WString`) - Имя персонажа, которого необходимо удалить из списка друзей.

## Возвращаемые значения

Возвращаемое значение отсутствует.

## Примеры

### Удаление друга из списка

```lua
social.RemoveFriend( name )
```
