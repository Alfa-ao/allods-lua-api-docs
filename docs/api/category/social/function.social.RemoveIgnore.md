# social.RemoveIgnore
Удаляет персонажа из списка игнорирования текущего аватара игрока.

## Описание

```lua
social.RemoveIgnore( name: WString )
```

Функция инициирует удаление указанного персонажа из списка игнорирования текущего аватара игрока.

## Список параметров

- **`name`** (`WString`) - Имя персонажа, которого необходимо удалить из списка игнорирования.

## Возвращаемые значения

Возвращаемое значение отсутствует.

## Примеры

### Удаление персонажа из списка игнорирования
```lua
social.RemoveIgnore( name )
```
