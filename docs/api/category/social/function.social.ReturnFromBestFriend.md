# social.ReturnFromBestFriend
Инициирует возвращение от побратима.

## Описание

```lua
social.ReturnFromBestFriend()
```

Функция инициирует процесс возвращения телепортом от побратима. Вызов запрещен, если возвращение пока недоступно.

## Список параметров

Параметры отсутствуют.

## Возвращаемые значения

Возвращаемое значение отсутствует.

## Примеры

### Проверка возможности и возвращение от побратима
```lua
if social.CanReturn() then
    social.ReturnFromBestFriend()
end
```

::: info Описание примера
В примере сначала проверяется доступность возвращения с помощью функции `social.CanReturn()`. Если условие выполняется, инициируется процесс возвращения.
:::
