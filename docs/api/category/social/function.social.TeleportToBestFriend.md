# social.TeleportToBestFriend

Делает попытку переместиться к побратиму.

## Описание

```lua
social.TeleportToBestFriend( friendId: ObjectId )
```

Вызов функции запрещен, если перемещение пока не доступно.

## Список параметров

- **`friendId`** (`ObjectId`) - Идентификатор побратима.

## Возвращаемые значения

Возвращаемое значение отсутствует.

## Примеры

### Проверка доступности и перемещение к побратиму

```lua
if social.CanTeleport() then
    social.TeleportToBestFriend( friendId )
end
```

::: info Описание примера
В примере сначала проверяется доступность перемещения с помощью функции `social.CanTeleport()`. Если перемещение доступно, инициируется перемещение к побратиму по его идентификатору.
:::
