# soulProgressLib.GetCurrentExperience

Возвращает текущее количество опыта души.

## Описание

```lua
soulProgressLib.GetCurrentExperience(): number
```

Функция возвращает текущее количество опыта души.

## Список параметров

Параметры отсутствуют.

## Возвращаемые значения

Возвращает `number` - количество опыта души.

## Примеры

### Получение текущего опыта души

```lua
local value = soulProgressLib.GetCurrentExperience()
```
