# soulProgressLib.GetMaxLevel

Возвращает максимальный уровень души.

## Описание

```lua
soulProgressLib.GetMaxLevel(): number | nil
```

Функция возвращает максимальный уровень души.

## Список параметров

Параметры отсутствуют.

## Возвращаемые значения

Возвращает `number` | `nil` - максимальный уровень души или `nil` в случае ошибки.

## Примеры

### Получение максимального уровня души

```lua
local soulGetMaxLevel = soulProgressLib.GetMaxLevel()
```
