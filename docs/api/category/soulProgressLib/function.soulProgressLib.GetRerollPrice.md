# soulProgressLib.GetRerollPrice
Рассчитывает количество опыта, затрачиваемого на сброс талантов.

## Описание
```lua
soulProgressLib.GetRerollPrice(): number
```
Функция возвращает количество опыта, затрачиваемого на сброс талантов.

## Список параметров
Параметры отсутствуют.

## Возвращаемые значения
Возвращает `number` - количество опыта, затрачиваемого на сброс талантов.

## Примеры
### Получение стоимости сброса талантов
```lua
local value = soulProgressLib.GetRerollPrice()
```
