# soulProgressLib.GetTipProgressGain
Возвращает подсказку по прокачке души с указанием активностей и награды.

## Описание

```lua
soulProgressLib.GetTipProgressGain(): ValuedText | nil
```

Функция возвращает подсказку по прокачке души с указанием активностей и награды. В случае возникновения ошибки возвращается `nil`.

## Список параметров

Параметры отсутствуют.

## Возвращаемые значения

Возвращает `ValuedText` | `nil` - подсказку по прокачке души с указанием активностей и награды, или `nil` в случае ошибки.

## Примеры

### Получение подсказки по прокачке
```lua
local tip = soulProgressLib.GetTipProgressGain()
```
