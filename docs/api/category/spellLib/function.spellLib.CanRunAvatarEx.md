# spellLib.CanRunAvatarEx

Определяет возможность запуска заклинания, учитывая только неизменяемые свойства главного игрока (расу, пол, фракцию и класс).

## Описание

```lua
spellLib.CanRunAvatarEx( id: SpellId ): boolean
```

Функция возвращает логическое значение, указывающее на возможность запуска заклинания, игнорируя все изменяемые состояния и учитывая только неизменяемые свойства главного игрока (расу, пол, фракцию и класс).

## Список параметров

- **`id`** (`SpellId`) - Уникальный идентификатор умения (заклинания).

## Возвращаемые значения

Возвращает `boolean` - `true`, если запуск заклинания возможен с учетом неизменяемых свойств главного игрока, и `false` в противном случае.

## Примеры

### Проверка возможности запуска заклинания

```lua
local spellbook = avatar.GetSpellBook()
self:Activate( spellLib.CanRunAvatarEx( spellbook[1] ) )
```

::: info Описание примера
В примере сначала извлекается книга заклинаний главного игрока с помощью функции `avatar.GetSpellBook`. Затем проверяется возможность запуска первого заклинания из списка через `spellLib.CanRunAvatarEx`, и результат передается в метод `self:Activate`.
:::
