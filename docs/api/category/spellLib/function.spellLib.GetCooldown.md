# spellLib.GetCooldown

Возвращает информацию о таймерах повторного использования заклинания по его идентификатору.

## Описание

```lua
spellLib.GetCooldown( id: SpellId ): table | nil
```

Функция извлекает и возвращает таблицу с информацией о таймерах повторного использования заклинания. Если умение с указанным идентификатором отсутствует, возвращается `nil`.

## Список параметров

- **`id`** (`SpellId`) - Уникальный идентификатор умения.

## Возвращаемые значения

Возвращает `table` | `nil`.

Если умение найдено, возвращается таблица со следующими полями:

- **`durationMs`** (`number`) - Общее время до повторного использования заклинания в миллисекундах.

- **`remainingMs`** (`number`) - Оставшееся время до повторного использования заклинания в миллисекундах.

- **`ignoreGlobalCooldown`** (`boolean`) - Флаг, указывающий, что заклинание игнорирует глобальное время восстановления и может быть применено при активном ГКД.

- **`debugName`** (`string` | `nil`) - Системная информация для отладочной версии, содержащая путь к файлу. Отсутствует в финальной версии клиента.

или `nil`, если умение с указанным идентификатором отсутствует.

## Примеры

### Получение оставшегося времени восстановления заклинания

```lua
local spellbook = avatar.GetSpellBook()
local spellInfo = spellLib.GetCooldown( spellbook[1] )
common.LogInfo( spellInfo.remainingMs )
```

::: info Описание примера
В примере сначала получается список заклинаний из книги заклинаний персонажа с помощью `avatar.GetSpellBook()`. Затем для первого заклинания в списке запрашивается информация о времени восстановления через `spellLib.GetCooldown()`. Полученное оставшееся время выводится в информационный лог.
:::
