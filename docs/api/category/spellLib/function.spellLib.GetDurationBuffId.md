# spellLib.GetDurationBuffId

Возвращает идентификатор специального баффа, связанного с умением.

## Описание

```lua
spellLib.GetDurationBuffId( spellId: SpellId ): BuffId | nil
```

Функция извлекает идентификатор специального баффа, связанного с умением, оставшееся время действия которого отображается на иконке в панели действий (например, время жизни механизмов инженера).

## Список параметров

- **`spellId`** (`SpellId`) - Идентификатор умения.

## Возвращаемые значения

Возвращает `BuffId` | `nil` - Идентификатор баффа, если такой бафф присутствует у умения.

## Примеры

### Получение идентификатора баффа

```lua
local durationBuff = spellLib.GetDurationBuffId( spellId )
```
