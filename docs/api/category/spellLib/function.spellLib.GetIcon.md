# spellLib.GetIcon
Возвращает идентификатор текстуры иконки заклинания по его идентификатору.

## Описание

```lua
spellLib.GetIcon( id: SpellId ): TextureId | nil
```

Функция возвращает идентификатор текстуры иконки заклинания по заданному идентификатору умения.

## Список параметров

- **`id`** (`SpellId`) - Уникальный идентификатор заклинания (умения).

## Возвращаемые значения

Возвращает `TextureId` | `nil` - Идентификатор текстуры иконки заклинания.

## Примеры

### Получение и установка иконки заклинания
```lua
local spellbook = avatar.GetSpellBook()
local icon = spellLib.GetIcon( spellbook[1] )
self.wtIcon:SetBackgroundTexture( icon )
```

::: info Описание примера
В примере сначала извлекается книга заклинаний персонажа. Затем для первого заклинания из книги получается идентификатор его иконки, который устанавливается в качестве фоновой текстуры для UI-элемента `wtIcon`.
:::
