# spellLib.GetObjectSpell
Возвращает `SpellId` умения по идентификатору объекта умения, имеющегося в спеллбуке.

## Описание
```lua
spellLib.GetObjectSpell( objectId: ObjectId ): SpellId
```
Функция извлекает и возвращает идентификатор умения по идентификатору объекта умения, имеющегося в спеллбуке. Возвращаемое умение доступно для использования, а не только для получения описания. Для используемых умений назначается идентификатор объекта умения, который также выступает в роли action Id.

## Список параметров
- **`objectId`** (`ObjectId`) - Идентификатор объекта умения.

## Возвращаемые значения
Возвращает `SpellId` - Идентификатор умения.

## Примеры
### Получение и использование идентификатора умения
```lua
local spellId = spellLib.GetObjectSpell( actionId )
common.LogInfo( spellLib.GetDescription( spellId ).name )
```

::: info Описание примера
В примере извлекается идентификатор умения по идентификатору его объекта. Затем с помощью полученного идентификатора запрашивается описание умения, из которого выводится название.
:::
