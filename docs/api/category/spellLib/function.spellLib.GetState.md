# spellLib.GetState

Возвращает информацию о динамическом состоянии заклинания по его идентификатору.

## Описание

```lua
spellLib.GetState( id: SpellId ): table|nil
```

Функция возвращает информацию о динамическом состоянии заклинания по его идентификатору.

## Список параметров

- **`id`** (`SpellId`) - Идентификатор умения.

## Возвращаемые значения

Возвращает `table` | `nil` - таблица с информацией о состоянии заклинания, если действие в слоте есть, или `nil`, если такого умения нет.

- **`enabled`** (`boolean`) - если `false`, то заклинание не удастся применить, но его можно попытаться использовать.

- **`autocastOn`** (`boolean`) - автоматическая подготовка заклинания, `true` - включена, `false` - выключена.

- **`prepared`** (`boolean`) - `true`, если заклинание приготовлено. `false`, если не приготовлено, или подготовка вообще не требуется (`launchWhenReady == true`).

- **`isActive`** (`boolean`) - `true`, если в данный момент заклинание активировано (включено).

- **`debugName`** (`string` | `nil`) - системная информация для отладочной версии (путь к файлу), отсутствует в FinalRelease версии клиента.

## Примеры

### Получение состояния заклинания из книги умений

```lua
local spellbook = avatar.GetSpellBook()
local spellState = spellLib.GetState( spellbook[1] )
self.wtActive:Toggle( spellState.enabled )
```

::: info Описание примера
Извлекается книга умений персонажа, после чего запрашивается состояние первого заклинания из списка. Полученное значение флага доступности передается в метод переключения состояния элемента интерфейса.
:::
