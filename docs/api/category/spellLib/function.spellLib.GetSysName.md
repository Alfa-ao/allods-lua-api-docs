# spellLib.GetSysName

Возвращает системное имя заклинания по его идентификатору.

## Описание

```lua
spellLib.GetSysName( id: SpellId ): string
```

Функция извлекает и возвращает системное имя заклинания по заданному идентификатору.

## Список параметров

- **`id`** (`SpellId`) - Идентификатор умения.

## Возвращаемые значения

Возвращает `string` - системное имя заклинания.

## Примеры

### Получение системного имени заклинания

```lua
local spellbook = avatar.GetSpellBook()
LogInfo( spellLib.GetSysName( spellbook[ 1 ] ) )
```

::: info Описание примера
В примере сначала запрашивается книга заклинаний текущего персонажа. Затем из полученного списка извлекается идентификатор первого заклинания, который передается в функцию для получения его системного имени. Результат выводится в информационный лог.
:::
