# transport.CanDrawInterface
Определяет необходимость отрисовки интерфейса выбранного корабля.

## Описание

```lua
transport.CanDrawInterface( transportId: ObjectId ): boolean
```

Функция возвращает признак необходимости отрисовки интерфейса выбранного корабля. Интерфейс отрисовывается для боевых кораблей, которыми могут управлять игроки. Для транспортных средств без управления (плот, лодка или скриптовый корабль), двигающихся по заданному маршруту, возвращается `false`. Данный флаг выставляется в ресурсе корабля.

## Список параметров

- **`transportId`** (`ObjectId`) - Уникальный идентификатор транспортного средства.

## Возвращаемые значения

Возвращает `boolean` - `true`, если кораблем можно управлять и требуется отображение интерфейса корабля.

## Примеры

### Проверка необходимости отрисовки интерфейса
```lua
local transportId = unit.GetTransport( avatar.GetId() )
if transportId then
    if transport.CanDrawInterface( transportId ) then
        LogInfo( "show interface!!!" )
    end
end
```

::: info Описание примера
В примере запрашивается идентификатор транспортного средства текущего аватара. Если идентификатор получен, проверяется необходимость отрисовки интерфейса с помощью `transport.CanDrawInterface`. При положительном результате в лог выводится соответствующее сообщение.
:::
