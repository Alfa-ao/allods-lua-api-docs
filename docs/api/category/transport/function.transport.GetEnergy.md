# transport.GetEnergy

Возвращает информацию об энергии транспортного средства.

## Описание

```lua
transport.GetEnergy( transportId: ObjectId ): table
```

Функция извлекает и возвращает таблицу с данными об энергии указанного транспортного средства. Если транспортное средство не найдено, функция генерирует исключение и возвращает таблицу с нулевыми значениями полей.

## Список параметров

- **`transportId`** (`ObjectId`) - Уникальный идентификатор транспортного средства.

## Возвращаемые значения

Возвращает `table` - таблица информации об энергии, содержащая следующие поля:

- **`value`** (`number`) - Текущее значение энергии.

- **`limit`** (`number`) - Значение предела энергии.

- **`changeRate`** (`number`) - Скорость изменения нагрева. Если значение больше 0, происходит нагрев, иначе - остывание.

## Примеры

### Получение текущей энергии транспорта

```lua
local transportId = unit.GetTransport( avatar.GetId() )
if transportId then
    local energy = transport.GetEnergy( transportId )
    local value = energy.value
end
```

::: info Описание примера
В примере сначала извлекается идентификатор транспортного средства, на котором находится главный персонаж. Если идентификатор успешно получен, запрашивается информация об энергии и извлекается ее текущее значение.
:::
