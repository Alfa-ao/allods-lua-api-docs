# transport.GetHealthMaximum

Возвращает максимально возможное значение здоровья для имеющегося корпуса.

## Описание

```lua
transport.GetHealthMaximum( transportId: ObjectId ): number
```

Функция возвращает максимально возможное значение здоровья для имеющегося корпуса транспортного средства. Если транспортное средство не найдено, генерируется исключение и возвращается ноль.

## Список параметров

- **`transportId`** (`ObjectId`) - Идентификатор транспортного средства.

## Возвращаемые значения

Возвращает `number` - максимально возможное значение здоровья для имеющегося корпуса.

## Примеры

### Получение максимального значения здоровья транспорта

```lua
local healthMaximum = transport.GetHealthMaximum( transportId )
```
