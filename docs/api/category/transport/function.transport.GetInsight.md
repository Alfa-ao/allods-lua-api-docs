# transport.GetInsight
Возвращает информацию о количестве эманации транспортного средства.

## Описание

```lua
transport.GetInsight( transportId: ObjectId ): number
```
Возвращение информации о количестве эманации транспортного средства. Эманация представляет собой ресурс, расходуемый на астральную навигацию. При отсутствии транспорта генерируется исключение и возвращается нулевое значение. Если аватар не относится к команде транспорта, также возвращается нулевое значение.

## Список параметров

- **`transportId`** (`ObjectId`) - Идентификатор транспортного средства.

## Возвращаемые значения

Возвращает `number` - значение инсайта.

## Примеры

### Получение количества эманации транспорта
```lua
local transportId = unit.GetTransport( avatar.GetId() )
if transportId then
    local insight = transport.GetInsight( transportId )
end
```

::: info Описание примера
Сначала получается идентификатор транспортного средства текущего аватара. Если идентификатор успешно получен, выполняется запрос количества эманации для данного транспорта.
:::
