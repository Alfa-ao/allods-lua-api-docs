# transport.GetMass

Возвращает массу транспортного средства без устройств.

## Описание

```lua
transport.GetMass( transportId: ObjectId ): number | nil
```

Функция возвращает массу транспортного средства без устройств. Если транспорт не найден, бросает исключение и возвращает `nil`.

## Список параметров

- **`transportId`** (`ObjectId`) - Идентификатор транспортного средства.

## Возвращаемые значения

Возвращает `number` | `nil` - масса транспортного средства без устройств. Если транспорт не найден, возвращает `nil`.

## Примеры

### Получение массы транспорта персонажа

```lua
local mass = transport.GetMass( unit.GetTransport( avatar.GetId() ) )
```

::: info Описание примера
В примере последовательно вызываются функции для получения идентификатора персонажа, определения его транспортного средства и извлечения массы этого транспорта.
:::
