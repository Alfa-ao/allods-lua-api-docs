# transport.GetPosition

Возвращает информацию о координатах транспортного средства по его идентификатору.

## Описание

```lua
transport.GetPosition( id: ObjectId ): table
```

Функция извлекает и возвращает информацию о текущих координатах транспортного средства на карте.

::: warning Замечание
Если транспортное средство с указанным идентификатором не найдено, функция бросает исключение и возвращает нулевую позицию.
:::

## Список параметров

- **`id`** (`ObjectId`) - Уникальный идентификатор транспортного средства.

## Возвращаемые значения

Возвращает `table`:

- **`posX`** (`number`) - Точные координаты на карте.
- **`posY`** (`number`) - Точные координаты на карте.
- **`posZ`** (`number`) - Точные координаты на карте.

## Примеры

### Получение координат транспорта

```lua
local pos = transport.GetPosition( id )
```
