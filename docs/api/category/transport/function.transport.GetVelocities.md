# transport.GetVelocities
Возвращает информацию о скоростях перемещения транспортного средства в пространстве.

## Описание
```lua
transport.GetVelocities( transportId: ObjectId ): table
```
Функция возвращает информацию о скоростях перемещения транспортного средства в пространстве. Если транспорт не найден, то функция бросает исключение и возвращает таблицу с нулевыми значениями.

## Список параметров

- **`transportId`** (`ObjectId`) - Уникальный идентификатор транспортного средства (не может быть `nil`).

## Возвращаемые значения

Возвращает `table` - Таблица информации о скоростях:

- **`horizontal`** (`number`) - Скорость перемещения по горизонтали (всегда > 0 - вперед).

- **`vertical`** (`number`) - Скорость перемещения по вертикали (> 0 - вверх).

- **`angular`** (`number`) - Скорость поворота (> 0 - против часовой стрелки).

## Примеры
### Получение горизонтальной скорости транспорта
```lua
local transportId = unit.GetTransport( avatar.GetId() )
if transportId then
    local velocities = transport.GetVelocities( transportId )
    if velocities then
        local speed = velocities.horizontal
    end
end
```

::: info Описание примера
В примере сначала получается идентификатор транспортного средства, на котором находится главный персонаж. Если идентификатор успешно получен, запрашивается информация о скоростях. При успешном получении таблицы скоростей извлекается значение горизонтальной скорости.
:::
