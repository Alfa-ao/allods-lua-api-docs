# unit.GetMana

Возвращает информацию о мане персонажа.

## Описание

::: danger VERSION: [<Badge type="warning" text="17.0.01.43" />](/index.md#17.0.0-UNIT_MANA)

Функция удалена.

```lua
unit.GetMana( unitId: ObjectId ): table | nil
```
:::

Если значения каких-то параметров неизвестны, возвращается `nil`.

## Список параметров

- **`unitId`** (`ObjectId`) - Идентификатор юнита.

## Возвращаемые значения

Возвращает `table` | `nil` - информация о мане:

- **`mana`** (`number` | `nil`) - Текущая мана юнита для дружественных целей (аватар, группа), в остальных случаях возвращается `nil`.

- **`maxMana`** (`number` | `nil`) - Максимальная мана юнита для дружественных целей (аватар, группа), в остальных случаях возвращается `nil`.

- **`percents`** (`number` | `nil`) - Процент текущей маны от максимальной.
