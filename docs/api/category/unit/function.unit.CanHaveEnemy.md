# unit.CanHaveEnemy
Возвращает признак возможности наличия врагов у юнита.

## Описание
```lua
unit.CanHaveEnemy( unitId: ObjectId ): boolean
```
Функция возвращает логическое значение, определяющее возможность наличия врагов у указанного юнита.

## Список параметров
- **`unitId`** (`ObjectId`) - Идентификатор юнита.

## Возвращаемые значения
Возвращает `boolean` - `true`, если юнит может иметь врагов.

## Примеры
### Получение признака наличия врагов
```lua
local canHaveEnemy = unit.CanHaveEnemy( unitId )
```
