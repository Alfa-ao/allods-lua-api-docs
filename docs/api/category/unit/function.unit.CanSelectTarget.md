# unit.CanSelectTarget

Проверяет возможность выделения указанного существа в цель главного игрока.

## Описание

```lua
unit.CanSelectTarget( unitId: ObjectId ): boolean
```

Функция возвращает логическое значение, указывающее на возможность выделения существа в цель. Запрет выделения может быть обусловлен, например, нахождением существа в другом плане. Если указанный юнит не существует, фиксируется ошибка в логе.

## Список параметров

- **`unitId`** (`ObjectId`) - Идентификатор юнита.

## Возвращаемые значения

Возвращает `boolean` - `true`, если юнит существует и его можно выделить в цель, иначе `false`. Если юнит не существует, логируется ошибка.

## Примеры

### Проверка возможности выделения цели

```lua
if not unit.CanSelectTarget( unitId ) then
    LogInfo( "цель невидима" )
end
```
