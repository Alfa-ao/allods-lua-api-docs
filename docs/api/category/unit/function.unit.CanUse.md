# unit.CanUse

Проверяет возможность взаимодействия с юнитом в текущий момент.

## Описание

```lua
unit.CanUse( unitId: ObjectId ): boolean
```

Функция выполняет проверку доступности юнита для взаимодействия, например, для разговора или лута из трупов мобов.

## Список параметров

- **`unitId`** (`ObjectId`) - Уникальный идентификатор юнита.

## Возвращаемые значения

Возвращает `boolean` - `true`, если с юнитом можно взаимодействовать в текущий момент, и `false` в противном случае.

## Примеры

### Проверка возможности использования юнита

```lua
local canUse = unit.CanUse( unitId )
```
