# unit.GetActivePet

Возвращает идентификатор активного пета персонажа, если персонаж является активным игроком или членом его группы.

## Описание

```lua
unit.GetActivePet( unitId: ObjectId ): ObjectId | nil
```

Функция возвращает идентификатор пета указанного юнита. Результат доступен только в случае, если юнит является активным игроком или членом его группы. Если пет отсутствует или юнит не соответствует указанным условиям, возвращается `nil`.

## Список параметров

- **`unitId`** (`ObjectId`) - Идентификатор юнита.

## Возвращаемые значения

Возвращает `ObjectId` | `nil` - идентификатор пета, если он существует (только для активного игрока или члена его группы), или `nil` в противном случае.

## Примеры

### Получение идентификатора пета

```lua
local petId = unit.GetActivePet( unitId )
if petId then
    local petName = object.GetName( petId )
end
```

::: info Описание примера
Выполняется запрос идентификатора активного пета для указанного юнита. Если пет существует (возвращаемое значение не равно `nil`), извлекается его имя с помощью функции `object.GetName`.
:::
