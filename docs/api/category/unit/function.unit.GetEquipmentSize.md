# unit.GetEquipmentSize
Возвращает количество слотов под экипировку у данного юнита.

## Описание
```lua
unit.GetEquipmentSize( unitId: ObjectId ): number
```
Функция извлекает и возвращает количество слотов под экипировку у заданного юнита. Юнит может являться главным игроком или игроком, инспектируемым в данный момент.

## Список параметров
- **`unitId`** (`ObjectId`) - Идентификатор юнита.

## Возвращаемые значения
Возвращает `number` - число слотов под экипировку юнита.

## Примеры
### Получение количества слотов экипировки
```lua
local size = unit.GetEquipmentSize( unitId )
```
