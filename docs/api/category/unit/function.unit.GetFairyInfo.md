# unit.GetFairyInfo

Возвращает информацию о покровителе.

## Описание

```lua
unit.GetFairyInfo( unitId: ObjectId ): table | nil
```

Функция извлекает информацию о покровителе. Наличие покровителя определяется по значению флага `isExist` возвращаемой таблицы.

## Список параметров

- **`unitId`** (`ObjectId`) - Идентификатор юнита.

## Возвращаемые значения

Возвращает `table` | `nil` - Если информация найдена, возвращается таблица со следующими полями:

- **`isExist`** (`boolean`) - `true`, если у игрока есть покровитель.

- **`name`** (`WString`) - Имя покровителя.

- **`description`** (`WString`) - Описание покровителя.

- **`rank`** (`number`) - Ранг покровителя.

- **`level`** (`number`) - Уровень покровителя.

- **`experience`** (`number`) - Опыт покровителя.

- **`levelExperience`** (`number`) - Опыт покровителя, необходимый для достижения этого уровня.

- **`nextLevelExperience`** (`number`) - Опыт покровителя, необходимый для достижения следующего уровня.

- **`isHungry`** (`boolean`) - Благосклонен ли покровитель.

- **`remainingMs`** (`number` | `nil`) - Время в миллисекундах, которое покровитель будет благосклонен. `nil` - в случае отсутствия благосклонности.

- **`isAlwaysActive`** (`boolean`) - Если `true`, то покровитель благосклонен всегда, независимо от значений `isHungry` и `remainingMs`.

- **`currentRankRemainingMs`** (`number` | `nil`) - Время в миллисекундах, которое у покровителя будет текущий ранг (временно хало 5-го уровня). `nil` - ранг навсегда.

- **`dpsBonus`** (`number`) - Во сколько раз увеличивается наносимый игроком урон.

- **`healBonus`** (`number`) - Во сколько раз увеличивается способность игрока лечить.

- **`powerBonus`** (`number`) - Значение бонуса для характеристики "Могущество".

## Примеры

### Получение значения бонуса к могуществу

```lua
local info = unit.GetFairyInfo( unitId )
if info then
    local powerBonus = info.powerBonus
end
```
