# unit.GetFairyZodiacSignInfo

Возвращает информацию о знаке зодиака покровителя указанного юнита.

## Описание

```lua
unit.GetFairyZodiacSignInfo( unitId: ObjectId ): table | nil
```

Функция извлекает и возвращает таблицу с информацией о знаке зодиака покровителя указанного юнита. Возвращаемые данные включают системное имя, отображаемое имя, описание знака зодиака, а также идентификатор текстуры иконки. Если информация о знаке зодиака не найдена, функция возвращает `nil`.

::: warning Замечание
Поле `image` доступно только в UI-реализации функции (UIState). В логической реализации (GameState) данное поле отсутствует в возвращаемой таблице.
:::

## Список параметров

- **`unitId`** (`ObjectId`) - Идентификатор юнита, информацию о знаке зодиака покровителя которого необходимо получить.

## Возвращаемые значения

Возвращает `table` | `nil` - таблицу с информацией о знаке зодиака покровителя юнита, или `nil`, если информация не найдена.

- **`sysName`** (`string`) - Уникальное системное имя знака зодиака.

- **`name`** (`WString`) - Имя знака зодиака.

- **`description`** (`WString`) - Описание знака зодиака.

- **`image`** (`TextureId`) - Идентификатор текстуры для иконки (только в UI-реализации).

## Примеры

### Получение имени знака зодиака покровителя

```lua
local info = unit.GetFairyZodiacSignInfo( unitId )
if info then
    LogInfo( info.name )
end
```
