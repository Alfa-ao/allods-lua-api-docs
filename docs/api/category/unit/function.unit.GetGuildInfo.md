# unit.GetGuildInfo

Возвращает информацию о гильдии игрока.

## Описание

```lua
unit.GetGuildInfo( unitId: ObjectId ): table | nil
```

Функция извлекает и возвращает таблицу с информацией о гильдии, в которой состоит указанный игрок. Если игрок не состоит в гильдии или информация недоступна, функция возвращает `nil`.

## Список параметров

- **`unitId`** (`ObjectId`) - уникальный идентификатор игрока.

## Возвращаемые значения

Возвращает `table` | `nil` - информация о гильдии, если персонаж состоит в ней, или `nil` в противном случае.

- **`name`** (`WString`) - имя гильдии игрока (пустая строка, если игрок не состоит в гильдии).

- **`rank`** (`number` | `nil`) - ранг игрока в гильдии, если он состоит в гильдии.

- **`level`** (`number` | `nil`) - уровень гильдии, если игрок состоит в гильдии.

- **`guildId`** (`number`) - идентификатор гильдии, если игрок состоит в гильдии.

## Примеры

### Получение имени гильдии

```lua
local guildInfo = unit.GetGuildInfo( unitId )
local name = guildInfo and guildInfo.name
```
