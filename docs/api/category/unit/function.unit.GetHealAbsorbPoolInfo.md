# unit.GetHealAbsorbPoolInfo

Возвращает информацию о пуле поглощения лечения (анти-хила) юнита, или `nil`, если пул отсутствует.

## Описание

```lua
unit.GetHealAbsorbPoolInfo( unitId: ObjectId ): table | nil
```

Функция извлекает и возвращает структуру данных, содержащую информацию о текущем состоянии пула поглощения лечения для указанного юнита.

## Список параметров

- **`unitId`** (`ObjectId`) - Идентификатор юнита.

## Возвращаемые значения

Возвращает `table` | `nil` - Таблица с информацией о пуле поглощения лечения или `nil`, если пул отсутствует.

- **`healAbsorbValue`** (`number`) - Текущее значение пула поглощения лечения юнита.

- **`healAbsorbLimit`** (`number`) - Максимальное значение пула поглощения лечения юнита.

- **`healAbsorbFactor`** (`number`) - Коэффициент поглощения лечения, определяющий часть лечения, не применяемую к юниту.

## Примеры

### Получение информации о пуле поглощения лечения

```lua
local poolInfo = unit.GetHealAbsorbPoolInfo( unitId )
```
