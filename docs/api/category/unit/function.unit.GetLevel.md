# unit.GetLevel

Возвращает текущий уровень юнита.

## Описание

```lua
unit.GetLevel( unitId: ObjectId ): number
```

Функция возвращает текущий уровень указанного юнита.

## Список параметров

- **`unitId`** (`ObjectId`) - Идентификатор юнита.

## Возвращаемые значения

Возвращает `number` - Текущий уровень юнита.

## Примеры

### Получение уровня юнита

```lua
local level = unit.GetLevel( unitId )
```
