# unit.GetMoodEmoteId

Возвращает идентификатор эмоции, с помощью которой выставлено настроение указанного игрока.

## Описание

```lua
unit.GetMoodEmoteId( unitId: ObjectId ): ObjectId | nil
```

Функция возвращает идентификатор эмоции, если у указанного игрока выставлено какое-либо настроение.

## Список параметров

- **`unitId`** (`ObjectId`) - Идентификатор игрока, для которого необходимо получить эмоцию настроения.

## Возвращаемые значения

Возвращает `ObjectId` | `nil` - Идентификатор эмоции, если у игрока есть какое-либо настроение, или `nil`, если настроение отсутствует.

## Примеры

### Получение и вывод системного имени эмоции

```lua
local emoteId = unit.GetMoodEmoteId( unitId )
local emoteInfo = avatar.GetEmoteInfo( emoteId )
if emoteInfo then
    common.LogInfo( "Emote system name: " .. emoteInfo.sysName )
end
```

::: info Описание примера
В примере сначала запрашивается идентификатор эмоции настроения игрока. Затем по полученному идентификатору извлекается полная информация об эмоции. Если информация успешно получена, в лог выводится системное имя эмоции.
:::
