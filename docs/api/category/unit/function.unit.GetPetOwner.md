# unit.GetPetOwner
Возвращает идентификатор владельца пета.

## Описание

```lua
unit.GetPetOwner( unitId: ObjectId ): ObjectId | nil
```

Функция извлекает и возвращает идентификатор владельца указанного пета. Если владелец не найден, возвращается `nil`.

## Список параметров

- **`unitId`** (`ObjectId`) - Уникальный идентификатор пета.

## Возвращаемые значения

Возвращает `ObjectId` | `nil` - Идентификатор владельца пета, если он найден; в противном случае `nil`.

## Примеры

### Проверка и получение владельца пета
```lua
if unit.IsPet( unitId ) then
    local petOwnerId = unit.GetPetOwner( unitId )
end
```

::: info Описание примера
В примере сначала проверяется, является ли указанный юнит петом с помощью функции `unit.IsPet`. Если проверка успешна, извлекается идентификатор его владельца через `unit.GetPetOwner`.
:::
