# unit.GetPlayerSoulLevel

Возвращает уровень души `искры` указанного игрока.

## Описание

```lua
unit.GetPlayerSoulLevel( playerId: ObjectId ): number | nil
```

Функция возвращает уровень искры для заданного идентификатора игрока.

## Список параметров

- **`playerId`** `(ObjectId)` - Идентификатор игрока, для которого необходимо получить уровень искры.

## Возвращаемые значения

Возвращает `number` - уровень искры игрока, или `nil`, если данные недоступны.

## Примеры

### Получить уровень искры аватара

```lua
local soulLevel = unit.GetPlayerSoulLevel( avatar.GetId() )
```
