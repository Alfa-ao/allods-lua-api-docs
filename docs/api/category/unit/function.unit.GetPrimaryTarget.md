# unit.GetPrimaryTarget

Возвращает информацию об основной цели юнита.

## Описание

```lua
unit.GetPrimaryTarget( unitId: ObjectId ): ObjectId | nil
```

Функция возвращает идентификатор основной цели указанного юнита. Если у юнита отсутствует цель, возвращается `nil`.

## Список параметров

- **`unitId`** (`ObjectId`) - Идентификатор юнита.

## Возвращаемые значения

Возвращает `ObjectId` | `nil` - идентификатор цели, или `nil`, если цели нет.

## Примеры

### Получение основной цели юнита

```lua
local id = unit.GetPrimaryTarget( unitId )
```
