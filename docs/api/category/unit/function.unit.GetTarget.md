# unit.GetTarget

Возвращает идентификатор цели юнита, используя дополнительную цель для аватара и основную для остальных.

## Описание

```lua
unit.GetTarget( unitId: ObjectId ): ObjectId | nil
```

Функция извлекает и возвращает идентификатор цели юнита. Для аватара используется дополнительная цель, а для всех остальных юнитов - основная.

## Список параметров

- **`unitId`** (`ObjectId`) - Идентификатор юнита.

## Возвращаемые значения

Возвращает `ObjectId` | `nil` - Идентификатор цели или `nil`, если цели нет.

## Примеры

### Получение идентификатора цели

```lua
local id = unit.GetTarget( unitId )
```
