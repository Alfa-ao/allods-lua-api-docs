# unit.GetTitle

Возвращает титул юнита.

## Описание

```lua
unit.GetTitle( unitId: ObjectId ): WString
```

Функция возвращает титул юнита.

::: warning Замечание
Реализовано только для мобов.
:::

## Список параметров

- **`unitId`** (`ObjectId`) - Идентификатор юнита.

## Возвращаемые значения

Возвращает `WString` - имя юнита (пустая строка, если имя не определено).

## Примеры

### Получение титула юнита

```lua
local title = unit.GetTitle( unitId )
```
