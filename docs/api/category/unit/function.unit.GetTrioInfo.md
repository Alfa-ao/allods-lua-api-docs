# unit.GetTrioInfo
Возвращает дополнительную информацию о персонажах игрока для трио (гибберлинги).

## Описание

```lua
unit.GetTrioInfo( unitId: ObjectId ): table | nil
```

Функция возвращает таблицу с именами персонажей, входящих в трио (гибберлинги). Если персонаж не является трио, возвращается `nil`.

::: warning Замечание
Функция работает только для игроков.
:::

## Список параметров

- **`unitId`** (`ObjectId`) - Идентификатор игрока.

## Возвращаемые значения

Возвращает `table` | `nil`.

Если игрок является трио, возвращается таблица со следующими полями:

- **`name2`** (`WString`) - Имя второго персонажа.

- **`name3`** (`WString`) - Имя третьего персонажа.

## Примеры

### Получение информации о трио

```lua
if object.IsPlayer( unitId ) then
    local trio = unit.GetTrioInfo( unitId )
    if trio then
        LogInfo( "trio 2: ", userMods.FromWString( trio.name2 ), ", trio 3: ", userMods.FromWString( trio.name3 ) )
    end
end
```

::: info Описание примера
Проверяется, является ли указанный идентификатор игроком. Если да, запрашивается информация о трио. При успешном получении данных в лог выводятся имена второго и третьего персонажей с предварительным преобразованием из `WString`.
:::
