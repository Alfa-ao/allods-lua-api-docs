# unit.GetVeteranRank
Возвращает информацию о ветеранском ранге игрока.

## Описание

```lua
unit.GetVeteranRank( unitId: ObjectId ): table | nil
```

Функция извлекает и возвращает информацию о ветеранском ранге игрока. Вызов функции допускается только для игроков.

::: warning Замечание
Функция может быть вызвана только для игроков.
:::

## Список параметров

- **`unitId`** (`ObjectId`) - Уникальный идентификатор игрока.

## Возвращаемые значения

Возвращает `table` | `nil`.

- **`name`** (`WString`) - Название ветеранского ранга.

- **`description`** (`WString`) - Описание ранга.

- **`image`** (`TextureId` | `nil`) - Идентификатор текстуры иконки ранга. Поле реализовано исключительно в UI.

## Примеры

### Получение названия ветеранского ранга

```lua
local info = unit.GetVeteranRank( unitId )
if info then
    local name = info.name
end
```
