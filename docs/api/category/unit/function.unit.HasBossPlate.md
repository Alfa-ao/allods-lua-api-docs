# unit.HasBossPlate

Определяет необходимость показа особой плашки с внутренним состоянием моба.

## Описание

```lua
unit.HasBossPlate( unitId: ObjectId ): boolean
```

Функция возвращает логическое значение, указывающее на необходимость показа особой плашки с внутренним состоянием моба.

## Список параметров

- **`unitId`** (`ObjectId`) - Идентификатор юнита.

## Возвращаемые значения

Возвращает `boolean` - `true`, если показ плашки требуется.

## Примеры

### Проверка состояния моба

```lua
if unit.HasBossPlate( unitId ) then
    LogInfo( "Это особый моб" )
end
```
