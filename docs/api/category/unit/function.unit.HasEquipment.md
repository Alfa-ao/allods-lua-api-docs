# unit.HasEquipment

Возвращает информацию о наличии экипировки у данного юнита.

## Описание

```lua
unit.HasEquipment( unitId: ObjectId ): boolean
```

Функция возвращает информацию о наличии экипировки у заданного юнита. Юнит может являться главным игроком или игроком, инспектируемым в данный момент.

## Список параметров

- **`unitId`** (`ObjectId`) - Идентификатор юнита.

## Возвращаемые значения

Возвращает `boolean` - наличие экипировки.

## Примеры

### Проверка наличия экипировки

```lua
local hasEquipment = unit.HasEquipment( unitId )
```
