# unit.IsAggressive

Определяет, является ли юнит агрессивным по отношению к главному игроку.

## Описание

```lua
unit.IsAggressive( unitId: ObjectId ): boolean
```

Функция проверяет статус агрессии указанного юнита по отношению к главному игроку.

## Список параметров

- **`unitId`** (`ObjectId`) - Идентификатор юнита.

## Возвращаемые значения

Возвращает `boolean` - `true`, если юнит агрессивен по отношению к главному игроку.

## Примеры

### Проверка агрессивности юнита

```lua
local isAggressive = unit.IsAggressive( unitId )
```
