# unit.IsAvatarRelated

Определяет, связан ли объект с аватаром.

[<Badge type="warning" text="17.0.01.43" />](/index.md#17.0.0-unit.IsAvatarRelated)

## Описание

```lua
unit.IsAvatarRelated( objectId: ObjectId ): boolean
```

Идентификатор обязан быть валидным идентификатором, но не обязан быть валидным идентификатором объекта. При передаче невалидного идентификатора объекта, например идентификатора экземпляра бафа, функция возвращает `false` без ошибок. Если функция возвращает `true`, гарантируется, что был передан идентификатор валидного юнита.

## Список параметров

- **`objectId`** (`ObjectId`) - Идентификатор объекта.

## Возвращаемые значения

Возвращает `boolean` - `true`, если объект связан с аватаром (он сам, ассистент, наемник, пет и т.п.), `false` в противном случае. Если возвращено `true`, гарантируется, что передан идентификатор валидного юнита.

## Примеры

### Проверка связи с аватаром

```lua
local isRelated = unit.IsAvatarRelated( objectId )

if isRelated then
    LogInfo( "Объект связан с аватаром" )
end
```
