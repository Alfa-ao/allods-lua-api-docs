# unit.IsFatalityDeath

Возвращает признак того, что юнит мёртв и на нём проигрывается фаталити.

## Описание

```lua
unit.IsFatalityDeath( unitId: ObjectId ): boolean
```

Функция возвращает логическое значение, указывающее на то, что юнит мёртв и на нём проигрывается фаталити.

## Список параметров

- **`unitId`** (`ObjectId`) - Идентификатор юнита.

## Возвращаемые значения

Возвращает `boolean` - `true`, если юнит мёртв и на нём будет проигрываться фаталити.

## Примеры

### Проверка статуса фаталити

```lua
local isFatalityDeath = unit.IsFatalityDeath( unitId )
```
