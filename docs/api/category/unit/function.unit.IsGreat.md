# unit.IsGreat

Определяет, является ли указанный игрок Великим.

## Описание

```lua
unit.IsGreat( unitId: ObjectId ): boolean
```

Функция возвращает `true`, если указанный игрок является Великим. Функция применяется только для игроков.

## Список параметров

- **`unitId`** (`ObjectId`) - Идентификатор юнита.

## Возвращаемые значения

Возвращает `boolean` - `true`, если указанный игрок является Великим.

## Примеры

### Базовый вызов

```lua
local isGreat = unit.IsGreat( unitId )
```
