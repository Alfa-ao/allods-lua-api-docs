# unit.IsUsable

Возвращает возможность принципиального использования юнита.

## Описание

```lua
unit.IsUsable( unitId: ObjectId ): boolean
```

Функция возвращает возможность принципиального использования юнита. Применяется только для лута мертвых мобов.

## Список параметров

- **`unitId`** (`ObjectId`) - Идентификатор юнита.

## Возвращаемые значения

Возвращает `boolean` - возможность принципиального использования юнита.

## Примеры

### Пример использования

```lua
local isUsable = unit.IsUsable( unitId )
```
