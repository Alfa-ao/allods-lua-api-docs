# wheelOfLoot.GetList

Возвращает список идентификаторов колёс лута для разрола.

## Описание

```lua
wheelOfLoot.GetList(): table
```

Функция возвращает список идентификаторов колёс лута для разрола.

## Список параметров

Параметры отсутствуют.

## Возвращаемые значения

Возвращает `table` - идентификаторы колёс лута разролов.

## Примеры

### Получение списка идентификаторов

```lua
local wheelIds = wheelOfLoot.GetList()
```
