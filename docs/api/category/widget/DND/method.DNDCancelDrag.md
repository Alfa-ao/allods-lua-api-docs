# WidgetSafe:DNDCancelDrag

Безусловно прекращает процесс перетаскивания (drag&drop) виджета.

## Описание

```lua
WidgetSafe:DNDCancelDrag()
```

Функция выполняет безусловное прекращение процесса перетаскивания (drag&drop) по внешним причинам (например, при переходе в другой режим интерфейса). Скрипт должен самостоятельно отменить логику и визуализацию, включая удаление курсора и подсветки с окон.

::: warning Замечание
Настоятельно рекомендуется вызывать данную функцию именно в том виджете, DnD которого активно в данный момент. В текущей реализации функция может быть вызвана из любого виджета с одинаковым эффектом, однако такое поведение не гарантируется в будущем.
:::

## Список параметров

Параметры отсутствуют.

## Возвращаемые значения

Возвращаемое значение отсутствует.

## Примеры

### Отмена перетаскивания

```lua
wtPanel:DNDCancelDrag()
```
