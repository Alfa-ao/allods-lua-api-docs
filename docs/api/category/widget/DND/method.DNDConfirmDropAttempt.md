# WidgetSafe:DNDConfirmDropAttempt

Подтверждает завершение операции drag&drop.

## Описание

```lua
WidgetSafe:DNDConfirmDropAttempt()
```

Функция подтверждает окончание операции drag&drop в ответ на событие `EVENT_DND_DROP_ATTEMPT`.

::: warning Замечание
Настоятельно рекомендуется вызывать функцию именно в том виджете, DnD которого активен в данный момент. В текущей реализации функция может быть вызвана из любого виджета с одинаковым эффектом, однако такое поведение не гарантируется в будущем.
:::

## Список параметров

Параметры отсутствуют.

## Возвращаемые значения

Возвращаемое значение отсутствует.

## Примеры

### Подтверждение завершения drag&drop

```lua
wtPanel:DNDConfirmDropAttempt()
```
