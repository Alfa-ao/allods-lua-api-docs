# WidgetSafe:DNDConfirmPickAttempt

Подтверждает начало операции drag&drop.

## Описание

```lua
WidgetSafe:DNDConfirmPickAttempt()
```

Функция осуществляет подтверждение начала перетаскивания виджета в ответ на событие `EVENT_DND_PICK_ATTEMPT`, идентификатор которого передается в данном событии.

::: warning Замечание
Настоятельно рекомендуется вызывать данную функцию именно в том виджете, drag&drop которого активно в данный момент. В текущей реализации функция может быть вызвана из любого виджета с одинаковым эффектом, однако такое поведение не гарантируется в будущем.
:::

## Список параметров

Параметры отсутствуют.

## Возвращаемые значения

Возвращаемое значение отсутствует.

## Примеры

### Подтверждение начала перетаскивания

```lua
wtPanel:DNDConfirmPickAttempt()
```
