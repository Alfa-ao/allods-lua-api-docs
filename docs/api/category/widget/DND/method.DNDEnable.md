# WidgetSafe:DNDEnable

Включает или отключает обработку drag&drop для виджета без отмены регистрации в системе.

## Описание

```lua
WidgetSafe:DNDEnable( isActive: boolean )
```

Метод управляет реакцией виджета на попытки перетаскивания. Доступен для всех типов виджетов. Отключение drag&drop через данный метод является предпочтительным способом при частых изменениях состояния, поскольку отмена и повторная регистрация в системе drag&drop представляют собой ресурсоемкие операции. Метод также применяется, когда виджет не предполагается перемещать, но ему необходим DNDId для специальной обработки (например, заблокированный слот на экшн-панели должен иметь DNDId для корректной работы перетаскивания на него).

::: tip Совет
По умолчанию обработка drag&drop включена для всех зарегистрированных виджетов. Включать дополнительно после регистрации не требуется.
:::

## Список параметров

- **`isActive`** (`boolean`) - включить (`true`) или выключить (`false`) реакцию на попытку перетаскивания.

## Возвращаемые значения

Возвращаемое значение отсутствует.

## Примеры

### Отключение drag&drop для виджета

```lua
wtPanel:DNDEnable( false )
```
