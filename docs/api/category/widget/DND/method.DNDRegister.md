# WidgetSafe:DNDRegister
Регистрирует указанный виджет и уникальный идентификатор для него.

## Описание

```lua
WidgetSafe:DNDRegister( id: number, isDragOnly: boolean )
```

Правила назначения идентификаторов описаны в [общем описании DnD системы](CategoryDragAndDrop). Если требуется идентификатор (без совместного использования), генерировать его вручную не следует, необходимо использовать `DNDRegisterGeneric`. Можно указать режим начала перетаскивания (drag attempt) для данного контрола - либо только на перетаскивание, либо как на перетаскивание, так и на клик.

## Список параметров

- **`id`** (`number`) - уникальный идентификатор, связанный с виджетом wtSrc.

- **`isDragOnly`** (`boolean`) - drag&drop включается либо только на перетаскивание, либо как на перетаскивание, так и на клик.

## Возвращаемые значения

Возвращаемое значение отсутствует.

## Примеры

### Регистрация виджета

```lua
wtPanel:DNDRegister( id, false )
```
