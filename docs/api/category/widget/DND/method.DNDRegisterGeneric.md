# WidgetSafe:DNDRegisterGeneric

Зарегистрирует виджет для drag&drop с автоматическим назначением идентификатора.

## Описание

```lua
WidgetSafe:DNDRegisterGeneric( isDragOnly: boolean ): number
```

Идентификатор назначается автоматически. Если идентификатор не важен, рекомендуется использовать автоматическое назначение. При разрегистрации и повторной регистрации виджета назначается новый идентификатор. Если это неприемлемо, необходимо сохранить выданный идентификатор и использовать его при повторной регистрации через `DNDRegister`. Можно указать режим, в котором для данного контрола может начинаться перетаскивание (drag attempt) - либо только на перетаскивание, либо как на перетаскивание, так и на клик.

## Список параметров

- **`isDragOnly`** (`boolean`) - drag&drop включается либо только на перетаскивание, либо как на перетаскивание, так и на клик.

## Возвращаемые значения

Возвращает `number` - назначенный уникальный идентификатор, связанный с виджетом wtSrc.

## Примеры

### Регистрация виджета

```lua
local id = wtPanel:DNDRegisterGeneric( false )
```
