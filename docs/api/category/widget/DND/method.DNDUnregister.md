# WidgetSafe:DNDUnregister

Отменяет регистрацию виджета в системе drag&drop.

## Описание

```lua
WidgetSafe:DNDUnregister()
```

Немедленно прерывает активный процесс drag&drop виджета, если он активен. Вызывает ошибку, если виджет не зарегистрирован в системе drag&drop.

## Список параметров

Параметры отсутствуют.

## Возвращаемые значения

Возвращаемое значение отсутствует.

## Примеры

### Отмена регистрации виджета

```lua
wtPanel:DNDUnregister()
```
