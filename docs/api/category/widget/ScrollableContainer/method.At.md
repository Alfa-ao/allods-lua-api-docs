# ScrollableContainerSafe:At
Возвращает элемент прокручиваемого контейнера по указанной позиции.

## Описание

```lua
ScrollableContainerSafe:At( pos: number ): WidgetSafe | nil
```

Функция извлекает и возвращает элемент прокручиваемого контейнера, находящийся на заданной позиции. Позиции отсчитываются от 1, где первый элемент имеет позицию 1, а последний - значение, возвращаемое методом `GetElementCount()`. Если элемент на указанной позиции отсутствует, возвращается `nil`.

## Список параметров

- **`pos`** (`number`) - Позиция возвращаемого элемента. Позиции отсчитываются от 1, первый элемент имеет позицию 1, последний - `GetElementCount()`.

## Возвращаемые значения

Возвращает `WidgetSafe` | `nil` - элемент контейнера на позиции `pos` или `nil`, если такого элемента в контейнере нет.

## Примеры

### Получение элемента по индексу
```lua
local wtButton = wtScrollableContainer:At( 5 )
```
