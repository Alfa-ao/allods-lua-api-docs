# ScrollableContainerSafe:EnsureVisible

Прокручивает контейнер таким образом, чтобы указанный элемент стал видимым по возможности полностью.

## Описание

```lua
ScrollableContainerSafe:EnsureVisible( widget: WidgetSafe )
```

Осуществляет прокрутку контейнера для обеспечения видимости указанного элемента. Если элемент уже полностью видим, прокрутка не производится.

## Список параметров

- **`widget`** (`WidgetSafe`) - Показываемый элемент.

## Возвращаемые значения

Возвращаемое значение отсутствует.

## Примеры

### Прокрутка к указанному элементу

```lua
wtScrollableContainer:EnsureVisible( wtSelectedElement )
```
