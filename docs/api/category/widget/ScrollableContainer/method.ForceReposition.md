# ScrollableContainerSafe:ForceReposition

Вызывает немедленную репозицию контейнера.

## Описание

```lua
ScrollableContainerSafe:ForceReposition( force: boolean | nil )
```

По умолчанию репозиция выполняется 1 раз в конце кадра, если была запланирована. К планированию репозиции приводит:

- Добавление, удаление или перемещение элементов.

- Изменение `placement` самого контейнера, любого его внутреннего виджета, любого элемента, родительского виджета при условии, что у контейнера `align == BOTH`.

Если после такого действия необходимо сразу получить актуальные `placement` контейнера или его элементов, нужно вызвать данный метод.

::: warning Замечание
Репозиция контейнера с большим числом элементов - дорогая операция, не следует вызывать ее без существенной необходимости.
:::

::: danger Опасность
Флаг `force` - жуткое колдунство. Если он понадобился, то что-то пошло сильно не так.
:::

## Список параметров

- **`force`** (`boolean` | `nil`) - Выполнить репозицию даже если она не запланирована. Значение по умолчанию: `false`.

## Возвращаемые значения

Возвращаемое значение отсутствует.

## Примеры

### Базовый вызов

```lua
wtScrollableContainer:ForceReposition()
```
