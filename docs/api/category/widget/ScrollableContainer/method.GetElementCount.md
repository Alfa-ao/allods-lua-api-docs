# ScrollableContainerSafe:GetElementCount
Возвращает количество элементов в контейнере.

## Описание
```lua
ScrollableContainerSafe:GetElementCount(): number
```
Функция возвращает количество элементов в контейнере.

## Список параметров
Параметры отсутствуют.

## Возвращаемые значения
Возвращает `number` - количество элементов.

## Примеры
### Получение количества элементов
```lua
local count = wtScrollableContainer:GetElementCount()
```
