# ScrollableContainerSafe:GetElementLimit
Извлекает максимальное количество элементов в контейнере.

## Описание

```lua
ScrollableContainerSafe:GetElementLimit(): number
```

Функция возвращает максимальное количество элементов в контейнере.

## Список параметров

Параметры отсутствуют.

## Возвращаемые значения

Возвращает `number` - максимальное количество элементов.

## Примеры

### Получение лимита элементов
```lua
local count = wtContainer:GetElementLimit()
```
