# ScrollableContainerSafe:IsSliderMax

Проверяет, находится ли ползунок прокрутки в самом конце.

## Описание

```lua
ScrollableContainerSafe:IsSliderMax(): boolean
```

Функция возвращает статус нахождения ползунка прокрутки в самом конце. Если контейнер не скроллится, возвращается `true`.

## Список параметров

Параметры отсутствуют.

## Возвращаемые значения

Возвращает `boolean` - `true`, если ползунок прокрутки находится в самом конце, иначе `false`. Если контейнер не скроллится, всегда возвращается `true`.

## Примеры

### Проверка положения ползунка

```lua
if wtScrollableContainer:IsSliderMax() then
    -- do something
end
```
