# ScrollableContainerSafe:PopBack

Удаляет последний элемент из контейнера.

## Описание

```lua
ScrollableContainerSafe:PopBack(): WidgetSafe | nil
```

Функция возвращает виджет удаленного элемента и удаляет последний элемент из контейнера. Если контейнер пуст, действие не выполняется.

::: warning Замечание
Удаляется именно элемент контейнера, но не его `WidgetSafe`. Виджет возвращается владельцу посредством неявного вызова `Owner:AddChild`.
:::

## Список параметров

Параметры отсутствуют.

## Возвращаемые значения

Возвращает `WidgetSafe` | `nil` - виджет удаленного элемента, если таковой имеется.

## Примеры

### Удаление последнего элемента

```lua
wtScrollableContainer:PopBack()
```
