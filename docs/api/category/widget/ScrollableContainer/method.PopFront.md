# ScrollableContainerSafe:PopFront

Удаляет первый элемент из контейнера.

## Описание

```lua
ScrollableContainerSafe:PopFront(): WidgetSafe | nil
```

Функция возвращает виджет удаленного первого элемента контейнера.

::: warning Замечание
Удаляется именно элемент контейнера, но не его `WidgetSafe`. Виджет возвращается владельцу (неявно вызывается `Owner:AddChild(widget)`).
:::

## Список параметров

Параметры отсутствуют.

## Возвращаемые значения

Возвращает `WidgetSafe` | `nil` - Виджет удаленного элемента, если таковой имеется, или `nil`, если контейнер пуст.

## Примеры

### Удаление первого элемента

```lua
wtScrollableContainer:PopFront()
```
