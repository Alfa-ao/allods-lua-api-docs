# ScrollableContainerSafe:PushBack
Добавляет в контейнер очередной элемент в конец списка.

## Описание
```lua
ScrollableContainerSafe:PushBack( widget: WidgetSafe )
```
Функция добавляет в контейнер очередной элемент в конец списка.

::: warning Замечание
Порядок отображения задается в настройках контейнера, поэтому визуально последний элемент может быть и в начале.
:::

::: danger Ошибки
Функция вернет ошибку, если выполняется любое из нижележащих условий:

- Добавляемый дочерний виджет является внутренним

- Добавляемый дочерний виджет является формой

- Добавляемый дочерний виджет в данный момент находится в контейнере или добавлен в сцену как Widget3D

- Контейнер переполнен
:::

## Список параметров
- **`widget`** (`WidgetSafe`) - Добавляемый элемент.

## Возвращаемые значения
Возвращаемое значение отсутствует.

## Примеры
### Добавление элемента в контейнер
```lua
wtScrollableContainer:PushBack( wtButton )
```
