# ScrollableContainerSafe:Remove
Удаляет указанный элемент из контейнера по переданному виджету.

## Описание
```lua
ScrollableContainerSafe:Remove( widget: WidgetSafe )
```
Метод удаляет указанный элемент из контейнера. Отсутствие данного виджета в контейнере считается ошибкой.

::: warning Замечание
Удаляется именно элемент контейнера, но не его WidgetSafe. Виджет возвращается владельцу посредством неявного вызова `Owner:AddChild( widget )`.
:::

## Список параметров
- **`widget`** (`WidgetSafe`) - Удаляемый элемент.

## Возвращаемые значения
Возвращаемое значение отсутствует.

## Примеры
### Удаление элемента из контейнера
```lua
wtScrollableContainer:Remove( wtButton )
```
