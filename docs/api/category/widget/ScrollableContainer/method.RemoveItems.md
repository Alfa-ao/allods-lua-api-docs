# ScrollableContainerSafe:RemoveItems

Удаляет все элементы из контейнера.

## Описание

```lua
ScrollableContainerSafe:RemoveItems()
```

Функция удаляет все элементы из контейнера.

::: warning Замечание
Удаляются именно элементы контейнера, но не их WidgetSafe. Они будут возвращены владельцам (для каждого элемента будет неявно вызван Owner:AddChild( widget )).
:::

## Список параметров

Параметры отсутствуют.

## Возвращаемые значения

Возвращаемое значение отсутствует.

## Примеры

### Очистка контейнера

```lua
wtScrollableContainer:RemoveItems()
```
