# ScrollableContainerSafe:SwapElements

Меняет местами пару элементов контейнера.

## Описание

```lua
ScrollableContainerSafe:SwapElements( pos1: number, pos2: number )
```

Функция производит обмен местами двух элементов контейнера.

::: warning Замечание
Операция существенно дешевле чем удаление / вставка.
:::

## Список параметров

- **`pos1`** (`number`) - Позиция первого элемента. Позиции отсчитываются от 1.

- **`pos2`** (`number`) - Позиция второго элемента. Позиции отсчитываются от 1.

## Возвращаемые значения

Возвращаемое значение отсутствует.

## Примеры

### Обмен элементов

```lua
wtContainer:SwapElements( 1, 2 ) -- Поменять местами 1 и 2 элементы
```
