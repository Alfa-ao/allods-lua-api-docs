# TextContainerSafe:ForceReposition

Вызывает немедленную репозицию контейнера.

## Описание

```lua
TextContainerSafe:ForceReposition( force: boolean | nil )
```

По умолчанию репозиция выполняется 1 раз в конце кадра, если была запланирована. К планированию репозиции приводит добавление или удаление элементов, а также изменение placement контейнера, любого из его родителей или детей (в том числе элементов). Если после такого действия необходимо сразу получить актуальные placement контейнера или его элементов, нужно вызвать данный метод.

::: warning Замечание
Репозиция контейнера с большим числом элементов - дорогая операция, не следует вызывать ее без существенной необходимости.
:::

::: danger Важное замечание
Флаг `force` - жуткое колдунство. Если он понадобился, то что-то пошло сильно не так.
:::

## Список параметров

- **`force`** (`boolean` | `nil`) - Выполняет репозицию даже если она не запланирована.

## Возвращаемые значения

Возвращаемое значение отсутствует.

## Примеры

### Базовый вызов

```lua
wtTextContainer:ForceReposition()
```
