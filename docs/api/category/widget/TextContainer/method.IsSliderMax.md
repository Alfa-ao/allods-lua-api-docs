# TextContainerSafe:IsliderMax

Проверяет, находится ли скроллер в конце полосы прокрутки.

## Описание

```lua
TextContainerSafe:IsliderMax(): boolean
```

Функция возвращает логическое значение, указывающее, находится ли скроллер в самом конце полосы прокрутки. Если контейнер не поддерживает прокрутку, функция всегда возвращает `true`.

## Список параметров

Параметры отсутствуют.

## Возвращаемые значения

Возвращает `boolean` - `true`, если скроллер находится в самом конце полосы прокрутки или контейнер не скроллируется, и `false` в противном случае.

## Примеры

### Проверка положения скроллера

```lua
if wtTextContainer:IsliderMax() then
    -- do something
end
```
