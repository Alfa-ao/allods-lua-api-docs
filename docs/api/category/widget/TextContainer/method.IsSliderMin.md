# TextContainerSafe:IsSliderMin

Проверяет, находится ли скроллер в самом начале.

## Описание

```lua
TextContainerSafe:IsSliderMin(): boolean
```

Метод возвращает логическое значение, указывающее на нахождение скроллера в самом начале. Если контейнер не скроллируется, всегда возвращается `true`.

## Список параметров

Параметры отсутствуют.

## Возвращаемые значения

Возвращает `boolean` - `true`, если скроллер находится в самом начале, и `false` в противном случае.

## Примеры

### Проверка положения скроллера

```lua
if wtTextContainer:IsSliderMin() then
    -- do something
end
```
