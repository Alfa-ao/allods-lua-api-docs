# TextContainerSafe:PopBack

Удаляет элемент в конце контейнера.

## Описание

```lua
TextContainerSafe:PopBack()
```

Метод удаляет элемент, расположенный в конце контейнера.

## Список параметров

Параметры отсутствуют.

## Возвращаемые значения

Возвращаемое значение отсутствует.

## Примеры

### Удаление элемента

```lua
wtTextContainer:PopBack()
```
