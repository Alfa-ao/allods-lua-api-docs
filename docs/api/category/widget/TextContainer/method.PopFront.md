# TextContainerSafe:PopFront

Удаляет элемент в начале контейнера.

## Описание

```lua
TextContainerSafe:PopFront()
```

Метод удаляет элемент, находящийся в начале контейнера.

## Список параметров

Параметры отсутствуют.

## Возвращаемые значения

Возвращаемое значение отсутствует.

## Примеры

### Удаление элемента из контейнера

```lua
wtTextContainer:PopFront()
```
