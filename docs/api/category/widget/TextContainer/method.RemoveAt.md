# TextContainerSafe:RemoveAt

Удаляет указанный элемент из контейнера.

## Описание

```lua
TextContainerSafe:RemoveAt( pos: number )
```

Функция удаляет элемент из текстового контейнера по заданному индексу.

## Список параметров

- **`pos`** (`number`) - индекс элемента, который необходимо удалить (начинается с нуля).

## Возвращаемые значения

Возвращаемое значение отсутствует.

## Примеры

### Удаление шестого элемента

```lua
wtTextContainer:RemoveAt( 5 )
```
