# TextViewSafe:ClearValues

Очищает все подставленные значения в ValuedText-е текстового контрола.

## Описание

```lua
TextViewSafe:ClearValues()
```

Метод выполняет очистку всех подставленных значений в ValuedText-е текстового контрола.

## Список параметров

Параметры отсутствуют.

## Возвращаемые значения

Возвращаемое значение отсутствует.

## Примеры

### Очистка значений

```lua
wtTextView:ClearValues()
```
