# TextViewSafe:FinishTextScaleEffect

Прерывает эффект масштабирования текста.

## Описание

```lua
TextViewSafe:FinishTextScaleEffect( finalPosition: boolean | nil, sendEvent: boolean | nil )
```

Функция прерывает выполнение эффекта масштабирования текста, примененного к виджету.

## Список параметров

- **`finalPosition`** (`boolean` | `nil`) - Выставить состояние виджета как конечное из эффекта или цепочки эффектов (`true`) или оставить виджет в том состоянии, в котором он находится в момент прерывания эффекта (`false`). По умолчанию `false`.

- **`sendEvent`** (`boolean` | `nil`) - Послать событие об окончании эффекта или цепочки эффектов (`true`) или не посылать (`false`). По умолчанию `false`. Если задано `true`, то событие будет послано вне зависимости от того, было ли оно затребовано при старте эффекта или цепочки эффектов.

## Возвращаемые значения

Возвращаемое значение отсутствует.

## Примеры

### Прерывание эффекта масштабирования

```lua
wtText:FinishTextScaleEffect()
```
