# TextViewSafe:GetDefaultTag

Метод возвращает тег по умолчанию.

## Описание

```lua
TextViewSafe:GetDefaultTag(): WString
```

Метод применяется для удобства, если формат текста подразумевает использование только одного значения подстановки.

## Список параметров

Параметры отсутствуют.

## Возвращаемые значения

Возвращает `WString` - тег по умолчанию.

## Примеры

### Получение тега по умолчанию

```lua
local tag = wtTextView:GetDefaultTag()
```
