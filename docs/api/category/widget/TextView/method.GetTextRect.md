# TextViewSafe:GetTextRect

Возвращает границы области, в которую вписан отрисованный текст.

## Описание

```lua
TextViewSafe:GetTextRect(): table
```

Функция возвращает таблицу с координатами и размерами области, в которую вписан отрисованный текст.

::: warning Замечание
Для получения валидных значений текст предварительно должен быть отрисован в предыдущем кадре.
:::

## Список параметров

Параметры отсутствуют.

## Возвращаемые значения

Возвращает `table` - таблицу с границами области текста:

- **`posX`** (`number`) - позиция по горизонтали.

- **`posY`** (`number`) - позиция по вертикали.

- **`sizeX`** (`number`) - ширина.

- **`sizeY`** (`number`) - высота.

## Примеры

### Получение границ текста

```lua
local rect = wtTextView:GetTextRect()
```
