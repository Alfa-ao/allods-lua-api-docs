# TextViewSafe:GetTextScale
Возвращает коэффициент масштабирования текста внутри текстового контрола.

## Описание
```lua
TextViewSafe:GetTextScale()
```
Функция возвращает коэффициент масштабирования текста. Если текст не масштабирован, возвращается `nil`.

::: warning Замечание
Масштабированные тексты могут "размыливаться".
:::

## Список параметров
Параметры отсутствуют.

## Возвращаемые значения
Возвращает `number` | `nil` - коэффициент масштабирования текста (>= 0.0) или `nil`, если текст не масштабирован.

## Примеры
### Получение коэффициента масштабирования
```lua
local scale = wtTextView:GetTextScale()
if not scale then
    LogInfo( "Text is not scaled" )
end
```

::: info Описание примера
Получается коэффициент масштабирования текста. Если масштабирование отсутствует, выводится информационное сообщение.
:::
