# TextViewSafe:SetFormat

Меняет формат текста.

## Описание

```lua
TextViewSafe:SetFormat( format: WString | String )
```

Механизм работы идентичен SetFormat.

::: warning Замечание
Изменение формата не рекомендуется.
:::

::: danger Предупреждение
Если вам потребовалась эта API, то скорее всего что-то пошло не так
:::

## Список параметров

- **`format`** (`WString` | `String`) - Устанавливаемый формат.

## Возвращаемые значения

Возвращаемое значение отсутствует.

## Примеры

### Изменение формата текста

```lua
wtTextView:SetFormat( "<h1>отформатированный текст</h1>" )
```
