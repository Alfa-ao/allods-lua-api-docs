# TextViewSafe:SetTextScale

Масштабирует текст внутри текстового контрола.

## Описание

```lua
TextViewSafe:SetTextScale( scale: number | nil )
```

Метод поддерживает только строго центрированный текст (выравнивание: `alignx="center"`, `aligny="middle"`). Использование метода рекомендуется исключительно для динамических эффектов из-за визуального "размыливания" текста.

## Список параметров

- **`scale`** (`number` | `nil`) - Коэффициент масштабирования текста. Значение должно быть больше или равно 0.0. Передача `nil` возвращает текст в исходное немасштабированное состояние.

## Возвращаемые значения

Возвращаемое значение отсутствует.

## Примеры

### Масштабирование текста

```lua
wtTextView:SetTextScale( 0.5 )
```
