# TextViewSafe:SetValuedText

Полностью задает новый текст для данного контрола.

## Описание

```lua
TextViewSafe:SetValuedText( valuedText: ValuedText )
```

Копирует оформление и подстановочные значения.

## Список параметров

- **`valuedText`** (`ValuedText`) - Устанавливаемый формат.

## Возвращаемые значения

Возвращаемое значение отсутствует.

## Примеры

### Установка текста

```lua
wtTextView:SetValuedText( valuedText )
```
