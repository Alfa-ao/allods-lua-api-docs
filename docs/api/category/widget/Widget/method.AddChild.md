# WidgetSafe:AddChild

Определяет текущий виджет родительским (Parent) по отношению к указанному.

## Описание

```lua
WidgetSafe:AddChild( widget: WidgetSafe, noReposition: boolean | nil )
```

::: danger Функция возвращает ошибку, если выполняется любое из нижележащих условий
- Любой из виджетов является внутренним
- Добавляемый дочерний виджет является формой
- Добавляемый дочерний виджет в данный момент находится в контейнере или добавлен в сцену как Widget3D
:::

Метод доступен для всех типов виджетов.

::: warning Замечание
Флаг `noReposition` предназначен для тонких оптимизаций при работе с динамическими виджетами, использование без понимания его работы может привести к неожиданным эффектам.
:::

## Список параметров

- **`widget`** (`WidgetSafe`) - добавляемый виджет

- **`noReposition`** (`boolean` | `nil`) - не позиционировать виджет (default false).

## Возвращаемые значения

Возвращаемое значение отсутствует.

## Примеры

### Добавление дочернего виджета

```lua
wtParent:AddChild( wtChild )
```
