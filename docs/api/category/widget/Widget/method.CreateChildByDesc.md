# WidgetSafe:CreateChildByDesc

Создает новый виджет по его описателю из ресурсной системы.

## Описание

```lua
WidgetSafe:CreateChildByDesc( widgetDesc: WidgetDesc, noReposition: boolean | nil ): WidgetSafe
```

Владельцем (Owner) и родителем (Parent) виджета становится текущий виджет, при его уничтожении все виджеты, которыми он владеет, также будут уничтожены. Менять владельца нельзя. Изменить родителя можно, например, функцией `AddChild`.

::: warning Замечание
С точки зрения работы с памятью рекомендуется создавать и уничтожать виджеты по мере необходимости. При этом невостребованный виджет рекомендуется не уничтожать немедленно, а помещать в короткоживущий кэш (10-30 сек). И если за это время он остался невостребованным - уничтожить окончательно.
:::

::: danger Ошибка
Функция возвращает ошибку, если виджет является внутренним.
:::

::: tip Совет
Флаги `noReposition` и `noParent` предназначены для тонких оптимизаций при работе с динамическими виджетами. Использование без понимания их работы может привести к неожиданным эффектам.
:::

## Список параметров

- **`widgetDesc`** (`WidgetDesc`) - описатель дочернего виджета из ресурсной системы.

- **`noReposition`** (`boolean` | `nil`) - не позиционировать виджет.

- **`noParent`** (`boolean` | `nil`) - не устанавливать родителя виджета (дополнительный параметр при вызове из `WidgetFactorySafe`).

## Возвращаемые значения

Возвращает `WidgetSafe` - созданный дочерний виджет.

## Примеры

### Создание дочернего виджета

```lua
local desc = wtTemplate:GetWidgetDesc()
local wtNew = mainForm:CreateChildByDesc( desc )
```
