# WidgetSafe:DestroyWidget

Уничтожает виджет.

## Описание

```lua
WidgetSafe:DestroyWidget()
```

Функция уничтожает виджет. Метод доступен для всех типов виджетов, кроме `FormSafe`.

::: warning Замечание
Нельзя уничтожать внутренние виджеты и любые `FormSafe`, формы создаются и уничтожаются только в cpp.
:::

Правила уничтожения виджетов (правила уничтожения форм при выгрузке аддонов идентичны):

Перед уничтожением виджета:

- Если виджет является `ScrollableContainerSafe`, то он будет очищен (будет неявно вызван `RemoveItems`).

- Если виджет является `Control3DSafe`, то все `Widget3D` будут откреплены (будет неявно вызван `RemoveAllWidget3D`).

При уничтожении виджета будут уничтожены:

- Все дочерние виджеты (рекурсивно). В том числе неродные (добавленные через `AddChild`).

- Все виджеты, которыми владеет данный виджет (независимо от того, куда они определены детьми).

::: warning Замечание
После вызова данной функции виджет становится невалидным. Вызов любого API-метода, кроме `IsValid`, вызовет исключение.
:::

## Список параметров

Параметры отсутствуют.

## Возвращаемые значения

Возвращаемое значение отсутствует.

## Примеры

### Уничтожение динамического виджета

```lua
wtDynamic:DestroyWidget()
```
