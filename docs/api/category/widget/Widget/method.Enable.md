# WidgetSafe:Enable

Активирует или деактивирует контрол.

## Описание

```lua
WidgetSafe:Enable( enable: boolean )
```

Метод доступен для всех типов виджетов. Активирует или деактивирует виджет в зависимости от переданного флага.

## Список параметров

- **`enable`** (`boolean`) - Флаг активации или деактивации виджета.

## Возвращаемые значения

Возвращаемое значение отсутствует.

## Примеры

### Деактивация виджета

```lua
wtElement:Enable( false )
```
