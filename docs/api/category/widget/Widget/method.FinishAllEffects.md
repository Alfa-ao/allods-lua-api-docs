# WidgetSafe:FinishAllEffects

Прерывает эффекты всех типов [ET_*](/api/constants/constants.ET.md).

## Описание

```lua
WidgetSafe:FinishAllEffects( finalPosition: boolean|nil, sendEvent: boolean|nil )
```

Метод прерывает выполнение всех активных эффектов виджета.

## Список параметров

- **`finalPosition`** (`boolean` | `nil`) - Выставить состояние виджета как конечное из эффекта / цепочки эффектов (`true`) или оставить виджет в том состоянии в котором он находится в момент прерывания эффекта (`false`). По умолчанию `false`.

- **`sendEvent`** (`boolean` | `nil`) - Послать событие об окончании эффекта / цепочки эффектов (`true`) или не посылать (`false`). По умолчанию `false`. Если задано `true` то событие будет послано вне зависимости от того было ли оно затребовано при старте эффекта / цепочки эффектов.

## Возвращаемые значения

Возвращаемое значение отсутствует.
