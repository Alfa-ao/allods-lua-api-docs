# WidgetSafe:GetActiveEffectRemainingMs

Возвращает оставшуюся длительность эффекта заданного типа у виджета.

## Описание

```lua
WidgetSafe:GetActiveEffectRemainingMs( effectType: ET_* ): number
```

Функция возвращает оставшуюся длительность эффекта заданного типа у виджета. Если на виджете не проигрывается соответствующий эффект, возвращается 0. Возвращаемое значение 0 не гарантирует отсутствие данного эффекта на виджете, так как эффект может присутствовать, но его длительность истекла, при этом состояние события окончания эффекта не определено.

## Список параметров

- **`effectType`** (`ET_*`) - Тип эффекта. (HELP)

## Возвращаемые значения

Возвращает `number` - оставшееся время проигрывания эффекта. Если выполняется цепочка эффектов, возвращается оставшееся время текущего шага. Если эффект отсутствует, возвращается 0.
