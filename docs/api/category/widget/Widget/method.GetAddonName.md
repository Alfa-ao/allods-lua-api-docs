# WidgetSafe:GetAddonName

Возвращает имя аддона, к которому относится виджет.

## Описание

```lua
WidgetSafe:GetAddonName(): string
```

Функция возвращает имя аддона, к которому относится данный виджет.

## Список параметров

Параметры отсутствуют.

## Возвращаемые значения

Возвращает `string` - имя аддона, к которому относится данный виджет.

## Примеры

### Получение имени аддона

```lua
local ownerAddon = wtCooldown:GetAddonName()
```
