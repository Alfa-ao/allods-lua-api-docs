# WidgetSafe:GetChildUnchecked

Возвращает дочерний контрол с заданным именем.

## Описание

```lua
WidgetSafe:GetChildUnchecked( name: string, recursive: boolean | nil ): WidgetSafe | nil
```

Функция возвращает дочерний контрол с заданным именем или `nil`, если контрол не существует. Поиск выполняется среди непосредственных детей или рекурсивно среди вложенных контролов. Имя обязано быть непустым.

## Список параметров

- **`name`** (`string`) - Название искомого виджета.

::: danger <Badge type="danger" text="^18.0.0 - (Deprecated)" /> 
- **`recursive`** (`boolean` | `nil`) - Флаг, определяющий необходимость рекурсивного поиска среди вложенных контролов. По умолчанию `false`.
:::

## Возвращаемые значения

Возвращает `WidgetSafe` | `nil` - Найденный дочерний контрол или nil, если контрол с заданным именем не существует.

## Примеры

### Получение дочернего контрола

```lua
local child = parent:GetChildUnchecked( "MyName01", false )
```
