# WidgetSafe:GetDebugInfo

Возвращает строку содержащую отладочную информацию о виджете.

## Описание

```lua
WidgetSafe:GetDebugInfo(): string
```

Функция возвращает строку содержащую отладочную информацию о виджете. Общий формат: "[ID_виджета][Тип_виджета]: (Имя_аддона)->Полный_путь, Resource: Путь_к_ресурсу" где:

- **`ID_виджета`** - определяется функцией `Widget:GetId()`.

- **`Тип_виджета`** - тип ресурса виджета. Если виджет создан без ресурса, используется значение `RD` (Runtime Defined).

- **`Имя_аддона`** - определяется функцией `Widget:GetAddonName()`.

- **`Полный_путь`** - строка вида `mainForm.wtMainPanel.[Unnamed].wtText` (пример).

- **`Путь_к_ресурсу`** - путь к `xdb` описателю виджета относительно геймдаты. Если виджет сериализован, используется значение `[Serialized]`. Если создан без ресурса, используется значение `[Runtime]`.

## Список параметров

Параметры отсутствуют.

## Возвращаемые значения

Возвращает `string` - строка с подробной отладочной информацией о виджете.

## Примеры

### Получение отладочной информации

```lua
LogInfo( wtSample:GetDebugInfo() )
```
