# WidgetSafe:GetFade

Возвращает коэффициент прозрачности виджета.

## Описание

```lua
WidgetSafe:GetFade(): number
```

Функция возвращает степень прозрачности виджета в диапазоне от 0 до 1, где 1.0 означает полную непрозрачность.

## Список параметров

Параметры отсутствуют.

## Возвращаемые значения

Возвращает `number` - степень прозрачности от 0 до 1, где 1.0 означает полную непрозрачность.

## Примеры

### Получение коэффициента прозрачности

```lua
local ownFade = wtLabel:GetFade()
```
