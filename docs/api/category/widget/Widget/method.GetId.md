# WidgetSafe:GetId

Возвращает уникальный числовой идентификатор виджета.

## Описание

```lua
WidgetSafe:GetId(): number
```

Является номером созданного виджета. Освободившиеся значения (от удаленных виджетов) повторно не назначаются.

::: warning Замечание
Идентификатор стабилен в рамках одного запуска клиента, не является хранимым и не применим для идентификации виджета между разными сессиями.
:::

## Список параметров

Параметры отсутствуют.

## Возвращаемые значения

Возвращает `number` - уникальный числовой идентификатор виджета.

## Примеры

### Получение идентификатора виджета

```lua
local id = wtLabel:GetId()
```
