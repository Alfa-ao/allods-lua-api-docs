# WidgetSafe:GetName

Возвращает имя контрола.

## Описание

```lua
WidgetSafe:GetName(): string
```

Функция возвращает имя контрола.

## Список параметров

Параметры отсутствуют.

## Возвращаемые значения

Возвращает `string` - имя контрола.

## Примеры

### Получение имени контрола

```lua
local name = wtElement01:GetName()
```
