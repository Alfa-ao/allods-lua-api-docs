# WidgetSafe:GetNamedChildren

Возвращает список именованных дочерних контролов.

## Описание

```lua
WidgetSafe:GetNamedChildren(): table
```

Функция возвращает список непосредственных дочерних контролов, не включая вложенные. Контролы, не имеющие имени, считаются служебными и в список не попадают. Метод доступен у всех типов виджетов.

## Список параметров

Параметры отсутствуют.

## Возвращаемые значения

Возвращает `table` - таблица со значениями типа `WidgetSafe`, индексированная с 1.

## Примеры

### Получение и перебор именованных дочерних контролов

```lua
for _, wtChild in ipairs( wtParent:GetNamedChildren() ) do
    LogInfo( wtChild:GetName() )
end
```
