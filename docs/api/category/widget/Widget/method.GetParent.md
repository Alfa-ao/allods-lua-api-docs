# WidgetSafe:GetParent

Возвращает родительский виджет для текущего элемента.

## Описание

```lua
WidgetSafe:GetParent(): WidgetSafe | nil
```

Функция возвращает родительский виджет для всех элементов, кроме форм. Для форм всегда возвращается `nil`. Если родителя нет, то возвращается `nil`. Возвращается именно родительский виджет, а не владелец (owner). Метод доступен у всех типов виджетов.

## Список параметров

Параметры отсутствуют.

## Возвращаемые значения

Возвращает `WidgetSafe` | `nil` - родительский виджет или `nil`, если родителя нет или текущий виджет является формой.

## Примеры

### Получение родительского виджета

```lua
local wtParent = widget:GetParent()
if wtParent then
    LogInfo( "parent name: ", wtParent:GetName() )
end
```
