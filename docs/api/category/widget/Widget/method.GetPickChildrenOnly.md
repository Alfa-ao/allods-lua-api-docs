# WidgetSafe:GetPickChildrenOnly

Получает статус атрибута `PickChildrenOnly` для виджета.

## Описание

```lua
WidgetSafe:GetPickChildrenOnly(): boolean
```

Функция возвращает статус атрибута `PickChildrenOnly`, определяющего обработку мышиных реакций только для дочерних элементов виджета, игнорируя сам виджет.

## Список параметров

Параметры отсутствуют.

## Возвращаемые значения

Возвращает `boolean` - `true`, если обрабатывать мышиные реакции нужно только для детей данного виджета (игнорируя сам виджет).

## Примеры

### Проверка статуса виджета

```lua
if wtTemplate:GetPickChildrenOnly() then
    ...
end
```
