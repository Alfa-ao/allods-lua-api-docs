# WidgetSafe:GetPriority

Возвращает текущий приоритет контрола.

## Описание

```lua
WidgetSafe:GetPriority(): number
```

Функция возвращает текущий приоритет контрола. Контрол с большим приоритетом (среди других детей того же родителя) рисуется поверх контролов с более низким. Метод доступен у всех типов виджетов.

## Список параметров

Параметры отсутствуют.

## Возвращаемые значения

Возвращает `number` - текущее значение приоритета контрола.

## Примеры

### Получение приоритета контрола

```lua
local priority = widget:GetPriority()
```
