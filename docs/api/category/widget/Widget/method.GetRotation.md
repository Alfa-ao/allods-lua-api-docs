# WidgetSafe:GetRotation

Возвращает текущий угол поворота текстур в радианах против часовой стрелки.

## Описание

```lua
WidgetSafe:GetRotation(): number
```

Функция возвращает текущий угол поворота текстур. Имеет смысл только при наличии хотя бы одного слоя, содержащего `WidgetLayerSimpleTexture`.

## Список параметров

Параметры отсутствуют.

## Возвращаемые значения

Возвращает `number` - угол поворота против часовой стрелки в радианах.

## Примеры

### Получение угла поворота

```lua
local radians = wtWidget:GetRotation()
```
