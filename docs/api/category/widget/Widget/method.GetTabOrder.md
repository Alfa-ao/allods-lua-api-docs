# WidgetSafe:GetTabOrder

Возвращает текущий приоритет обхода виджета.

## Описание

```lua
WidgetSafe:GetTabOrder(): number
```

Функция возвращает текущий приоритет обхода виджета. Метод имеется у всех типов виджетов. Чем меньше значение, тем раньше до виджета дойдет очередь при обходе виджетов по нажатию Tab.

## Список параметров

Параметры отсутствуют.

## Возвращаемые значения

Возвращает `number` - текущее значение приоритета обхода виджета.

## Примеры

### Получение приоритета обхода

```lua
local tabOrder = widget:GetTabOrder()
```
