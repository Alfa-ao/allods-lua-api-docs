# WidgetSafe:GetTransparentInput

Показывает, является ли виджет прозрачным для ввода.

## Описание

```lua
WidgetSafe:GetTransparentInput(): boolean
```

Функция возвращает логическое значение, указывающее на прозрачность виджета для ввода.

## Список параметров

Параметры отсутствуют.

## Возвращаемые значения

Возвращает `boolean` - показывает, является ли виджет прозрачным для ввода.

## Примеры

### Проверка прозрачности виджета

```lua
local isTransparentInput = wtTemplate:GetTransparentInput()
```
