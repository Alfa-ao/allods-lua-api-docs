# WidgetSafe:GetWidgetDesc

Возвращает описатель виджета в ресурсной системе.

## Описание

```lua
WidgetSafe:GetWidgetDesc(): WidgetDesc
```

Функция возвращает описатель виджета из ресурсной системы. Метод работает только для виджетов, созданных на основе таких описателей (большинство виджетов именно такие, исключения будут описываться отдельно).

::: warning Замечание
Функция возвращает ошибку, если выполняется любое из нижележащих условий: 
- Виджет является внутренним.
- Виджет является формой.
:::

## Список параметров

Параметры отсутствуют.

## Возвращаемые значения

Возвращает `WidgetDesc` - описатель виджета из ресурсной системы.

## Примеры

### Получение описателя виджета

```lua
local desc = wtTemplate:GetWidgetDesc()
```
