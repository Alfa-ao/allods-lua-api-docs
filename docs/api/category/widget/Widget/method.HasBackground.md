# WidgetSafe:HasBackground

Проверяет существование фонового слоя у виджета.

## Описание

```lua
WidgetSafe:HasBackground(): boolean
```

Функция возвращает логическое значение, указывающее на существование фонового слоя у виджета.

## Список параметров

Параметры отсутствуют.

## Возвращаемые значения

Возвращает `boolean` - `true`, если фоновый слой существует, и `false` в противном случае.

## Примеры

### Проверка и установка текстуры фона

```lua
if wtActionIcon:HasBackground() then
    wtActionIcon:SetBackgroundTexture( placeholderIconId )
end
```

::: info Описание примера
В примере сначала проверяется наличие фонового слоя у виджета. Если слой существует, устанавливается текстура фона с использованием идентификатора `placeholderIconId`.
:::
