# WidgetSafe:HasForeground

Проверяет существование переднего слоя у виджета.

## Описание

```lua
WidgetSafe:HasForeground(): boolean
```

Функция возвращает логическое значение, указывающее на существование переднего слоя у виджета.

## Список параметров

Параметры отсутствуют.

## Возвращаемые значения

Возвращает `boolean` - `true`, если передний слой существует.

## Примеры

### Проверка и установка переднего слоя

```lua
if wtActionIcon:HasForeground() then
    wtActionIcon:SetForegroundTexture( placeholderIconId )
end
```

::: info Описание примера
Проверяется наличие переднего слоя у виджета. Если слой существует, устанавливается текстура переднего плана.
:::
