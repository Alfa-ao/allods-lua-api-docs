# WidgetSafe:IsClipContent

Проверяет, выполняется ли обрезка дочерних виджетов по размерам текущего виджета.

## Описание

```lua
WidgetSafe:IsClipContent(): boolean
```

Функция возвращает логическое значение, определяющее, выполняется ли обрезка дочерних виджетов по размерам текущего виджета.

## Список параметров

Параметры отсутствуют.

## Возвращаемые значения

Возвращает `boolean` - `true`, если выполняется обрезка дочерних виджетов по размерам текущего виджета.

## Примеры

### Получение статуса обрезки контента

```lua
local isClipContent = widget:IsClipContent()
```
