# WidgetSafe:IsContentLoaded

Проверяет загруженность текстур виджета.

## Описание

```lua
WidgetSafe:IsContentLoaded(): boolean
```

Функция возвращает статус загрузки текстур виджета. Если виджет невидим, он считается загруженным. Проверяются текстуры всех слоев виджета и его видимых детей (рекурсивно). Для успеха все они должны быть полностью загружены. Метод актуален при загрузке больших списков виджетов.

## Список параметров

Параметры отсутствуют.

## Возвращаемые значения

Возвращает `boolean` - `true`, если текстуры виджета и его видимых детей (рекурсивно) полностью загружены.

## Примеры

### Проверка загрузки текстур

```lua
local loaded = widget:IsContentLoaded()
```
