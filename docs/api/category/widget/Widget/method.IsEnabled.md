# WidgetSafe:IsEnabled

Проверяет включенность контрола.

## Описание

```lua
WidgetSafe:IsEnabled(): boolean
```

Функция возвращает признак включенности контрола.

## Список параметров

Параметры отсутствуют.

## Возвращаемые значения

Возвращает `boolean` - `true`, если виджет включен.

## Примеры

### Проверка состояния контрола

```lua
local enabled = widget:IsEnabled()
```
