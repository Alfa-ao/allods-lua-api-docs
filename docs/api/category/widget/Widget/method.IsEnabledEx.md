# WidgetSafe:IsEnabledEx

Проверяет, включен ли контрол с учетом всей цепочки родителей.

## Описание

```lua
WidgetSafe:IsEnabledEx(): boolean
```

Функция возвращает результат проверки включенности контрола с учетом всей цепочки родителей.

## Список параметров

Параметры отсутствуют.

## Возвращаемые значения

Возвращает `boolean` - `true`, если виджет и все его родители (рекурсивно) включены.

## Примеры

### Проверка включенности виджета

```lua
local enabled = widget:IsEnabledEx()
```
