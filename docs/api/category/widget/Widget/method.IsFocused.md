# WidgetSafe:IsFocused

Определяет, находится ли контрол в фокусе.

## Описание

```lua
WidgetSafe:IsFocused(): boolean
```

## Список параметров

Параметры отсутствуют.

## Возвращаемые значения

Возвращает `boolean` - `true`, если контрол находится в фокусе.

## Примеры

### Проверка фокуса контрола

```lua
local focused = widget:IsFocused()
```
