# WidgetSafe:IsValid

Проверяет валидность указанного виджета.

## Описание

```lua
WidgetSafe:IsValid(): boolean
```

Функция возвращает статус валидности указанного виджета.

## Список параметров

Параметры отсутствуют.

## Возвращаемые значения

Возвращает `boolean` - `true`, если виджет валиден, иначе `false`.

## Примеры

### Проверка валидности виджета

```lua
if not wtSender or not wtSender:IsValid() then
    return
end
```
