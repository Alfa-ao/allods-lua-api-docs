# WidgetSafe:IsVisible

Проверяет видимость контрола без учёта видимости родителей.

## Описание

```lua
WidgetSafe:IsVisible(): boolean
```

Функция возвращает результат проверки видимости контрола без учёта видимости родителей.

## Список параметров

Параметры отсутствуют.

## Возвращаемые значения

Возвращает `boolean` - `true`, если виджет будет виден, когда все его родители будут видимыми.

## Примеры

### Проверка видимости контрола

```lua
local visible = widget:IsVisible()
```
