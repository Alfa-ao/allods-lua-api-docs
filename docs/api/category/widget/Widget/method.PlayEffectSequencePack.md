# WidgetSafe:PlayEffectSequencePack

Запускает набор цепочек эффектов разных типов.

## Описание

```lua
WidgetSafe:PlayEffectSequencePack( effectPack: table )
```

Функция принимает таблицу, где ключом является тип эффекта `ET_*`, а значением - параметры цепочки эффектов `sequenceParams`. Описание параметров `sequenceParams` приводится в методе `WidgetSafe:PlayEffectSequence`. Для типа `ET_TEXTURE_ROTAION` используется метод `WidgetSafe:PlayRotationEffectSequence`.

## Список параметров

- **`effectPack`** (`table`) - Таблица, описывающая набор цепочек эффектов. Ключом является тип эффекта `ET_*`, значением - `sequenceParams` для данного эффекта.

    - **`sequenceParams`** (`table`) - Таблица, описывающая параметры цепочки эффектов.

        - **`[1]..[N]`** (`table`) - От 1 до 256 таблиц описателей шага эффекта без разрывов. Каждый описатель шага представляет собой таблицу вида `{ start, finish, timeMs, algoDesc }`.

            - **`start`** (`number` | `nil`) - Начальное состояние виджета. Может отсутствовать или быть неполным. В этом случае недостающие данные берутся из текущего состояния виджета на первом шаге или из конечного состояния на предыдущем шаге.

            - **`finish`** (`number` | `nil`) - Конечное состояние виджета. Может отсутствовать или быть неполным. В этом случае недостающие данные берутся из начального состояния виджета.

            - **`timeMs`** (`number` | `nil`) - Длительность эффекта в миллисекундах. Должно быть строго положительным. В случае `nil` используется значение 1000.

            - **`algoDesc`** (`number` | `table` | `nil`) - Описание алгоритма эффекта.

                - `nil` - Значение по умолчанию `EA_MONOTONOUS_INCREASE`.

                - `number` - Значение `EA_*`.

                - `table` - Описание алгоритма `EA_*` с параметрами. Обязательное поле `type` (`number`) - значение `EA_*`. Набор полей зависит от алгоритма.

        Опциональные поля:
        
        - **`showOnStart`** (`boolean` | `nil`) - Показать виджет перед началом цепочки эффектов. По умолчанию `false`.

        - **`hideOnFinish`** (`boolean` | `nil`) - Скрыть виджет после окончания цепочки эффектов. По умолчанию `false`.

        - **`cycled`** (`boolean` | `nil`) - Зациклить цепочку эффектов. По умолчанию `false`. Зацикленная цепочка исполняется до явного прерывания.

        - **`sendStepEvent`** (`boolean` | `nil`) - Посылать событие об окончании каждого промежуточного шага эффекта, кроме последнего. По умолчанию `false`.

        - **`sendFinishEvent`** (`boolean` | `nil`) - Посылать событие об окончании цепочки эффектов. По умолчанию `false`.

        - **`eventLabel`** (`string` | `number` | `nil`) - Не влияет на работу цепочки эффектов. При наличии присылается в событиях шага или окончания цепочки, приводится к строке. По умолчанию отсутствует.

        - **`startOffsetMs`** (`number` | `nil`) - Миллисекунда, с которой начинается цепочка эффектов. Может быть больше длительности цепочки. Используется для синхронизации эффектов на разных виджетах. По умолчанию `0`.

## Возвращаемые значения

Возвращаемое значение отсутствует.

## Примеры

### Запуск набора эффектов

```lua
wtTextView:PlayEffectSequencePack( {
    [ ET_FADE ] = {
        { 0.25, 1, 800, EA_SYMMETRIC_FLASH },
        showOnStart = true,
        hideOnFinish = true
    },
    [ ET_TEXT_SCALE ] = {
        { 1, 1.25, 200 },
        { nil, nil, 400 },
        { nil, 0.1, 200 }
    }
} )
```
