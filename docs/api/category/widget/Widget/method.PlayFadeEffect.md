# WidgetSafe:PlayFadeEffect

Запускает эффект изменения прозрачности виджета.

## Описание

```lua
WidgetSafe:PlayFadeEffect( start: number | nil, finish: number | nil, timeMs: number, algoDesc: number, needEvent: boolean, eventReceivers: table )
```

Эффект имеет тип `ET_FADE` и соответствует шаблону `PlayEffect`. Значения параметров `start` и `finish` представляют собой число с плавающей точкой в диапазоне от 0 до 1, задающее значение непрозрачности.

## Список параметров

- **`start`** (`number` | `nil`) - `(float) [ 0, 1 ]` начальная непрозрачность виджета.
- **`finish`** (`number` | `nil`) - `(float) [ 0, 1 ]` конечная непрозрачность виджета.
- **`timeMs`** (`number` | `nil`) - Длительность эффекта в миллисекундах, должно быть строго положительное, в случае `nil` используется значение 1000. Гарантируется что итоговая длительность эффекта попадет в диапазон (timeMs, timeMs + время кадра).
- **`algoDesc`** (`number` | `table` | `nil`) - Описание алгоритма эффекта: 

    - `nil` - значение по умолчанию `EA_MONOTONOUS_INCREASE`; 
    - `number` - значение `EA_*`; 
    - `table` - описание алгоритма `EA_*` с параметрами, обязательное поле `type` (`number`) - значение `EA_*`, набор полей зависит от алгоритма.

- **`needEvent`** (`boolean` | `nil`) - Нужно ли посылать событие `EVENT_EFFECT_FINISHED` по окончании данного эффекта, по умолчанию `false`.
- **`eventReceivers`** (`table` | `nil`) - Список системных имен аддонов (помимо аддона запустившего эффект) получателей события `EVENT_EFFECT_FINISHED`, по умолчанию пуст. Поле игнорируется в пользовательских дополнениях.

## Возвращаемые значения

Возвращаемое значение отсутствует.

## Примеры

### Вспышка и плавное появление

```lua
wt:PlayFadeEffect( 0.0, 1.0, 2000, EA_SYMMETRIC_FLASH ) -- сделать вспышку длительностью в 2 секунды
wt:PlayFadeEffect( nil, 0 ) -- плавное появление
```
