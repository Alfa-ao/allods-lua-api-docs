# WidgetSafe:PlayMoveEffectSequence

Запускает цепочку эффектов изменения положения виджета.

## Описание

```lua
WidgetSafe:PlayMoveEffectSequence( sequenceParams: table )
```

Запускает цепочку эффектов изменения положения виджета. Эффект имеет тип `ET_FADE`. Типы `start` / `finish`: table (WidgetPlacement), значимые поля `posX`, `posY`, `highPosX`, `highPosY`

::: warning Замечание
Если виджет выровнен по ширине (`WIDGET_ALIGN_BOTH`) или имеет неявное масштабирование (`WIDGET_SIZING_CHILDREN` / `WIDGET_SIZING_INTERNAL`), то данный эффект может приводить к изменению размера виджета.
:::

## Список параметров

- **`sequenceParams`** (`table`) - Таблица, описывающая параметры цепочки эффектов.

    Обязательные поля:

    - **`[1] .. [N]`** (`table`) - N (1 <= N <= 256, без разрывов) таблиц-описателей шага эффекта. Каждый описатель шага это таблица вида `{ start, finish, timeMs, algoDesc }`.

        Поля таблицы описателя шага:

        - **`start`** (`table`(`WidgetPlacement`) | `nil`) - начальное положение виджета.

        - **`finish`** (`table`(`WidgetPlacement`) | `nil`) - конечное положение виджета.

        - **`timeMs`** (`number` | `nil`) - `(int64)` Длительность эффекта в миллисекундах, должно быть строго положительное. В случае `nil` используется значение `1000`.

        - **`algoDesc`** (`number` | `table` | `nil`) - Описание алгоритма эффекта.

            - `nil` - Значение по умолчанию `EA_MONOTONOUS_INCREASE`.

            - `number` - Значение `EA_*`.

            - `table` - Описание алгоритма `EA_*` с параметрами. Обязательное поле `type` (`number`) - значение `EA_*`. Набор полей зависит от алгоритма.

    Опциональные поля:

    - **`showOnStart`** (`boolean` | `nil`) - Показать виджет перед началом цепочки эффектов. По умолчанию `false`.

    - **`hideOnFinish`** (`boolean` | `nil`) - Скрыть виджет после окончания цепочки эффектов. По умолчанию `false`.

    - **`cycled`** (`boolean` | `nil`) - Зациклить цепочку эффектов. По умолчанию `false`.

    - **`sendStepEvent`** (`boolean` | `nil`) - Посылать событие об окончании каждого промежуточного шага эффекта (но не последнего). По умолчанию `false`.

    - **`sendFinishEvent`** (`boolean` | `nil`) - Послать событие об окончании цепочки эффектов. По умолчанию `false`.

    - **`eventLabel`** (`string` | `number` | `nil`) - Не влияет на работу цепочки эффектов. При наличии будет присылаться в событиях шага / окончания цепочки, приводится к строке. По умолчанию отсутствует.

    - **`startOffsetMs`** (`number` | `nil`) - `(int64)` С какой миллисекунды начать цепочку эффектов (может быть больше длительности цепочки, тогда `start = start % duration`). Нужно для синхронизации эффектов на разных виджетах. По умолчанию `0`.

## Возвращаемые значения

Возвращаемое значение отсутствует.

## Примеры

### Зацикленное перемещение виджета по сторонам квадрата

```lua
wt:PlayMoveEffectSequence( {
    { { posX = 0, posY = 0 }, { posX = 200, posY = 0 }, 500 },
    { nil, { posX = 200, posY = 200 }, 500 },
    { nil, { posX = 0, posY = 200 }, 500 },
    { nil, { posX = 0, posY = 0 }, 500 },
    cycled = true
} )
```
