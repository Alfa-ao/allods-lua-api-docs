# WidgetSafe:Rotate

Задает поворот текстур на всех слоях (против часовой стрелки).

## Описание

```lua
WidgetSafe:Rotate( radians: number )
```

Поворот возможен только для слоев с `WidgetLayerSimpleTexture`.

## Список параметров

- **`radians`** (`number`) - угол поворота против часовой стрелки (в радианах).

## Возвращаемые значения

Возвращаемое значение отсутствует.

## Примеры

### Поворот на pi

```lua
wtPanel:Rotate( 3.1416 )
```
