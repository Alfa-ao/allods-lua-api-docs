# WidgetSafe:RotateWithChildren

Поворачивает геометрию виджета на заданный угол вокруг его центра вместе с дочерними виджетами.

## Описание

```lua
WidgetSafe:RotateWithChildren( angle: number )
```

Функция поворачивает геометрию виджета на заданный угол вокруг его центра вместе с дочерними виджетами.

::: warning Замечание
Вращается лишь геометрия слоев. Тесты на попадания курсора в область используют оригинальный прямоугольник, поэтому использовать данную функцию для поворотов интерактивных виджетов не рекомендуется.
:::

::: warning Замечание
У базового вращающегося виджета и у дочерних необходимо сбрасывать `clipContent`, иначе содержимое будет обрезано после поворота.
:::

::: warning Замечание
Не рекомендуется перемещать повернутые виджеты, так как они вращаются вокруг запомненной точки на экране. После перемещения необходимо повторно вызвать данную функцию для перерасчета запомненной точки.
:::

::: tip Совет
Метод доступен у всех типов виджетов, однако проверен лишь на `panel` и `button`. У других типов виджетов могут быть свои слои, для которых не реализован поворот, что потребует доработки.
:::

## Список параметров

- **`angle`** (`number`) - Угол в радианах, на который поворачивается виджет.

## Возвращаемые значения

Возвращаемое значение отсутствует.

## Примеры

### Поворот виджета на 45 градусов

```lua
parent:RotateWithChildren( 3.141592653589793238 / 4 )
```
