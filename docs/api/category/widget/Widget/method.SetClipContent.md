# WidgetSafe:SetClipContent

Устанавливает режим обрезки дочерних виджетов по размерам текущего виджета.

## Описание

```lua
WidgetSafe:SetClipContent( clipContent: boolean )
```

Функция задает необходимость обрезки дочерних виджетов по границам текущего виджета.

## Список параметров

- **`clipContent`** (`boolean`) - `true`, если обрезать дочерние виджеты по размерам текущего виджета.

## Возвращаемые значения

Возвращаемое значение отсутствует.

## Примеры

### Включение обрезки дочерних виджетов

```lua
widget:SetClipContent( true )
```
