# WidgetSafe:SetFade

Задает прозрачность виджета.

## Описание

```lua
WidgetSafe:SetFade( fade: number )
```

Установка степени прозрачности виджета. В данный момент прозрачность не распространяется на дочерние контролы.

## Список параметров

- **`fade`** (`number`) - степень прозрачности от 0.0 до 1.0, где 1.0 - это полностью непрозрачный.

## Возвращаемые значения

Возвращаемое значение отсутствует.

## Примеры

### Установка непрозрачности

```lua
wtLabel:SetFade( 1.0 )
```
