# WidgetSafe:SetFocus

Устанавливает или снимает фокус с контрола.

## Описание

```lua
WidgetSafe:SetFocus( focus: boolean )
```

## Список параметров

- **`focus`** (`boolean`) - Указывает на необходимость установки или снятия фокуса с контрола.

## Возвращаемые значения

Возвращаемое значение отсутствует.

## Примеры

### Установка фокуса

```lua
wtElement:SetFocus( true )
```
