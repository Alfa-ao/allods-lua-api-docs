# WidgetSafe:SetName

Меняет имя контрола.

## Описание

```lua
WidgetSafe:SetName( name: string )
```

::: danger Функция возвращает ошибку
Если виджет является внутренним.
:::

## Список параметров

- **`name`** (`string`) - Имя контрола.

## Возвращаемые значения

Возвращаемое значение отсутствует.

## Примеры

### Изменение имени контрола

```lua
wtElement01:SetName( "NewName" )
```
