# WidgetSafe:SetOnShowNotification

Устанавливает режим присылки событий об изменении видимости контрола.

## Описание

```lua
WidgetSafe:SetOnShowNotification( notify: boolean )
```

Установка режима присылки событий требуется для оптимизации производительности, поскольку рассылка событий о видимости всех контролов системы без разбора требует неоправданно много ресурсов. Метод изменяет величину счётчика запросов на событие у заданного виджета, увеличивая его на 1 при необходимости присылки и уменьшая на 1 при отказе. События присылаются только при значении счётчика больше 0, что позволяет нескольким аддонам одновременно определять необходимость присылки.

## Список параметров

- **`notify`** (`boolean`) - При значении `true` событие `EVENT_WIDGET_SHOW_CHANGED` присылается для данного виджета, увеличивая счётчик запросов на 1. При значении `false` событие не присылается, а счётчик запросов уменьшается на 1.

## Возвращаемые значения

Возвращаемое значение отсутствует.

## Примеры

### Установка режима присылки событий

```lua
widget:SetOnShowNotification( notify )
```
