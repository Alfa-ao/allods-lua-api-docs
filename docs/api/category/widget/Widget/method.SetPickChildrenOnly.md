# WidgetSafe:SetPickChildrenOnly

Устанавливает флаг обработки мышиных реакций исключительно для дочерних виджетов.

## Описание

```lua
WidgetSafe:SetPickChildrenOnly( pickChildrenOnly: boolean )
```

Установка статуса pickChildrenOnly определяет обработку мышиных реакций только для дочерних виджетов с игнорированием самого родительского виджета.

## Список параметров

- **`pickChildrenOnly`** (`boolean`) - Указывает, необходимо ли обрабатывать мышиные реакции только для дочерних виджетов, игнорируя сам виджет.

## Возвращаемые значения

Возвращаемое значение отсутствует.

## Примеры

### Установка флага

```lua
wtTemplate:SetPickChildrenOnly( true )
```
