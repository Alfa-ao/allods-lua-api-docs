# WidgetSafe:SetPriority

Задает приоритет отрисовки контрола относительно других дочерних элементов.

## Описание

```lua
WidgetSafe:SetPriority( priority: number )
```

Функция устанавливает приоритет контрола. Контрол с большим приоритетом (среди других детей того же родителя) рисуется поверх контролов с более низким приоритетом.

::: danger Функция вернет ошибку, если выполняется любое из нижеследующих условий:
- Виджет является внутренним.
:::

## Список параметров

- **`priority`** (`number`) - приоритет контрола.

## Возвращаемые значения

Возвращаемое значение отсутствует.

## Примеры

### Установка приоритета контрола

```lua
wtElement:SetPriority( 10 )
```
