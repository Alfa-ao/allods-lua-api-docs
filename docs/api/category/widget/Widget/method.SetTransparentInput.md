# WidgetSafe:SetTransparentInput

Устанавливает, является ли виджет прозрачным для ввода.

## Описание

```lua
WidgetSafe:SetTransparentInput( transparentInput: boolean )
```

Функция устанавливает, является ли виджет прозрачным для ввода.

## Список параметров

- **`transparentInput`** (`boolean`) - `true`, если виджет должен быть прозрачным для ввода.

## Возвращаемые значения

Возвращаемое значение отсутствует.

## Примеры

### Установка прозрачности для ввода

```lua
wtTemplate:SetTransparentInput( true )
```
