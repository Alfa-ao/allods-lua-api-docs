# WidgetSafe:Show

Показывает или скрывает контрол и его потомков.

## Описание

```lua
WidgetSafe:Show( show: boolean )
```

Показывает или скрывает контрол и его потомков в зависимости от переданного флага.

## Список параметров

- **`show`** (`boolean`) - Флаг, определяющий необходимость показа или скрытия контрола.

## Возвращаемые значения

Возвращаемое значение отсутствует.

## Примеры

### Базовый вызов

```lua
wtCooldown:Show( true )
```
