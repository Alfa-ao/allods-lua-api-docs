## ADDON_STATE

Состояние аддона.

### Список значений

- **`ADDON_STATE_NOT_INITED`** (`number`) - аддон не загружен и еще не загружался. Ресурсы аддона не загружены. Аддоном можно управлять.

- **`ADDON_STATE_NOT_LOADED`** (`number`) - аддон сейчас не загружен, но уже загружался. Ресурсы аддона загружены. Аддоном можно управлять.

- **`ADDON_STATE_LOADING`** (`number`) - аддон находится в процессе загрузки. Аддоном нельзя управлять.

- **`ADDON_STATE_LOADED`** (`number`) - аддон загружен и активен. Аддоном можно управлять.

- **`ADDON_STATE_UNLOADING`** (`number`) - аддон находится в процессе выгрузки. Аддоном нельзя управлять.

- **`ADDON_STATE_RELOADING`** (`number`) - аддон находится в процессе перезагрузки. Аддоном нельзя управлять.
