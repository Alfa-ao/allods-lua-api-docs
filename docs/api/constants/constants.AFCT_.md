## AFCT

Определяет числовой тип условия или фильтра.

### Описание

Числовое перечисление, задающее базовые логические операции и типы условий.

### Список значений

- **`AFCT_Simple`** (`number`)

- **`AFCT_List`** (`number`)

- **`AFCT_Or`** (`number`)

- **`AFCT_And`** (`number`)

- **`AFCT_Pet`** (`number`)

- **`AFCT_Not`** (`number`)
