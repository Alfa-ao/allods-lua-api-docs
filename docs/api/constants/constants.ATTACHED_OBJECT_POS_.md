## ATTACHED_OBJECT_POS

Определяет место привязки к игровому объекту.

### Описание

Место привязки к игровому объекту, используемое для позиционирования дополнительных элементов или эффектов.

### Список значений

- **`ATTACHED_OBJECT_POS_BOTTOM`** (`number`) - Снизу.

- **`ATTACHED_OBJECT_POS_CENTER`** (`number`) - По центру.

- **`ATTACHED_OBJECT_POS_UP`** (`number`) - Сверху.
