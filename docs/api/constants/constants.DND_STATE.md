## DND_STATE

Числовое перечисление. Состояние виджета в системе drag&drop.

### Список значений

- **`DND_STATE_NOT_REGISTERED`** (`number`) - Виджет не зарегистрирован в системе drag&drop.

- **`DND_STATE_NOT_READY`** (`number`) - Виджет не готов к началу перемещения (система занята, перемещается другой виджет и т.п.).

- **`DND_STATE_READY`** (`number`) - Виджет готов к началу перемещения, попыток перемещения не зарегистрировано.

- **`DND_STATE_PREPARE`** (`number`) - Виджет готов к началу перемещения, возможно есть попытка перемещения (кнопка мыши нажата, но сдвига еще нет).

- **`DND_STATE_WAIT_PICK_CONFIRMATION`** (`number`) - Ожидается подтверждение на начало перемещения виджета.

- **`DND_STATE_DRAGGING`** (`number`) - Виджет в процессе перемещения.

- **`DND_STATE_WAIT_DROP_CONFIRMATION`** (`number`) - Ожидается подтверждение на завершение перемещения виджета.
