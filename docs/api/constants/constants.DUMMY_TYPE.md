## DUMMY_TYPE
Определяет тип контейнера с предметами, экипированными на персонаже игрока.

### Описание
Числовое перечисление.

### Список значений
- **`DUMMY_TYPE_PRIMARY`** (`number`) - Первичный набор экипировки.

- **`DUMMY_TYPE_SECONDARY`** (`number`) - Вторичный набор экипировки (первый набор экипировки для «драконьего облика»).

- **`DUMMY_TYPE_TERTIARY`** (`number`) - Третичный набор экипировки (второй набор экипировки для «драконьего облика»).

- **`DUMMY_TYPE_QUATERNARY`** (`number`) - Четвертичный набор экипировки (третий набор экипировки для «драконьего облика»).
