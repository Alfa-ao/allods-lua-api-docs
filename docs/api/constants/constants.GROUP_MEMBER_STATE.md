## GROUP_MEMBER_STATE
Определяет состояние члена группы.

### Описание
Числовое перечисление. Состояние `GROUP_MEMBER_STATE_NEAR` означает, что по игроку доступна вся информация. На самом деле, персонаж этого игрока может находиться где-то в нескольких «километрах» от аватара, но в пределах одного аллода, на котором они оба находятся. Состояние `GROUP_MEMBER_STATE_FAR` означает, что информация по игроку доступна лишь частично. Игрок находится на другом аллоде, возможно, в инстансе, или в Чистилище. Состояние `GROUP_MEMBER_STATE_OFFLINE` означает, что информацию по игроку получить невозможно, так как его id = nil. Игрок находится вне игры.

### Список значений
- **`GROUP_MEMBER_STATE_OFFLINE`** (`number`) - Игрок не находится в игре.

- **`GROUP_MEMBER_STATE_NEAR`** (`number`) - По игроку доступна вся информация.

- **`GROUP_MEMBER_STATE_FAR`** (`number`) - Игрок в игре, но информация по нему недоступна либо доступна только частично.

- **`GROUP_MEMBER_STATE_MERC`** (`number`) - Это не игрок, а NPC-наемник.

- **`GROUP_MEMBER_STATE_AFK`** (`number`) - Игрок в статусе AFK.
