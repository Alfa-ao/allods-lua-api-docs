## GUILD_SIMBOLICS_TEXTURE_TYPE
Определяет тип слоя с текстурой для гильдейской символики.

### Описание
Числовое перечисление. Значения приведены в порядке наложения текстурных слоев.

### Список значений
- **`GUILD_SIMBOLICS_TEXTURE_TYPE_PATTERN`** (`number`) - Field, гербовое поле (заливка гербового поля).

- **`GUILD_SIMBOLICS_TEXTURE_TYPE_EMBLEM1`** (`number`) - Fringe, оторочка (обрамление герба по краям).

- **`GUILD_SIMBOLICS_TEXTURE_TYPE_EMBLEM2`** (`number`) - CrestBase, основа (под фигуркой).

- **`GUILD_SIMBOLICS_TEXTURE_TYPE_EMBLEM3`** (`number`) - CrestFill, наполнение (между основой и фигуркой).

- **`GUILD_SIMBOLICS_TEXTURE_TYPE_EMBLEM4`** (`number`) - CrestFigure, фигурка (самый верхний элемент).
