## ITEMMALL_ITEM

Константы типов итеммольных предметов.

### Список значений

- **`ITEMMALL_ITEM_NOTITEMMALLABLE`** (`number`) - Предмет не из Лавки редкостей.

- **`ITEMMALL_ITEM_ITEMMALLABLE`** (`number`) - Предмет возможен в Лавке редкостей.

- **`ITEMMALL_ITEM_CREDIT`** (`number`) - Может выставляться в Лавке редкостей, но не выдает бонусов при покупке, так как может спелами начислить сумму (вексили и т.п.).

- **`ITEMMALL_ITEM_SELLABLE`** (`number`) - Предмет можно продать в Лавку редкостей за кристаллы (например, кошелёк с кристаллами).
