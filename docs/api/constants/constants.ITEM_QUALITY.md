## ITEM_QUALITY

Константы качества предмета.

### Описание

Список цветов, соответствующих этим константам в графическом оформлении интерфейсов.

### Список значений

- **`ITEM_QUALITY_SYSTEM`** (`number`) - Служебное значение, не означающее никакого качества.

- **`ITEM_QUALITY_JUNK`** (`number`) - Серый.

- **`ITEM_QUALITY_GOODS`** (`number`) - Белый.

- **`ITEM_QUALITY_COMMON`** (`number`) - Зеленый.

- **`ITEM_QUALITY_UNCOMMON`** (`number`) - Синий.

- **`ITEM_QUALITY_RARE`** (`number`) - Пурпурный (Фиолет).

- **`ITEM_QUALITY_EPIC`** (`number`) - Оранжевый.

- **`ITEM_QUALITY_LEGENDARY`** (`number`) - Изумрудный (Салат).

- **`ITEM_QUALITY_RELIC`** (`number`) - Лимонный.

- **`ITEM_QUALITY_DRAGON`** (`number`) - Розовый.
