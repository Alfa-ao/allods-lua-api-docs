## KBF

Числовое перечисление. Состояние модификаторов клавиатуры. Допустима комбинация нескольких модификаторов зажатых клавиш.

### Список значений

- **`KBF_NONE`** (`number`) - Нет модификаторов.

- **`KBF_SHIFT`** (`number`) - Зажата одна из клавиш Shift.

- **`KBF_ALT`** (`number`) - Зажата одна из клавиш Alt.

- **`KBF_CTRL`** (`number`) - Зажата одна из клавиш Ctrl.

- **`KBF_ANY`** (`number`) - Признак, что модификатор не имеет значения.

### Примеры

#### Проверка нажатия Shift

```lua
if bit.band(params.kbFlags, KBF_SHIFT) ~= 0 then
    LogInfo("Shift pressed")
end
```
