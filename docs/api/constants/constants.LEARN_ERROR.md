## LEARN_ERROR

Ошибка при изучении заклинания или умения у тренера.

### Список значений

- **`LEARN_ERROR_LOW_LEVEL`** (`number`)

- **`LEARN_ERROR_NO_CASH`** (`number`)

- **`LEARN_ERROR_NO_PREVIOS_RANKS`** (`number`)

- **`LEARN_ERROR_ALREADY_KNOWN`** (`number`)

- **`LEARN_ERROR_PREVIOS_TRAINING_UNFINISHED`** (`number`)
