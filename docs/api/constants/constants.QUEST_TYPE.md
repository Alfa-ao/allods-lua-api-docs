## QUEST_TYPE

Перечисление типа квеста.

### Список значений

- **`QUEST_TYPE_SOLO`** (`number`) - Квест-задание.

- **`QUEST_TYPE_PARTY`** (`number`) - Групповая миссия.

- **`QUEST_TYPE_RAID`** (`number`) - В рейд инстанс - кампания.

- **`QUEST_TYPE_MINI_RAID`** (`number`) - В мини рейд инстанс - кампания.
