## REPUTATION_LEVEL

Числовое перечисление для представления уровня репутации.

### Список значений

- **`REPUTATION_LEVEL_HOSTILITY`** (`number`)

- **`REPUTATION_LEVEL_ENEMY`** (`number`)

- **`REPUTATION_LEVEL_UNFRIENDLY`** (`number`)

- **`REPUTATION_LEVEL_NEUTRAL`** (`number`)

- **`REPUTATION_LEVEL_KINDLY`** (`number`)

- **`REPUTATION_LEVEL_FRIENDLY`** (`number`)

- **`REPUTATION_LEVEL_CONFIDENTIAL`** (`number`)
