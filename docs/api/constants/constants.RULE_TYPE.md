## RULE_TYPE

Тип внутриигрового эвента.

### Список значений

- **`RULE_TYPE_ACTION`** (`number`) - Рекламная акция и т.п.

- **`RULE_TYPE_HOLYDAY`** (`number`) - Праздники.

- **`RULE_TYPE_SINGLE`** (`number`) - Одиночные.

- **`RULE_TYPE_GROUP`** (`number`) - Групповые.

- **`RULE_TYPE_GUILD`** (`number`) - Гильдейские.
