## SPELLBOOK_PAGE

Константы типа страницы спеллбука для интерфейса.

### Список значений

- **`SPELLBOOK_PAGE_NORMAL`** (`number`) - Боевые спеллы.

- **`SPELLBOOK_PAGE_HALO`** (`number`) - Спеллы Покровителя.

- **`SPELLBOOK_PAGE_SPOUSE`** (`number`) - Семейные спеллы.

- **`SPELLBOOK_PAGE_OTHER`** (`number`) - Небоевые и прочие спеллы.
