## VENDOR

Тип торговца.

### Список значений

- **`VENDOR_NO_VENDOR`** (`number`) - Не торговец.

- **`VENDOR_GENERAL`** (`number`) - Обычный торговец с предметами неясного назначения.

- **`VENDOR_WEAPON_ARMOR`** (`number`) - Торговец оружием и броней.

- **`VENDOR_CRAFTING_COMPONENTS`** (`number`) - Торговец компонентами для крафтинга.

- **`VENDOR_USABLE_ITEMS`** (`number`) - Торговец используемыми предметами (еда, бутылки, ступки и т.п.).

- **`VENDOR_GUILD`** (`number`) - У торговца есть хотя бы один гильдейский предмет.

- **`VENDOR_MYRRH`** (`number`) - У торговца есть мирра.

- **`VENDOR_RUNE`** (`number`) - У торговца есть руны.

- **`VENDOR_BADGE`** (`number`) - Торговец продает товары за астральные баджики.
