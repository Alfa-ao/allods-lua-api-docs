## ZONE_TIER_DIFFICULTY

Сложность игровой зоны.

### Список значений

- **`ZONE_TIER_DIFFICULTY_DEFAULT`** (`number`) - Обычная.

- **`ZONE_TIER_DIFFICULTY_NONE`** (`number`) - Никакая.

- **`ZONE_TIER_DIFFICULTY_EASY`** (`number`) - Лёгкая.

- **`ZONE_TIER_DIFFICULTY_MEDIUM`** (`number`) - Средняя.

- **`ZONE_TIER_DIFFICULTY_HARD`** (`number`) - Тяжелая.

- **`ZONE_TIER_DIFFICULTY_INSANE`** (`number`) - Сверх тяжелая.
