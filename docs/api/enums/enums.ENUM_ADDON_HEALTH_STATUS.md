## ENUM_ADDON_HEALTH_STATUS

Определяет возможные статусы состояния аддона.

### Описание

Возможные статусы состояния аддона, используемые для оценки стабильности его работы.

### Список значений

- **`ENUM_ADDON_HEALTH_STATUS_GOOD`** (`number`) - Исполнение кода аддона не вызывает ошибок.

- **`ENUM_ADDON_HEALTH_STATUS_AVERAGE`** (`number`) - Исполнение кода аддона вызывает умеренное количество ошибок.

- **`ENUM_ADDON_HEALTH_STATUS_BAD`** (`number`) - Исполнение кода аддона вызывает чрезмерное количество ошибок.
