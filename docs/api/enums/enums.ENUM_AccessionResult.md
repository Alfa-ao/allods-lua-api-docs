## ENUM_AccessionResult

Определяет результат работы с именованными каналами.

### Описание

Текстовое перечисление, проверяется на билдере. Префикс для проверки - `ENUM_AccessionResult`.

### Список значений

- **`ENUM_AccessionResult_NoChat`** (`string`)

- **`ENUM_AccessionResult_Success`** (`string`)

- **`ENUM_AccessionResult_WrongFaction`** (`string`)

- **`ENUM_AccessionResult_AlreadyIn`** (`string`)
