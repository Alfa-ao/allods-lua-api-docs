## ENUM_AffectGroup

Определяет подмножества отношений между игроком и окружением.

### Описание

Подмножества отношений между игроком и окружением, используемые для фильтрации целей или получателей эффектов.

### Список значений

- **`ENUM_AffectGroup_All`** (`number`)

- **`ENUM_AffectGroup_Group`** (`number`)

- **`ENUM_AffectGroup_Raid`** (`number`)

- **`ENUM_AffectGroup_Friends`** (`number`)

- **`ENUM_AffectGroup_Enemies`** (`number`)
