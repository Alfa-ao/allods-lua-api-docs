## ENUM_AlignX

Определяет числовое значение горизонтального выравнивания.

### Описание

Числовое перечисление, задающее варианты горизонтального выравнивания текста или элементов интерфейса.

### Список значений

- **`ENUM_AlignX_DEFAULT`** (`number`)

- **`ENUM_AlignX_LEFT`** (`number`)

- **`ENUM_AlignX_CENTER`** (`number`)

- **`ENUM_AlignX_RIGHT`** (`number`)

- **`ENUM_AlignX_JUSTIFY`** (`number`)

- **`ENUM_AlignX_NONE`** (`number`)
