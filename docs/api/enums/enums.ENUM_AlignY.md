## ENUM_AlignY

Определяет числовое значение вертикального выравнивания.

### Описание

Числовое перечисление, задающее варианты вертикального выравнивания текста или элементов интерфейса.

### Список значений

- **`ENUM_AlignY_TOP`** (`number`)

- **`ENUM_AlignY_MIDDLE`** (`number`)

- **`ENUM_AlignY_BOTTOM`** (`number`)

- **`ENUM_AlignY_DEBUG`** (`number`)
