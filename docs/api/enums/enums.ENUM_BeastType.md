## ENUM_BeastType

Определяет типы монстров в личном приключении.

### Описание

Числовое и текстовое перечисление.

### Список значений

- **`ENUM_BeastType_AE`** (`number`) - Монстр с массовым уроном.

- **`ENUM_BeastType_Pack`** (`number`) - Группа монстров.

- **`ENUM_BeastType_Solo`** (`number`) - Одиночный монстр.

- **`ENUM_BeastType_Boss`** (`number`) - Босс.

- **`ENUM_BeastType_Endboss`** (`number`) - Финальный босс.

- **`ENUM_BeastType_AE`** (`string`) - Монстр с массовым уроном.

- **`ENUM_BeastType_Pack`** (`string`) - Группа монстров.

- **`ENUM_BeastType_Solo`** (`string`) - Одиночный монстр.

- **`ENUM_BeastType_Boss`** (`string`) - Босс.

- **`ENUM_BeastType_Endboss`** (`string`) - Финальный босс.
