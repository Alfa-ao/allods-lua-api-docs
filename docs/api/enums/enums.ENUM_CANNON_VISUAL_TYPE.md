## ENUM_CANNON_VISUAL_TYPE

Определяет тип визуального отображения пушек корабля на интерфейсе.

### Описание

Числовое перечисление.

### Список значений

- **`ENUM_CANNON_VISUAL_TYPE_CORVET`** (`number`) - Визуальный тип корвета.

- **`ENUM_CANNON_VISUAL_TYPE_BRIG`** (`number`) - Визуальный тип брига.
