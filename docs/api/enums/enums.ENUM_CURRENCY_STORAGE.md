## ENUM_CURRENCY_STORAGE

Определяет место хранения альтернативной валюты.

### Описание

Числовое перечисление.

### Список значений

- **`ENUM_CURRENCY_STORAGE_AVATAR`** (`number`) - У главного игрока.

- **`ENUM_CURRENCY_STORAGE_GUILD`** (`number`) - В гильдии.

- **`ENUM_CURRENCY_STORAGE_SOUL`** (`number`) - В душе (доступна для всех ремортов главного игрока).
