## ENUM_CURRENCY_VISUALIZE_MODE

Режимы отображения валюты.

### Список значений

- **`ENUM_CURRENCY_VISUALIZE_MODE_SHOW`** (`number`) - Всегда отображается (по умолчанию).

- **`ENUM_CURRENCY_VISUALIZE_MODE_HIDE`** (`number`) - Всегда скрывается (обработка валюты не будет передаваться в скрипты).

- **`ENUM_CURRENCY_VISUALIZE_MODE_CUSTOM`** (`number`) - Отображение управляется скриптами.
