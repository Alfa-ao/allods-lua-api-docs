## ENUM_ChatFailedType

Определяет причину, по которой не удалось отправить сообщение в чат.

### Описание

Текстовое перечисление. Префикс для автоматической проверки - `ENUM_ChatFailedType`.

### Список значений

- **`ENUM_ChatFailedType_Mute`** (`string`) - Игрок находится в муте.

- **`ENUM_ChatFailedType_InternalError`** (`string`) - Внутренняя ошибка системы.

- **`ENUM_ChatFailedType_Silence`** (`string`) - Игрок находится в режиме тишины.

- **`ENUM_ChatFailedType_NoPoints`** (`string`) - Недостаточно очков для отправки.

- **`ENUM_ChatFailedType_EnemyFaction`** (`string`) - Сообщение отправлено вражеской фракции.

- **`ENUM_ChatFailedType_Ignored`** (`string`) - Игрок находится в списке игнорируемых.
