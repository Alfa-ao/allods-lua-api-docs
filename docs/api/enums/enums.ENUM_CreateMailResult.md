## ENUM_CreateMailResult

Определяет результат создания письма.

### Описание

Текстовое перечисление. Префикс для автоматической проверки - `ENUM_CreateMailResult`.

### Список значений

- **`ENUM_CreateMailResult_Succeeded`** (`string`) - Письмо успешно создано.

- **`ENUM_CreateMailResult_InvalidMoneyAmount`** (`string`) - Некорректная сумма денег.

- **`ENUM_CreateMailResult_TooManyItemsAttached`** (`string`) - Прикреплено слишком много предметов.

- **`ENUM_CreateMailResult_UnknownReceiver`** (`string`) - Неизвестный получатель.

- **`ENUM_CreateMailResult_AbonentsCannotParticipateByMail`** (`string`) - Абоненты не могут участвовать в почтовой системе.

- **`ENUM_CreateMailResult_InternalSystemError`** (`string`) - Внутренняя ошибка системы.

- **`ENUM_CreateMailResult_NotEnoughMoney`** (`string`) - Недостаточно денег.

- **`ENUM_CreateMailResult_NotEnoughItems`** (`string`) - Недостаточно предметов.

- **`ENUM_CreateMailResult_NotEnoughMoneyAndItems`** (`string`) - Недостаточно денег и предметов.

- **`ENUM_CreateMailResult_NotTalkingToMailBox`** (`string`) - Диалог с почтовым ящиком не активен.

- **`ENUM_CreateMailResult_NoSubject`** (`string`) - Отсутствует тема письма.

- **`ENUM_CreateMailResult_ItemBound`** (`string`) - Предмет привязан к персонажу.
