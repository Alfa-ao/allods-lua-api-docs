## ENUM_CreatureStat

Определяет характеристики персонажа, не входящие в базовые врожденные статы.

### Описание

Числовое перечисление.

### Список значений

- **`ENUM_CreatureStat_HealthRegen`** (`number`) - Регенерация здоровья.

- **`ENUM_CreatureStat_ManaRegen`** (`number`) - Регенерация маны.

- **`ENUM_CreatureStat_Power`** (`number`) - Могущество.

- **`ENUM_CreatureStat_Wisdom`** (`number`) - Мудрость.

- **`ENUM_CreatureStat_Stamina`** (`number`) - Выносливость.
