## ENUM_CriticalMalfunctionType_CMT

Определяет код критической поломки корабля.

### Описание

Текстовое перечисление. Префикс для автоматической проверки - `ENUM_CriticalMalfunctionType_CMT`.

### Список значений

- **`ENUM_CriticalMalfunctionType_CMT_ReactorShutdown`** (`string`) - Реактор выключился от перегрева.

- **`ENUM_CriticalMalfunctionType_CMT_ManaBurst`** (`string`) - Произошел Mana Burst.

- **`ENUM_CriticalMalfunctionType_CMT_EngineShutdown`** (`string`) - Двигатель выключился.

- **`ENUM_CriticalMalfunctionType_CMT_RudderStuck`** (`string`) - Руль заклинило.

- **`ENUM_CriticalMalfunctionType_CMT_RudderBrokenLeft`** (`string`) - Руль не поворачивается влево.

- **`ENUM_CriticalMalfunctionType_CMT_RudderBrokenRight`** (`string`) - Руль не поворачивается вправо.

- **`ENUM_CriticalMalfunctionType_CMT_DoubleDeath`** (`string`) - Игрок в лазарете оставлен на второй срок.

- **`ENUM_CriticalMalfunctionType_CMT_CriticalMiss`** (`string`) - Пушка критически промахнулась.
