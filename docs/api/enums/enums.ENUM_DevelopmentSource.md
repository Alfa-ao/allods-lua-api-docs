## ENUM_DevelopmentSource

Определяет тип источника, с которого получен опыт для развития персонажа.

### Описание

Числовое и текстовое перечисление.

### Список значений

- **`ENUM_DevelopmentSource_Kill`** (`number`) - За убийство моба.

- **`ENUM_DevelopmentSource_Quest`** (`number`) - За выполнение задания.

- **`ENUM_DevelopmentSource_Cheat`** (`number`) - Чит.

- **`ENUM_DevelopmentSource_Fatigue`** (`number`) - За накопленный отдых.

- **`ENUM_DevelopmentSource_Impact`** (`number`) - Воздействие.

- **`ENUM_DevelopmentSource_ImpactDirect`** (`number`) - Прямое воздействие.

- **`ENUM_DevelopmentSource_Kill`** (`string`) - За убийство моба.
