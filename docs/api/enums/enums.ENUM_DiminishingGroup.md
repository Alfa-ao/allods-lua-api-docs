## ENUM_DiminishingGroup

Определяет группы контроля для механизма диминишинга.

### Описание

Числовое перечисление.

### Список значений

- **`ENUM_DiminishingGroup_Slow`** (`number`) - Замедление.

- **`ENUM_DiminishingGroup_Stun`** (`number`) - Оглушение, отталкивание.

- **`ENUM_DiminishingGroup_Fear`** (`number`) - Страх.

- **`ENUM_DiminishingGroup_Silence`** (`number`) - Немота, обезоруживание.

- **`ENUM_DiminishingGroup_Blind`** (`number`) - Ослепление, дезориентация.

- **`ENUM_DiminishingGroup_Disable`** (`number`) - Длительное обездвиживание, заморозка, усыпление, очарование, гипноз, астрал.
