## ENUM_DominationAreaState

Определяет состояния цели в режиме Domination.

### Описание

Числовое перечисление.

### Список значений

- **`ENUM_DominationAreaState_Free`** (`number`) - Не захвачена.

- **`ENUM_DominationAreaState_UnderAssault`** (`number`) - Осаждается.

- **`ENUM_DominationAreaState_Captured`** (`number`) - Захвачена.

- **`ENUM_DominationAreaState_AssaultFrozen`** (`number`) - Осада приостановлена.

- **`ENUM_DominationAreaState_Void`** (`number`) - Неопределенное состояние.
