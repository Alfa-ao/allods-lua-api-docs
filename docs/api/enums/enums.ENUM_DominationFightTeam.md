## ENUM_DominationFightTeam

Определяет команды в режиме Domination.

### Описание

Числовое перечисление.

### Список значений

- **`ENUM_DominationFightTeam_First`** (`number`) - Первая команда.

- **`ENUM_DominationFightTeam_Second`** (`number`) - Вторая команда.

- **`ENUM_DominationFightTeam_Null`** (`number`) - Пустая команда.
