## RESISTANCE

Перечисления для представления сопротивляемостей персонажа.

### Список значений

- **`RESISTANCE_ELEMENTAL`** (`number`)

- **`RESISTANCE_DIVINE`** (`number`)

- **`RESISTANCE_NATURE`** (`number`)

- **`RESISTANCE_PHYSICAL`** (`number`)

---

## ENUM_Element

### Описание

Текстовое перечисление автоматически проверяется на билдере. Префикс для проверки: `ENUM_Element`.

### Список значений

- **`ENUM_EELEMENTAL`** (`string`)

- **`ENUM_EDIVINE`** (`string`)

- **`ENUM_ENATURE`** (`string`)

- **`ENUM_EPHYSICAL`** (`string`)
