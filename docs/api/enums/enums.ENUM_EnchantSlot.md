## ENUM_EnchantSlot
Определяет тип слота, в который вставляется энчант.

### Описание
Числовое и текстовое перечисление.

### Список значений
- **`ENUM_EnchantSlot_Offence`** (`number`) - Слот атаки.

- **`ENUM_EnchantSlot_Defence`** (`number`) - Слот защиты.

- **`ENUM_EnchantSlot_Special`** (`number`) - Специальный слот.

- **`ENUM_EnchantSlot_Offence`** (`string`) - Слот атаки.

- **`ENUM_EnchantSlot_Defence`** (`string`) - Слот защиты.

- **`ENUM_EnchantSlot_Special`** (`string`) - Специальный слот.
