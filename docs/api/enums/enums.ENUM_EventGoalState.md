## ENUM_EventGoalState
Определяет текущее состояние задания процедурного данжа.

### Описание
Текстовое перечисление.

### Список значений
- **`ENUM_EventGoalState_Active`** (`string`) - В процессе выполнения.

- **`ENUM_EventGoalState_Success`** (`string`) - Успешно завершено.

- **`ENUM_EventGoalState_Failed`** (`string`) - Провалено.
