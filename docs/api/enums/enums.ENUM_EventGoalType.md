## ENUM_EventGoalType
Определяет тип задания процедурного данжа.

### Описание
Текстовое перечисление.

### Список значений
- **`ENUM_EventGoalType_KillMobs`** (`string`) - Охота на мобов.

- **`ENUM_EventGoalType_DefenceMobs`** (`string`) - Защита или сопровождение моба.

- **`ENUM_EventGoalType_Survive`** (`string`) - Выживание.

- **`ENUM_EventGoalType_ElementProgress`** (`string`) - Прогресс элементов.
