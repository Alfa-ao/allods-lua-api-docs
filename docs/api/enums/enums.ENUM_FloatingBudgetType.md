## ENUM_FloatingBudgetType
Определяет виды основных бюджетов статов.

### Описание
Числовое перечисление.

### Список значений
- **`ENUM_FloatingBudgetType_MainBudget`** (`number`) - Основной бюджет.

- **`ENUM_FloatingBudgetType_DefenceBudget`** (`number`) - Бюджет защиты.

- **`ENUM_FloatingBudgetType_OffenceBudget`** (`number`) - Бюджет атаки.
