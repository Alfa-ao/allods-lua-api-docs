## ENUM_GROUP_INVITE_FAILED
Определяет результат провальной попытки пригласить игрока в группу.

### Описание
Текстовое перечисление. Префикс для проверки - `ENUM_GROUP_INVITE_FAILED`.

### Список значений
- **`ENUM_GROUP_INVITE_FAILED_NOT_EXIST`** (`string`) - Игрока с заданным именем не существует.

- **`ENUM_GROUP_INVITE_FAILED_NOT_LOGGED_IN`** (`string`) - Игрока с заданным именем нет в игре.

- **`ENUM_GROUP_INVITE_FAILED_CANT_INVITE_SELF`** (`string`) - Нельзя приглашать себя.

- **`ENUM_GROUP_INVITE_FAILED_FULL_GROUP`** (`string`) - Нельзя приглашать игроков в полную группу.

- **`ENUM_GROUP_INVITE_FAILED_ALREADY_IN`** (`string`) - Указанный игрок уже состоит в группе.

- **`ENUM_GROUP_INVITE_FAILED_ZONE_NOT_ALLOWED`** (`string`) - Запрещено приглашение на этой зоне.

- **`ENUM_GROUP_INVITE_FAILED_NOT_LEADER`** (`string`) - Главный игрок состоит в группе и не является лидером. Он не может приглашать в группу.
