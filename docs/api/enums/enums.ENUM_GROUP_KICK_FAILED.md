## ENUM_GROUP_KICK_FAILED
Определяет результат провальной попытки выгнать игрока из группы.

### Описание
Текстовое перечисление. Префикс для проверки - `ENUM_GROUP_KICK_FAILED`.

### Список значений
- **`ENUM_GROUP_KICK_FAILED_NOT_IN_GROUP`** (`string`) - Главный игрок не состоит в группе.

- **`ENUM_GROUP_KICK_FAILED_OTHER_PLAYER_NOT_IN_GROUP`** (`string`) - Указанный игрок не состоит в группе главного игрока.

- **`ENUM_GROUP_KICK_FAILED_NOT_LEADER`** (`string`) - Главный игрок не является лидером группы.
