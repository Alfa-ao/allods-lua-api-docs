## ENUM_GUILD_RESULT
Определяет причину невыполнения действия с гильдией.

### Описание
Текстовое перечисление. Префикс для проверки - `ENUM_GUILD_RESULT`.

### Список значений
- **`ENUM_GUILD_RESULT_NOT_ENOUGH_RIGHTS`** (`string`) - Недостаточно прав.

- **`ENUM_GUILD_RESULT_CANT_CREATE_WRONG_GROUP_SIZE`** (`string`) - Некорректный размер группы для создания.

- **`ENUM_GUILD_RESULT_CANT_CREATE_GROUP_MEMBER_TOO_FAR`** (`string`) - Член группы находится слишком далеко.

- **`ENUM_GUILD_RESULT_CANT_CREATE_NO_GROUP`** (`string`) - Отсутствие группы.

- **`ENUM_GUILD_RESULT_CANT_CREATE_NOT_GROUP_LEADER`** (`string`) - Игрок не является лидером группы.

- **`ENUM_GUILD_RESULT_CANT_CREATE_PLAYER_ALREADY_IN_GUILD`** (`string`) - Игрок уже состоит в гильдии.

- **`ENUM_GUILD_RESULT_PLAYER_IS_NOT_IN_GUILD`** (`string`) - Игрок не состоит в гильдии.

- **`ENUM_GUILD_RESULT_PLAYER_ALREADY_IN_GUILD`** (`string`) - Игрок уже находится в гильдии.

- **`ENUM_GUILD_RESULT_CANT_OPERATE_WITH_THIS_RANK`** (`string`) - Невозможно выполнить операцию с данным рангом.

- **`ENUM_GUILD_RESULT_LEADER_CANT_LEAVE`** (`string`) - Лидер не может покинуть гильдию.

- **`ENUM_GUILD_RESULT_ALREADY_FULL`** (`string`) - Гильдия уже заполнена.

- **`ENUM_GUILD_RESULT_NO_GUILD`** (`string`) - Гильдия отсутствует.

- **`ENUM_GUILD_RESULT_BANK_NOT_EMPTY`** (`string`) - Банк гильдии не пуст.
