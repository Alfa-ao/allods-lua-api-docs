## ENUM_GlobalScalerType
Определяет тип единиц развития персонажа.

### Описание
Числовое и текстовое перечисление.

- **`ENUM_GlobalScalerType_MobExp`** (`number`) - Опыт за мобов.

- **`ENUM_GlobalScalerType_Authority`** (`number`) - Авторитет.

- **`ENUM_GlobalScalerType_QuestExp`** (`number`) - Опыт за задания.

- **`ENUM_GlobalScalerType_Reputation`** (`number`) - Репутация.

- **`ENUM_GlobalScalerType_QuestLoot`** (`number`) - Добыча за задания.

- **`ENUM_GlobalScalerType_AstralLoot`** (`number`) - Астральная добыча.

- **`ENUM_GlobalScalerType_WorldDrop`** (`number`) - Мировая добыча.
