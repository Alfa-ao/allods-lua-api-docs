## ENUM_GuildBankOperation
Определяет тип операции в гильдейском банке.

### Описание
Текстовое перечисление.

### Список значений
- **`ENUM_GuildBankOperation_RaiseFunds`** (`string`) - Сбор средств.

- **`ENUM_GuildBankOperation_TransferMoney`** (`string`) - Перевод денег.

- **`ENUM_GuildBankOperation_GetHistory`** (`string`) - Получение истории операций.
