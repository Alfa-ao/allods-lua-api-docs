## ENUM_GuildHistoryOrder
Определяет тип сортировки истории операций с гильдейским банком.

### Описание
Текстовое перечисление.

### Список значений
- **`ENUM_GuildHistoryOrder_OPERATIONTIME`** (`string`) - По времени.

- **`ENUM_GuildHistoryOrder_OPERATIONTYPE`** (`string`) - По типу операции.

- **`ENUM_GuildHistoryOrder_AFFECTEDMONEY`** (`string`) - По сумме денег.

- **`ENUM_GuildHistoryOrder_AVATARNAME`** (`string`) - По имени игрока.
