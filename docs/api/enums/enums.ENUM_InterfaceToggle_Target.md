## ENUM_InterfaceToggle_Target

Числовое перечисление, описывающее цель воздействия клиент-даты InterfaceToggle. Целью может быть отдельный аддон или целиком весь интерфейс для катсцен.

### Описание

Представляет маркер, описывающий состояние корабля.

### Список значений

- **`ENUM_InterfaceToggle_Target_All`** (`number`) - Весь интерфейс для катсцен.

- **`ENUM_InterfaceToggle_Target_ShipConstructionProgress`** (`number`) - Прогресс строительства корабля.

- **`ENUM_InterfaceToggle_Target_ShipRepairProgress`** (`number`) - Прогресс ремонта корабля.
