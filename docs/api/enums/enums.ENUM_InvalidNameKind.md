## ENUM_InvalidNameKind

Текстовое перечисление. Префикс для автоматической проверки - `ENUM_InvalidNameKind`.

### Описание

Причина недопустимости имени. Значение `ENUM_InvalidNameKind_None` приходит в случае удачного именования корабля вместе с параметром `success = true`.

### Список значений

- **`ENUM_InvalidNameKind_AlreadyInUse`** (`string`)

- **`ENUM_InvalidNameKind_InternalError`** (`string`)

- **`ENUM_InvalidNameKind_InvalidLength`** (`string`)

- **`ENUM_InvalidNameKind_InvalidSubstring`** (`string`)

- **`ENUM_InvalidNameKind_InvalidSymbols`** (`string`)

- **`ENUM_InvalidNameKind_None`** (`string`)
