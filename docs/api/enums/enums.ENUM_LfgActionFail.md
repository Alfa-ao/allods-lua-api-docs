## ENUM_LfgActionFail

Причина сбоя действия с LFG.

### Список значений

- **`ENUM_LfgActionFail_InvalidRole`** (`string`) - Выбрана не подходящая персонажу роль в группе.

- **`ENUM_LfgActionFail_InvalidDestination`** (`string`) - Невозможно отправиться в выбранную локацию.

- **`ENUM_LfgActionFail_LeaderRequire`** (`string`) - Инициировать отправку в выбранную локацию может только лидер группы.
