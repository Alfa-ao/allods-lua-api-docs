## ENUM_LotteryState

Состояние лотереи, розыгрыша.

### Список значений

- **`ENUM_LotteryState_Prepare`** (`number` | `string`) - До начала розыгрыша.

- **`ENUM_LotteryState_Roll`** (`number` | `string`) - Идет розыгрыш.

- **`ENUM_LotteryState_End`** (`number` | `string`) - Розыгрыш окончен.

- **`ENUM_LotteryState_Fail`** (`number` | `string`) - Ошибка.
