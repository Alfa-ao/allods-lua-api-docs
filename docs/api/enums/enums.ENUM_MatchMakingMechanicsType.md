## ENUM_MatchMakingMechanicsType

Тип игровой механики инстанс-ивента.

### Список значений

- **`ENUM_MatchMakingMechanicsType_UNKNOWN`** (`number`) - Тип неизвестен.

- **`ENUM_MatchMakingMechanicsType_BATTLEGROUND`** (`number`) - Баттлграунд.

- **`ENUM_MatchMakingMechanicsType_FOOTBALL`** (`number`) - Гоблинобол.

- **`ENUM_MatchMakingMechanicsType_SUMMERBOSS`** (`number`) - Летний босс.

- **`ENUM_MatchMakingMechanicsType_LASTSTAND`** (`number`) - Последний рубеж.

- **`ENUM_MatchMakingMechanicsType_CAPTURE_POINTS`** (`number`) - Захват точек.

- **`ENUM_MatchMakingMechanicsType_RATING_ARENA`** (`number`) - Рейтинговая арена.

- **`ENUM_MatchMakingMechanicsType_ANNIVERSARY_EVENT`** (`number`) - Юбилейный ивент.

- **`ENUM_MatchMakingMechanicsType_GLADIATOR_ARENA`** (`number`) - Гладиаторская арена.

- **`ENUM_MatchMakingMechanicsType_DOMINATION`** (`number`) - Доминион.
