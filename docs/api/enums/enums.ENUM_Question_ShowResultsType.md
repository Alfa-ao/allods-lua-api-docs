## ENUM_Question_ShowResultsType

Определяет способ отображения результатов голосования.

### Список значений

- **`ENUM_Question_ShowResultsType_None`** (`number`) - результаты выводить не нужно.

- **`ENUM_Question_ShowResultsType_All`** (`number`) - результаты нужно выводить.

- **`ENUM_Question_ShowResultsType_Anonymous`** (`number`) - результаты нужно выводить анонимно.
