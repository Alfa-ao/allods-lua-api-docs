## ENUM_QuizQuestionType

Определяет типы вопросов для викторины.

### Список значений

- **`ENUM_QuizQuestionType_UNSPECIFIC`** (`number`) - произвольный опрос.

- **`ENUM_QuizQuestionType_VOTE_KICK`** (`number`) - голосование за кик.

- **`ENUM_QuizQuestionType_CHOICE_ROLES`** (`number`) - требуется выбрать роль.
