## ENUM_RAID_FAILED

Причина невыполнения действия с рейдом.

### Описание

Текстовое перечисление, проверяется на билдере. Префикс для проверки `ENUM_RAID_FAILED`.

### Список значений

- **`ENUM_RAID_FAILED_NOT_ENOUGH_RIGHTS`** (`string`)

- **`ENUM_RAID_FAILED_PLAYER_IS_NOT_IN_RAID`** (`string`)

- **`ENUM_RAID_FAILED_PLAYER_ALREADY_IN_RAID`** (`string`)

- **`ENUM_RAID_FAILED_LEADER_CANT_LEAVE`** (`string`)

- **`ENUM_RAID_FAILED_ZONE_NOT_ALLOWED`** (`string`)

- **`ENUM_RAID_FAILED_ALREADY_FULL`** (`string`)
