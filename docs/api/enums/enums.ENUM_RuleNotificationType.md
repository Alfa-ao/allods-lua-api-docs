## ENUM_RuleNotificationType

Тип нотификации на HUD об внутриигровом эвенте.

### Список значений

- **`ENUM_RuleNotificationType_Default`** (`number` | `string`) - Просто какое-то событие в календаре.

- **`ENUM_RuleNotificationType_Box`** (`number` | `string`) - Шкатулка.

- **`ENUM_RuleNotificationType_Chest`** (`number` | `string`) - Ларец.

- **`ENUM_RuleNotificationType_CrystalSale`** (`number` | `string`) - Распродажа кристаллов.

- **`ENUM_RuleNotificationType_PriceChanging`** (`number` | `string`) - Изменение цены на товары в ИМ.

- **`ENUM_RuleNotificationType_New`** (`number` | `string`) - Новый ассортимент в ИМ.
