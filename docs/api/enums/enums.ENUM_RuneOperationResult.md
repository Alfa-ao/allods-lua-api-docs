## ENUM_RuneOperationResult

Текстовое перечисление для представления результата операции с руной.

### Описание

Перечисление автоматически проверяется на билдере. Префикс для проверки `ENUM_RuneOperationResult`.

### Список значений

- **`ENUM_RuneOperationResult_SlotNumberOutOfBounds`** (`string`)

- **`ENUM_RuneOperationResult_SlotIsEmpty`** (`string`)

- **`ENUM_RuneOperationResult_ItemIsNotExtractor`** (`string`)

- **`ENUM_RuneOperationResult_ItemHasNoRune`** (`string`)

- **`ENUM_RuneOperationResult_WrongInstrumentLevel`** (`string`)

- **`ENUM_RuneOperationResult_NoFreeSpace`** (`string`)

- **`ENUM_RuneOperationResult_SecondRuneNotFound`** (`string`)

- **`ENUM_RuneOperationResult_ItemIsNotCombiner`** (`string`)

- **`ENUM_RuneOperationResult_ItemIsNotRune`** (`string`)

- **`ENUM_RuneOperationResult_ItemAlreadyHasRune`** (`string`)

- **`ENUM_RuneOperationResult_CannotInsertIntoThis`** (`string`)

- **`ENUM_RuneOperationResult_NoHigherLevelRune`** (`string`)

- **`ENUM_RuneOperationResult_OperationFailed`** (`string`)

- **`ENUM_RuneOperationResult_NotEnoughRunes`** (`string`)

- **`ENUM_RuneOperationResult_OperationSuccess`** (`string`)
