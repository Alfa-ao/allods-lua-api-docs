## ENUM_TakeItemActionType

Тип получения предмета игроком.

### Описание

Текстовое перечисление. Префикс для автоматической проверки - `ENUM_TakeItemActionType`.

### Список значений

- **`ENUM_TakeItemActionType_Loot`** (`string`) - Предмет пришёл из лута.

- **`ENUM_TakeItemActionType_Quest`** (`string`) - Предмет получен или забран квестом (выдан в начале, забран в конце, ревард).

- **`ENUM_TakeItemActionType_QuestAbandon`** (`string`) - Итем забрали по причине отказа от квеста.

- **`ENUM_TakeItemActionType_Spell`** (`string`) - Итем появился или исчез по причине каста спела.

- **`ENUM_TakeItemActionType_Vendor`** (`string`) - Итем появился или исчез при разговоре с вендором.

- **`ENUM_TakeItemActionType_Craft`** (`string`) - При каком-то крафтинге (итем взят из крафт бега).

- **`ENUM_TakeItemActionType_Mail`** (`string`) - Из почты.

- **`ENUM_TakeItemActionType_Drop`** (`string`) - Игрок выкинул итем.

- **`ENUM_TakeItemActionType_SelfAnnihilation`** (`string`) - Итем был уничтожен по времени.

- **`ENUM_TakeItemActionType_Money`** (`string`) - Простая операция с деньгами.

- **`ENUM_TakeItemActionType_Box`** (`string`)

- **`ENUM_TakeItemActionType_RuneCombine`** (`string`)

- **`ENUM_TakeItemActionType_SkilledItemGeneration`** (`string`)

- **`ENUM_TakeItemActionType_AuctionBet`** (`string`) - Игрок делает ставку.

- **`ENUM_TakeItemActionType_AuctionCreate`** (`string`) - Игрок выставляет предмет на аукцион и с него берут залог.

- **`ENUM_TakeItemActionType_AuctionBuyout`** (`string`) - Игрок выкупает предмет на аукционе.

- **`ENUM_TakeItemActionType_Other`** (`string`)

- **`ENUM_TakeItemActionType_CurrencyExchange`** (`string`)

- **`ENUM_TakeItemActionType_Mentor`** (`string`)

- **`ENUM_TakeItemActionType_ItemMall`** (`string`)
