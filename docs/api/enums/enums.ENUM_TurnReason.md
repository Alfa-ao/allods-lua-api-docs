## ENUM_TurnReason

Причина, по которой устройство выключено.

### Описание

Текстовое перечисление, проверяется на билдере. Префикс для проверки `ENUM_TurnReason`.

### Список значений

- **`ENUM_TR_Broken`** (`string`)

- **`ENUM_TR_Abordage`** (`string`)

- **`ENUM_TR_Silence`** (`string`)

- **`ENUM_TR_InterHubAcceleration`** (`string`)

- **`ENUM_TR_Construction`** (`string`)

- **`ENUM_TR_InHangar`** (`string`)

- **`ENUM_TR_TeleportToIsland`** (`string`)

- **`ENUM_TR_Teleport`** (`string`)

- **`ENUM_TR_Malfunction`** (`string`)

- **`ENUM_TR_ReactorsShutdown`** (`string`)

- **`ENUM_TR_ShipDestroyed`** (`string`)

- **`ENUM_TR_Init`** (`string`)
