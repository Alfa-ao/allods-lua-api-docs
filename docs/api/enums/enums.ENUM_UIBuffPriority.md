## ENUM_UIBuffPriority

Интерфейсный приоритет бафа. Гарантируется строгий порядок, можно сравнивать как числа. Большее значение означает более высокий приоритет.

### Список значений

- **`ENUM_UIBuffPriority_Low`** (`number`) - Низкий приоритет.

- **`ENUM_UIBuffPriority_Normal`** (`number`) - По умолчанию.

- **`ENUM_UIBuffPriority_Medium`** (`number`)

- **`ENUM_UIBuffPriority_High`** (`number`)

- **`ENUM_UIBuffPriority_Absolute`** (`number`) - Отображается специальной отдельной иконкой. Действует соглашение, что такой баф может висеть только 1.
