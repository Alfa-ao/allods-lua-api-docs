## ENUM_UpgradeChanceBehavior

Текстовое и числовое перечисление. Префикс для автоматической проверки - `ENUM_UpgradeChanceBehavior`.

### Описание

Что происходит при срабатывании шанса особо улучшить метапредмет.

### Список значений

- **`ENUM_UpgradeChanceBehavior_MaximizeImprovement`** (`number` | `string`) - Моментальное улучшение.

- **`ENUM_UpgradeChanceBehavior_DoubleImprovement`** (`number` | `string`) - Удвоение величины улучшения.
