## CategoryEnums

Различные енумы (перечисления) Lua API.

Енумы могут быть целочисленными, либо строковыми. Часть енумов может автоматически проверяться на билдере на соответствие описаниям их в базе. В случае расхождения будут показаны все несоответствия. Сейчас автоматическая проверка возможна для RelatedTexts, каждому такому енуму должен соответствовать отдельный *.xdb.

Помимо перечислений, объявленных в скрипте, есть глобальные переменные - перечисления, объявленные в коде.
