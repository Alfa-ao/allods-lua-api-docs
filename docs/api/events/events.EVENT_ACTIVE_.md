## EVENT_ACTIVE_MOUNT_CHANGED

Событие посылается при изменении активного ездового животного главного игрока.

### Описание

```lua
EVENT_ACTIVE_MOUNT_CHANGED
```

Событие посылается каждый раз, когда у главного игрока меняется активное ездовое животное (он садится на него или спешивается).

### Список параметров

Параметры отсутствуют.

### Возвращаемые значения

Возвращаемое значение отсутствует.

## EVENT_ACTIVE_MOUNT_TIME_LEFT_CHANGED

Событие посылается при кардинальном изменении времени жизни активного ездового животного.

### Описание

```lua
EVENT_ACTIVE_MOUNT_TIME_LEFT_CHANGED
```

Событие посылается каждый раз, когда у главного игрока кардинально меняется время жизни ездового животного (сколько времени осталось до исчезновения этого животного из конюшни). Событие приходит только в том случае, если время меняется скачком на большую величину по каким-либо причинам на сервере. Стандартные периодические изменения на одну секунду не вызывают это событие.

### Список параметров

Параметры отсутствуют.

### Возвращаемые значения

Возвращаемое значение отсутствует.

## EVENT_ACTIVE_PET_EXIST_CHANGED

Событие посылается при изменении активного питомца, передавая информацию о его предыдущем типе.

### Описание

```lua
EVENT_ACTIVE_PET_EXIST_CHANGED
```

Событие посылается каждый раз, когда у главного игрока меняется активный питомец. Является близким аналогом `EVENT_ACTIVE_PET_CHANGED`. Если вы не понимаете разницу между данным событием и `EVENT_ACTIVE_PET_CHANGED`, то данное событие использовать не следует.

### Список параметров

- **`lastType`** (`number`) - предыдущий тип питомца. Соответствует одному из значений перечисления `PET_TYPE_...`:
  - `PET_TYPE_UNKNOWN`
  - `PET_TYPE_NECROMANCER`
  - `PET_TYPE_DRUID`
  - `PET_TYPE_PSIONIC`

### Возвращаемые значения

Возвращаемое значение отсутствует.
