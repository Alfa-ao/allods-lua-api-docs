# EVENT_ADDON_*

## EVENT_ADDON_HEALTH_CHANGED

Событие присылается при изменении показателей состояния аддона.

### Описание

```lua
EVENT_ADDON_HEALTH_CHANGED
```

Основным показателем состояния является **статус состояния аддона** - количество ассертов, возбуждаемых исполнением кода скрипта аддона. В зависимости от количества и частоты возбуждаемых ассертов статус состояния может принимать значения в диапазоне `ENUM_ADDON_HEALTH_STATUS_...`.

Отслеживание состояния аддонов необходимо вследствие того, что некоторые из них имеют ошибки в коде, создающие чрезмерную спам-нагрузку на интерфейс клиента.

### Список параметров

- **`sysName`** (`string`) - системное имя аддона.

- **`status`** (`number`) - статус состояния аддона.

### Возвращаемые значения

Обработка события производится в зарегистрированном обработчике.

## EVENT_ADDON_LOAD_STATE_CHANGED

Уведомление об изменении состояния аддона.

### Описание

```lua
EVENT_ADDON_LOAD_STATE_CHANGED
```

Список возможных состояний смотри в перечислении `AddonState`.

### Список параметров

- **`name`** (`string`) - системное имя аддона.

- **`state`** (`number`) - новое состояние аддона (соответствует перечислению `AddonState`).

- **`isUserAddon`** (`boolean`) - является ли аддон пользовательским.

### Возвращаемые значения

Обработка события производится в зарегистрированном обработчике.

## EVENT_ADDON_REDUCE_PERFOMANCE

Событие присылается, когда система фиксирует критически большое ухудшение производительности клиента из-за конкретного аддона.

### Описание

```lua
EVENT_ADDON_REDUCE_PERFOMANCE
```

### Список параметров

- **`sysName`** (`string`) - системное имя аддона.

- **`timeMs`** (`number`) - среднее время обработки события аддоном (в миллисекундах).

- **`deltaFps`** (`number`) - приблизительное количество кадров в секунду, которые отнимает аддон.

- **`maxDeltaFps`** (`number`) - максимальное количество кадров в секунду, которые отнимал аддон.

### Возвращаемые значения

Обработка события производится в зарегистрированном обработчике.
