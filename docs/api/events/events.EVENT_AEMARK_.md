## EVENT_AEMARK_POINT_CLICKED

### Описание

```
EVENT_AEMARK_POINT_CLICKED
```

Событие присылается при клике в террейн при активном AEMark.

### Список параметров

В обработчик события передается таблица `GamePosition` со следующими полями:
- **`posX`** (`number`) - координата по X.
- **`posY`** (`number`) - координата по Y.
- **`posZ`** (`number`) - координата по Z.
