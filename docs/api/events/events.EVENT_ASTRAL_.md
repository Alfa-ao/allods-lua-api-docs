## EVENT_ASTRAL_SECTOR_CHECK_JUMP_RESULT

### Описание

```
EVENT_ASTRAL_SECTOR_CHECK_JUMP_RESULT
```

Событие возвращает результат проверки группы на возможность совершения прыжка в выбранный сектор астрала до выбранной POI.

### Список параметров

- **`id`** (`ObjectId`) - идентификатор выбранной POI.

- **`sectorId`** (`AstralSectorId`) - сектор астрала, которому принадлежит выбранная POI.

- **`isSuccess`** (`boolean`) - `true`, если прыжок доступен. Проверка завершилась успешно.

- **`failEntries`** (`table` | `nil`) - если `isSuccess == true`, то `nil`. Список причин провала проверки (индексирован с 1), каждый элемент которого является таблицей с полями:
    - **`failType`** (`string`) - тип неудовлетворенного требования `ENUM_FailType_...`.
    - **`names`** (`table`) - список имен аватаров (индексирован с 1), не удовлетворяющих требованию `failType`.

### Смотрите также

- [astral.CheckJump](/api/category/astral/function.astral.CheckJump.md)
- [ENUM_FailType](/api/enums/enums.ENUM_FailType.md)
