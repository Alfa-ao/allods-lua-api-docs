## EVENT_BEAM_CANNON_SHOT_STARTED

### Описание

```
EVENT_BEAM_CANNON_SHOT_STARTED
```

Событие посылается в момент выстрела (тика) из лучемета. В этот момент уже известно, есть попадания или нет. Если попаданий нет, то `targets` равен `nil`.

### Список параметров

- **`id`** (`ObjectId`) - Идентификатор устройства (тип устройства `USDEV_BEAM_CANNON`).

- **`targets`** (`table` | `nil`) - Таблица (индексированная с 1) идентификаторов (`ObjectId`) целей. Если попаданий нет, то `nil`.
