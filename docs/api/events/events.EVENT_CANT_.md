## EVENT_CANT_LEAVE_GAME_IN_COMBAT

### Описание

```
EVENT_CANT_LEAVE_GAME_IN_COMBAT
```

Событие, уведомляющее о невозможности выхода из игры, если персонаж находится в бою.

### Список параметров

Параметры отсутствуют.

## EVENT_CANT_LOOT_DISAPPEARED_LOOT_BAG

### Описание

```
EVENT_CANT_LOOT_DISAPPEARED_LOOT_BAG
```

Сообщение о невозможности получить лут с исчезнувшего объекта. Например, кто-то уже получил лут с сундука или моба до того, как сервер успел сообщить об этом клиенту.

### Список параметров

Параметры отсутствуют.

## EVENT_CANT_SEND_CHAT_BY_DELAY

### Описание

```
EVENT_CANT_SEND_CHAT_BY_DELAY
```

Уведомление о невозможности отправить сообщение в чат. Сообщения нельзя отсылать чаще, чем через определенный интервал времени для предотвращения спама.

### Список параметров

- **`delayMs`** (`number`) - Допустимый интервал между сообщениями в чат в миллисекундах.
