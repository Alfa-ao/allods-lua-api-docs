## EVENT_CAN_CREATE_GUILD_HERE_RESPONSE

### Описание

Событие передается в ответ на запрос проверки возможности создания гильдии `guild.CanCreateGuildHereRequest` в текущем месте с использованием заданного предмета.

### Поля события

- **`success`** (`boolean`) - можно ли создать гильдию в данном месте.
