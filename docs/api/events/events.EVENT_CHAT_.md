## EVENT_CHAT_AVATAR_MUTED

### Описание

```
EVENT_CHAT_AVATAR_MUTED
```

Событие посылается, когда аватар лишен права писать сообщения в чат.

### Список параметров

- **`reason`** (`WString`) - причина.

- **`durationMinutes`** (`number`) - продолжительность в минутах.

- **`time`** (`table`) - таблица с информацией о времени отправки сообщения (локальное время сервера).
    - **`h`** (`number`) - час.
    - **`m`** (`number`) - минута.
    - **`s`** (`number`) - секунда.

## EVENT_CHAT_MESSAGE

[<Badge type="warning" text="^17.1.*" />](/index.md#17.0.0-UniqueId) [<Badge type="warning" text="^18.0.0" />](/index.md#17.0.0-UniqueId) <Badge type="warning" text="Process" />

### Описание

```
EVENT_CHAT_MESSAGE
```

Событие посылается для каждого нового сообщения, пришедшего в чат. Если сообщение является эхом (включено в настройках по умолчанию), то это то сообщение, которое мы изначально попытались отправить.

Событие содержит сокращенную информацию о событии - только текст. Более подробная информация содержится в событии `EVENT_CHAT_MESSAGE_WITH_OBJECTS`.

::: warning Замечание
В пользовательских аддонах есть ограничение: событие может не приходить на турнирах.
:::

### Список параметров

- **`sender`** (`WString`) - имя отправителя (игрока или моба).

- **`shard`** (`WString`) - название сервера отправителя.

- **`senderUniqueId`** (`UniqueId` | `nil`) - уникальный идентификатор персонажа-отправителя.
- **`senderId`** (`ObjectId` | `nil`) - идентификатор персонажа-отправителя или `nil`, если данная информация недоступна (например, если игрок не отреплицирован).
- **`chatType`** (`number`) - тип сообщения (`CHAT_TYPE_...`).
- **`isEcho`** (`boolean`) - является ли сообщение эхом.
- *Для `CHAT_TYPE_WHISPER` (только для эха):*
    - **`recipient`** (`WString`) - имя получателя.
- **`isAlive`** (`boolean`) - жив игрок (может действовать) или нет (мертв или в чистилище).
- **`msg`** (`WString`) - текст сообщения.
- **`spamWeight`** (`number`) - спам-вес сообщения. Если меньше 100, то не спам, иначе - спам.

## EVENT_CHAT_MESSAGE_IS_FLOOD

### Описание

```
EVENT_CHAT_MESSAGE_IS_FLOOD
```

Событие, которое приходит при невозможности отослать сообщение в чат, поскольку сообщение подпадает под критерии флуда (множество одинаковых сообщений, следующих с высокой частотой).

### Список параметров

- **`cooldownMs`** (`number`) - время (в миллисекундах), которое должно пройти до момента, когда сообщение может быть послано в чат.

## EVENT_CHAT_MESSAGE_REJECTED

### Описание

```
EVENT_CHAT_MESSAGE_REJECTED
```

Событие, которое приходит при невозможности доставить сообщение в чат.

### Список параметров

- **`sysReason`** (`string`) - причина неудачной отправки сообщения (`ENUM_ChatFailedType_...`).
- **`time`** (`table`) - таблица с информацией о времени прихода сообщения.
    - **`h`** (`number`) - часы.
    - **`m`** (`number`) - минуты.
    - **`s`** (`number`) - секунды.
- **`expiredTime`** (`table` | `nil`) - если ограничения нет, то `nil`, иначе таблица с полями о том, сколько времени осталось.
    - **`d`** (`number`) - дней.
    - **`h`** (`number`) - часов.
    - **`m`** (`number`) - минут.
    - **`s`** (`number`) - секунд.

::: info Примечание
В случае `sysReason == "ENUM_ChatFailedType_Mute"` (игрока забанили в чате) в `expiredTime` прописано, сколько времени осталось до окончания бана. Если бан вечный, то поле `expiredTime` отсутствует.
:::

### Смотрите также

- [`ENUM_ChatFailedType_...`](/api/enums/enums.ENUM_ChatFailedType.md)

## EVENT_CHAT_MESSAGE_WITH_OBJECTS

[<Badge type="warning" text="^17.1.*" />](/index.md#17.0.0-UniqueId) [<Badge type="warning" text="^18.0.0" />](/index.md#17.0.0-UniqueId) <Badge type="warning" text="Process" />

### Описание

```
EVENT_CHAT_MESSAGE_WITH_OBJECTS
```

Событие посылается для каждого нового сообщения, пришедшего в чат. Если сообщение является эхом (включено в настройках по умолчанию), то это то сообщение, которое мы изначально попытались отправить.

Событие приходит вместе с `EVENT_CHAT_MESSAGE` и содержит более полную информацию - текст и предметы.

::: warning Замечание
В пользовательских аддонах есть ограничение: событие может не приходить на турнирах.
:::

### Список параметров
- **`sender`** (`WString`) - имя отправителя (игрока или моба).
- **`shard`** (`WString`) - название сервера отправителя.
- **`senderUniqueId`** (`UniqueId` | `nil`) - уникальный идентификатор персонажа-отправителя.
- **`senderId`** (`ObjectId` | `nil`) - идентификатор персонажа-отправителя или `nil`, если данная информация недоступна (например, если игрок не отреплицирован).
- **`recipientUniqueId`** (`UniqueId` | `nil`) - уникальный идентификатор персонажа-получателя или `nil`, если данная информация недоступна.
- **`recipientId`** (`ObjectId` | `nil`) - идентификатор персонажа-получателя или `nil`, если данная информация недоступна.
- **`chatType`** (`number`) - тип сообщения (`CHAT_TYPE_...`).
- **`isEcho`** (`boolean`) - является ли сообщение эхом.
- **`time`** (`table`) - таблица с информацией о времени отправки сообщения (локальное время сервера).
    - **`h`** (`number`) - час.
    - **`m`** (`number`) - минута.
    - **`s`** (`number`) - секунда.
- *Для `CHAT_TYPE_WHISPER` (только для эха):*
    - **`recipient`** (`WString`) - имя получателя.
- **`isAlive`** (`boolean`) - жив игрок (может действовать) или нет (мертв или в чистилище).
- **`messages`** (`table`) - таблица, индексированная `[0..]`, содержащая таблицы с информацией о фрагментах сообщения:
    - **`text`** (`WString` | `nil`) - если не `nil`, то текстовый фрагмент.
    - **`spamWeight`** (`number` | `nil`) - спам-вес для текстового фрагмента сообщения. Если меньше 100, то не спам, иначе - спам.
    - **`item`** (`ValuedObject` | `nil`) - если не `nil`, то подстановочный объект, содержащий информацию о предмете.
    - **`medal`** (`ValuedObject` | `nil`) - если не `nil`, то подстановочный объект, содержащий информацию о достижении.

### Смотрите также

## EVENT_CHAT_SENT_TO_ALT

### Описание

```
EVENT_CHAT_SENT_TO_ALT
```

Событие посылается в случае отсылки личного сообщения игроку, который в данный момент находится в игре под своим альтернативным персонажем.

### Список параметров

- **`altName`** (`WString`) - имя альтернативного персонажа, который на самом деле получит сообщение.
