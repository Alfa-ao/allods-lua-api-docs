## EVENT_CHEST_LOOTER_CHANGED

Событие посылается при изменении состояния устройства. Например, устройство кто-то стал использовать.

### Описание

```
EVENT_CHEST_LOOTER_CHANGED
```

Событие посылается при изменении состояния устройства. Например, устройство кто-то стал использовать.

### Список параметров

- **`deviceId`** (`number`) - id устройства.
