## EVENT_CONTEXT_ACTION_POINT_STARTED

### Описание

```
EVENT_CONTEXT_ACTION_POINT_STARTED
```

Событие присылается, если необходимо начать отслеживание точки применения контекстного действия.

### Список параметров

- **`id`** (`ObjectId`) - идентификатор контекстного действия.

***

## EVENT_CONTEXT_ACTIONS_CHANGED

Событие присылается при изменении контекстных действий.

### Описание

```
EVENT_CONTEXT_ACTIONS_CHANGED
```

Событие присылается при изменении контекстных действий. Мог измениться список контекстных действий или флаг enabled какого-либо контекстного действия.

### Список параметров

Параметры отсутствуют.
