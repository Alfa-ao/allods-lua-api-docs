## EVENT_CUSTOM_EMOTE

### Описание

```
EVENT_CUSTOM_EMOTE
```

Текстовая эмоция (`/emote`) от другого игрока.

### Список параметров

- **`id`** (`ObjectId`) - Идентификатор игрока, от которого пришло сообщение. Не может быть `nil`.

- **`targetId`** (`ObjectId` | `nil`) - Идентификатор цели сообщения или `nil`, если цель не указана.

- **`text`** (`WString`) - Текстовое сообщение.

- **`isAlive`** (`boolean`) - Флаг состояния игрока. `true`, если игрок жив и может действовать; `false`, если игрок мертв или находится в чистилище.
