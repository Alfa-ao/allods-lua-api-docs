## EVENT_DISBAND_GUILD_REQUEST

### Описание

```
EVENT_DISBAND_GUILD_REQUEST
```

Запрос на роспуск гильдии от игрока. Приходит, например, при выполнении слеш-команды роспуска гильдии. Ожидаемая обработка - запрос игроку на подтверждение роспуска и отдача команды серверу на собственно роспуск.

Событие `EVENT_DISBAND_GUILD_REQUEST` генерируется при инициации процесса роспуска гильдии. Обработчик события в аддоне должен отобразить игроку диалог или запрос на подтверждение данного действия. В случае получения согласия от игрока, необходимо отправить соответствующую команду на сервер для фактического роспуска гильдии.

### Список параметров

Параметры отсутствуют.

### Примеры

#### Обработка запроса на роспуск

```lua
function OnDisbandGuildRequest()
    -- Запрос подтверждения у игрока (например, открытие диалога подтверждения)

    -- Если игрок подтверждает действие:
    -- guild.Disband() -- вызов функции роспуска гильдии
end

common.RegisterEventHandler(OnDisbandGuildRequest, "EVENT_DISBAND_GUILD_REQUEST")
```
