## EVENT_DND_DRAG_CANCELLED

### Описание
```
EVENT_DND_DRAG_CANCELLED
```
Событие присылается при отмене перетаскивания (drag&drop) системой. Скрипт должен выполнить все необходимые логические и визуальные операции, отменяющие перетаскивание.

### Список параметров
Параметры отсутствуют.

---

## EVENT_DND_DRAG_OVER

### Описание
```
EVENT_DND_DRAG_OVER
```
Событие присылается во время drag&drop при изменении виджета под курсором (выборка ведется по стандартному алгоритму PICK, то есть среди доступных для кликов). Скрипт должен выполнить все необходимые визуальные операции, показывающие и перемещающие курсор, а также объекты под ним. Событие присылается как на вход в контрол, так и на выход из него.

### Список параметров

- **`srcWidget`** (`WidgetSafe`) - перетаскиваемый виджет.

- **`srcId`** (`number`) - идентификатор DNDId перетаскиваемого виджета.

- **`targetWidget`** (`WidgetSafe` | `nil`) - виджет под курсором, `nil` если такового нет (считаются только доступные для кликов виджеты, MainScreenControl3D игнорируется).

- **`targetId`** (`number`) - идентификатор DNDId, связанный с виджетом под курсором. Если виджета под курсором нет или он не зарегистрирован в drag&drop, то `DND_INVALID_ID`.

- **`enter`** (`boolean`) - вошли или вышли из объекта под курсором.

## EVENT_DND_DRAG_TO

### Описание
```
EVENT_DND_DRAG_TO
```
Событие присылается при перемещении курсора во время drag&drop.

::: warning Замечание
Событие может прийти после окончания drag&drop, если оно было отправлено в очередь до уведомления системы об окончании перетаскивания. Эту ситуацию надо проверять дополнительно.
:::

### Список параметров
- **`srcWidget`** (`WidgetSafe`) - перетаскиваемый виджет.

- **`srcId`** (`number`) - идентификатор DNDId перетаскиваемого виджета.

- **`posX`** (`number`) - координата курсора по X (реальная).

- **`posY`** (`number`) - координата курсора по Y (реальная).

- **`outside`** (`boolean`) - находится ли курсор за пределами окна приложения.

- **`kbFlags`** (`number`(`KBF_...`)) - состояние модификаторов клавиатуры.

## EVENT_DND_DROP_ATTEMPT

### Описание
```
EVENT_DND_DROP_ATTEMPT
```
Событие присылается при попытке системы завершить drag&drop. Для подтверждения окончания перетаскивания скрипт должен вызвать функцию `DNDConfirmDropAttempt`. При завершении drag&drop скрипт должен в этом же обработчике события выполнить все необходимые логические и визуальные операции, заканчивающие перетаскивание.

### Список параметров
- **`srcWidget`** (`WidgetSafe`) - перетаскиваемый виджет.

- **`srcId`** (`number`) - идентификатор DNDId перетаскиваемого виджета.

- **`targetWidget`** (`WidgetSafe` | `nil`) - виджет под курсором, `nil` если такового нет (считаются только доступные для кликов виджеты, MainScreenControl3D игнорируется).

- **`targetId`** (`number`) - идентификатор DNDId, связанный с виджетом под курсором. Если виджета под курсором нет или он не зарегистрирован в drag&drop, то `DND_INVALID_ID`.

- **`kbFlags`** (`number`(`KBF_...`)) - состояние модификаторов клавиатуры.
(HELP)

## EVENT_DND_PICK_ATTEMPT

### Описание
```
EVENT_DND_PICK_ATTEMPT
```
Событие присылается при попытке системы начать drag&drop. Для подтверждения начала перетаскивания скрипт должен вызвать функцию `DNDConfirmPickAttempt`.

### Список параметров
- **`srcWidget`** (`WidgetSafe`) - окно, которое пытаются начать перетаскивать.

- **`srcId`** (`number`) - идентификатор, зарегистрированный для окна, которое пытаются начать перетаскивать.

- **`posX`** (`number`) - координата курсора по X (реальная).

- **`posY`** (`number`) - координата курсора по Y (реальная).

- **`kbFlags`** (`number`(`KBF_...`)) - состояние модификаторов клавиатуры.
(HELP)
