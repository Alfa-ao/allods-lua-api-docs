## EVENT_DUNGEON_CHOICE_FINISHED

### Описание

```
EVENT_DUNGEON_CHOICE_FINISHED
```

Событие присылается каждый раз, когда выбор личного приключения для атаки закончен.

### Список параметров

Параметры отсутствуют.
