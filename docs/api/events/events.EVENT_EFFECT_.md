## EVENT_EFFECT_FINISHED

### Описание

```
EVENT_EFFECT_FINISHED
```

Событие присылается при завершении эффекта на виджете с указанием его типа. Событие посылается только в том случае, если виджет был валиден на момент отсылки события, событие было заказано в PlayEffect или было принудительно послано в FinishEffect, аддон находится в списке получателей события.

### Список параметров

- **`wtOwner`** (`WidgetSafe`) - виджет, переданный в функции PlayEffect.

- **`effectType`** (`number`(`ET_*`)) - тип эффекта.

## EVENT_EFFECT_SEQUENCE_FINISHED

### Описание

```
EVENT_EFFECT_SEQUENCE_FINISHED
```

Событие присылается при завершении цепочки эффектов на виджете с указанием её типа. Событие посылается только в том случае, если виджет был валиден на момент отсылки события, событие было заказано в PlayEffectSequence или было принудительно послано в FinishEffect, аддон является аддоном, запустившим цепочку эффектов.

### Список параметров

- **`wtOwner`** (`WidgetSafe`) - виджет, переданный в функции PlayEffectSequence.

- **`effectType`** (`number`(`ET_*`)) - тип эффекта.

- **`label`** (`string` | `nil`) - метка, переданная в PlayEffectSequence, при наличии.

---

## EVENT_EFFECT_SEQUENCE_STEP

### Описание

```
EVENT_EFFECT_SEQUENCE_STEP
```

Событие присылается при завершении шага цепочки эффектов на виджете с указанием её типа. Событие посылается только в том случае, если виджет был валиден на момент отсылки события, событие было заказано в PlayEffectSequence, аддон является аддоном, запустившим цепочку эффектов.

### Список параметров

- **`wtOwner`** (`WidgetSafe`) - виджет, переданный в функции PlayEffectSequence.

- **`effectType`** (`number`(`ET_*`)) - тип эффекта.

- **`step`** (`number`) - номер завершенного шага цепочки.

- **`label`** (`string` | `nil`) - метка, переданная в PlayEffectSequence, при наличии.
