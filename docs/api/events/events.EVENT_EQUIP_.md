## EVENT_EQUIP_FAILED

### Описание

```
EVENT_EQUIP_FAILED
```

Событие присылается при провале попытки экипировать предмет. Приходит либо itemId, либо slot.

### Список параметров

- **`sysCode`** (`string`(`ENUM_DressResult_...`)) - код ошибки.

- **`itemId`** (`ObjectId` | `nil`) - идентификатор предмета, если есть такая информация.

- **`slot`** (`number` | `nil`) - индекс слота в инвентаре, если есть такая информация.

- **`slotType`** (`number`(`ITEM_CONT_...`)) - тип контейнера, в котором лежит предмет.
