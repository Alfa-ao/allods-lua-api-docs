## EVENT_FAMILY_CREATED

### Описание

```
EVENT_FAMILY_CREATED
```

Событие присылается в случае, если игрок вступает в брак.

### Список параметров

- **`unitId`** (`ObjectId`) - идентификатор игрока.

---

EVENT_FAMILY_DESTROYED

### Список параметров

## EVENT_FAMILY_SPELL_EXPERIENCE_CHANGED

### Описание

```
EVENT_FAMILY_SPELL_EXPERIENCE_CHANGED
```

Событие присылается в случае, если изменяется опыт, накопленный семейным заклинанием главного игрока.

### Список параметров

- **`spellId`** (`SpellId`) - идентификатор ресурса заклинания.

---

EVENT_FAMILY_SPELLS_CHANGED
