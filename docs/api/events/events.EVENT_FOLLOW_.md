## EVENT_FOLLOW_MODE_CHANGED

### Описание

```
EVENT_FOLLOW_MODE_CHANGED
```

Событие посылается каждый раз, когда изменяется режим следования за объектом.

### Список параметров

- **`followObjectId`** (`ObjectId` | `nil`) - идентификатор объекта, за которым следует аватар.
