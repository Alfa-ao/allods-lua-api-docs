## EVENT_GAME_ITEM_CHANGED

### Описание

```
EVENT_GAME_ITEM_CHANGED
```

Событие присылается при изменении предмета.

### Список параметров

- **`itemId`** (`ObjectId`) - идентификатор предмета.

---

## EVENT_GAME_ITEM_CURSED_CHANGED

### Описание

```
EVENT_GAME_ITEM_CURSED_CHANGED
```

Событие присылается при изменении проклятости предмета. Одновременно приходит событие EVENT_GAME_ITEM_CHANGED.

### Список параметров

- **`itemId`** (`ObjectId`) - идентификатор предмета.
