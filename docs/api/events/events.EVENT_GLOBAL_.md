## EVENT_GLOBAL_COOLDOWN

[<Badge type="warning" text="16.0.00.42" />](/changelog/16.0.0.md#16.0.0-EVENT_GLOBAL_COOLDOWN)

### Описание

```
EVENT_GLOBAL_COOLDOWN
```

Событие присылается при начале эффекта для элемента в книге умений. Для некоторых типов эффектов в сообщении передаются дополнительные поля.

### Список параметров

- **`effect`** (`number`(`EFFECT_TYPE_...`)) - тип начавшегося эффекта.

- **`id`** (`number`) - номер события.

- **`duration`** (`number`) - общая продолжительность в миллисекундах.

- **`remaining`** (`number`) - оставшееся время в миллисекундах.

## EVENT_GLOBAL_NOTICE

### Описание

```
EVENT_GLOBAL_NOTICE
```

Событие приходит, если присылается сообщение от гейммастеров.

### Список параметров

- **`msg`** (`WString`) - сообщение.

## EVENT_GLOBAL_RATES_CHANGED

### Описание

```
EVENT_GLOBAL_RATES_CHANGED
```

Событие приходит, если изменяется список глобальных рейтов к прогрессу персонажа.

### Список параметров

Параметры отсутствуют.
