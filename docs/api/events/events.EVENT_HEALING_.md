## EVENT_HEALING_RECEIVED

### Описание

```
EVENT_HEALING_RECEIVED
```

Событие присылается при лечении юнита. Для срабатывания данного события требуется указание идентификатора объекта ObjectId(number) в качестве параметра функции `common.RegisterEventHandler`.

### Список параметров

- **`unitId`** (`ObjectId`) - идентификатор вылеченного юнита.

- **`healerId`** (`ObjectId` | `nil`) - идентификатор лекаря, если информация о нём ещё доступна.

- **`heal`** (`number`) - количество единиц, на которое юнит был вылечен.

- **`healthLevel`** (`number`) - уровень лечения.

- **`isCritical`** (`boolean`) - был ли крит при лечении.

- **`isGlancing`** (`boolean`) - было ли лечение ослабленным.

- **`isLifeSteal`** (`boolean`) - это лечение от характеристики Кровожадность.

- **`resisted`** (`number`) - величина лечения, которая поглощена из-за сложности ран.

- **`runeResisted`** (`number`) - величина лечения, которая поглощена рунической сложностью ран.

- **`absorbed`** (`number`) - величина лечения, которая поглощена другими причинами.

- **`overload`** (`number`) - величина избыточного лечения, которую не получила цель.

- **`lethality`** (`number`) - величина сложности ран цели в момент лечения.

- **`spellId`** (`SpellId` | `nil`) - идентификатор спелла, которым лечили.

- **`abilityId`** (`AbilityId` | `nil`) - идентификатор абилки, которой лечили.

- **`buffId`** (`BuffId` | `nil`) - идентификатор буффа, которым лечили.

- **`isFall`** (`boolean`) - true, если здоровье изменено из-за падения.
