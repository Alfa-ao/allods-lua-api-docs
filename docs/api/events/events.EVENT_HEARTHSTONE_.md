## EVENT_HEARTHSTONE_COOLDOWN_STARTED

### Описание

```
EVENT_HEARTHSTONE_COOLDOWN_STARTED
```

Событие присылается при старте кулдауна на HearthStone.

### Список параметров

- **`duration`** (`number`) - общая продолжительность в миллисекундах.

- **`remaining`** (`number`) - оставшееся время в миллисекундах.
