## EVENT_HIDDEN_CURRENCY_VALUE_CHANGED

### Описание

```
EVENT_HIDDEN_CURRENCY_VALUE_CHANGED
```

Событие присылается при изменении количества скрытой игровой альтернативной валюты.

### Список параметров

- **`id`** (`CurrencyId`) - идентификатор альтернативной валюты.

- **`delta`** (`number`) - число, на которое изменилось значение валюты.

- **`sysName`** (`string`) - внутреннее имя альтернативной валюты.
