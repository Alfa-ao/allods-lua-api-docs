## EVENT_INSPECT_AVATAR_MEDALS_RESULT

### Описание

```
EVENT_INSPECT_AVATAR_MEDALS_RESULT
```

Событие присылается с результатом вызова информации о достижениях другого игрока.

### Список параметров

- **`unitId`** (`number`) - идентификатор игрока, для которого пришли данные по медалям.

- **`medals`** (`table`) - список идентификаторов достижений игрока.

### Смотрите также

- [medalsLib.GetMedalInfo](/api/category/medalsLib/function.medalsLib.GetMedalInfo.md)

## EVENT_INSPECT_MOUNT_CHANGED

### Описание

```
EVENT_INSPECT_MOUNT_CHANGED
```

## EVENT_INSPECT_STARTED

### Описание

```
EVENT_INSPECT_STARTED
```

Событие посылается при начале инспекции объекта. При потере цели инспекция сбрасывается событием EVENT_INSPECT_FINISHED.

### Список параметров

Параметры отсутствуют.
