## EVENT_ITEMS_EXCHANGE_DECLINE_IGNORED

### Описание

```
EVENT_ITEMS_EXCHANGE_DECLINE_IGNORED
```

Событие присылается при невозможности торговли по причине игнора.

### Список параметров

- **`declinerName`** (`WString`) - имя персонажа, от которого пришел отказ.

---

## EVENT_ITEMS_EXCHANGE_ERROR

### Описание

```
EVENT_ITEMS_EXCHANGE_ERROR
```

Событие присылается, если во время торговли с другим игроком происходит ошибка.

### Список параметров

- **`inviter`** (`WString`) - имя игрока, инициировавшего торговлю.

- **`invited`** (`WString`) - имя игрока, приглашенного торговать.

- **`error`** (`string`(`ENUM_ExchangeResult...`)) - описание ошибки.

---

## EVENT_ITEMS_EXCHANGE_STATE_CHANGED

### Описание

```lua
EVENT_ITEMS_EXCHANGE_STATE_CHANGED
```

Событие приходит, когда изменилось состояние торговли между игроками. Состояний может быть несколько - этап приглашения, этап самой торговли, ни в том ни в другом (торговля прервана или закончена). Событие приходит только в промежутке от момента инициирования торговли до её завершения (`interaction.HasExchange()`).

### Список параметров

Параметры отсутствуют.
