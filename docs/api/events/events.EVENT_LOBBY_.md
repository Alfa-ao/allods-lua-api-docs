## EVENT_LOBBY_CLIENT_MESSAGE

### Описание

```lua
EVENT_LOBBY_CLIENT_MESSAGE
```

Событие приходит как уведомление о поступлении на клиент текстового сообщения в лобби. Строковый код типа берётся из ресурса и задается непосредственно в эффектах типа `ClientData` (серверный тип - `gameMechanics.world.ClientData`) в расширении `InterfaceAction`. В сообщении передаются пары имя-значение параметров. Каждый из параметров может быть одним из двух типов (строка, число). Каждому типу соответствует свое поле, в котором хранится информация о значении, а остальные поля пустые. То есть значение передано только в одном из полей-значений (`int`, `text`).

::: info Перечисления

Рекомендуемые значения `sysId`:

- `ENUM_BATTLE_ACHIEVEMENT` - достижение в астральных кораблях

- `ENUM_CHAT_MESSAGE` - сообщение выведется в чат

- `ENUM_CHAT_MOB_MESSAGE` - сообщение выведется в чат от имени моба в виде "имя моба: текст сообщения"

- `ENUM_TOOLTIP` - сообщение выведется в тултип (например, когда нужно перечислить условия вступления на LFG-активность)

- `ENUM_WARNING_MESSAGE` - на экран (обычное)

- `ENUM_WARNING_MESSAGE_FRAME` - на экран (с рамкой)

- `ENUM_WARNING_MESSAGE_RED` - на экран (красное)

- `ENUM_WARNING_MESSAGE_BLUE` - на экран (синее)

- `ENUM_ANNOUNCE_MESSAGE` - анонс красным цветом

- `ENUM_SHOW_BUBBLE` - бабл над головой

- `ENUM_MESSAGE_BOX` - сообщение с кнопкой Ок

- `ENUM_MODAL_MESSAGE` - то же в модальном окне (пользователь ничего не может делать, пока не закроет окно)

- `ENUM_POINTS_ANNOUNCE` - анонс об изменении очков (на БГ)

- `ENUM_ARENA_START_ANNOUNCE` - анонс о 10-секундной готовности на арене

- `ENUM_Tutorial_` - в учебник

- `ENUM_SOCIAL_NETWORKS_POST` - в автоматический постинг сообщений в соц.сети

:::

### Список параметров

- **`sysId`** (`string`) - строковый код типа.

- **`text`** (`WString`) - текст сообщения.

- **`sysChatChannel`** (`string` | `nil`) - строковый идентификатор канала в чате, если канал был задан. См. `/ChatLog/Channels/ScriptMessageChannels.lua`. Уровни вложенности конкатенируются через подчеркивание. Например - `combat_damage_outgoing_miss`.

- **`values`** (`table`) - индексированный с 0 список полученных параметров.

    - **`name`** (`string`) - строковое имя параметра.

    - **`viewType`** (`number` | `nil`) - если не `nil`, то параметр надо показать не обычным, а указанным способом. Значения соответствуют перечислению `CLIENT_DATA_PARAM_*`.

    - **`int`** (`number` | `nil`) - число, если получено число.

    - **`text`** (`WString` | `nil`) - строка, если получена строка.
