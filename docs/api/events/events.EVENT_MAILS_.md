## EVENT_MAILS_CHANGED

### Описание

```
EVENT_MAILS_CHANGED
```

Событие присылается об изменении содержимого писем. В частности, при получении недостающей информации с сервера. Присылается список всех измененных за кадр писем (событие приходит не чаще раза за кадр).

### Список параметров

- **`table`** (`table`) - таблица, индексированная [0..], содержащая список измененных писем.
