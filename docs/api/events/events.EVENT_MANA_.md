## EVENT_MANA_RECEIVED

### Описание

```
EVENT_MANA_RECEIVED
```

Событие присылается при изменении маны юнита другим юнитом.

### Список параметров

- **`unitId`** (`ObjectId`) - юнит, у которого изменилась мана.

- **`casterId`** (`ObjectId` | `nil`) - юнит, который изменил ману, если информация о нём ещё доступна.

- **`addedMana`** (`number`) - величина изменения маны (отрицательная - выжгли, положительная - добавили).

- **`spellId`** (`SpellId` | `nil`) - Id ресурса заклинания, которым изменили ману.

- **`abilityId`** (`AbilityId` | `nil`) - Id абилки, если изменили абилкой.

- **`buffId`** (`BuffId` | `nil`) - Id буффа, если изменили буффом.

- **`isFall`** (`boolean`) - true, если мана изменена из-за падения.

- **`isExploit`** (`boolean`) - true, если мана изменена из-за эксплойта.
