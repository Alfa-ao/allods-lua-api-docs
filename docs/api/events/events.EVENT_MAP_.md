## EVENT_MAP_CHANNELS_INFO_CHANGED

### Описание

```
EVENT_MAP_CHANNELS_INFO_CHANGED
```

Событие возникает при изменении состояния каналов в текущей игровой локации.

### Список параметров

Параметры отсутствуют.

## EVENT_MAP_INSTANCE_FULL

### Описание

```
EVENT_MAP_INSTANCE_FULL
```

Событие присылается о невозможности зайти в полностью заполненный инстанс.

### Список параметров

- **`mapName`** (`WString`) - название инстанса.
