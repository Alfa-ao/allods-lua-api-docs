## EVENT_MEMBER_MEDAL_FINISHED

### Описание

```
EVENT_MEMBER_MEDAL_FINISHED
```

Событие присылается о выполнении достижения членом группы или отряда аватара, но не самим аватаром.

### Список параметров

- **`id`** (`ObjectId`) - идентификатор достижения.

- **`avatarName`** (`WString`) - имя персонажа выполнившего достижение.
