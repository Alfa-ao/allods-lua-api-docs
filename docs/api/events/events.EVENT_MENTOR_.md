## EVENT_MENTOR_APPRENTICE_ADDED

### Описание

```
EVENT_MENTOR_APPRENTICE_ADDED
```

Событие присылается о появлении у ментора нового ученика.

### Список параметров

- **`mentorId`** (`ObjectId`) - идентификатор (субъекта менторских взаимоотношений) ментора.

- **`mentorPlayerId`** (`ObjectId`) - идентификатор (субъекта менторских взаимоотношений) добавленного ученика.

## EVENT_MENTOR_APPRENTICE_REWARD_CHANGED

### Описание

```
EVENT_MENTOR_APPRENTICE_REWARD_CHANGED
```

Событие приходит, если у субъекта менторских взаимоотношений изменилась награда, полученная с ученика.

### Список параметров

- **`mentorId`** (`ObjectId`) - идентификатор субъекта менторских взаимоотношений - ментора.

- **`apprenticeId`** (`ObjectId`) - идентификатор субъекта менторских взаимоотношений - ученика.
