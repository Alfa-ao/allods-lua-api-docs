## EVENT_MOB_ACTION_PROGRESS_FINISH

### Описание

```
EVENT_MOB_ACTION_PROGRESS_FINISH
```

Событие присылается при окончании действия мобом.

### Список параметров

- **`id`** (`ObjectId`) - идентификатор моба.

## EVENT_MOB_ACTION_PROGRESS_FREEZE

### Описание

```
EVENT_MOB_ACTION_PROGRESS_FREEZE
```

Событие присылается при заморозке прогресса действия моба.

### Список параметров

- **`id`** (`ObjectId`) - идентификатор моба.

- **`progress`** (`number`) - обновление времени действия action (в миллисекундах).

---

## EVENT_MOB_ACTION_PROGRESS_START

### Описание

```
EVENT_MOB_ACTION_PROGRESS_START
```

Событие присылается при запуске действия мобом.

### Список параметров

- **`id`** (`ObjectId`) - идентификатор моба.

- **`duration`** (`number`) - время действия "действия" (в миллисекундах).

- **`progress`** (`number`) - прошло времени (в миллисекундах, так как событие может прийти с задержкой).

- **`name`** (`WString`) - название действия.

- **`spellId`** (`SpellId` | `nil`) - если известен спелл, то присылается идентификатор спелла.

- **`isPrecast`** (`boolean` | `nil`) - если известен спелл, то присылается признак, что у спелла есть время прекаста.

- **`isChannel`** (`boolean` | `nil`) - если известен спелл, то присылается признак, что у спелла есть механика чаннелинга.
