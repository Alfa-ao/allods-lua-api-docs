## EVENT_NAVIGATOR_FOLLOWED_CHANGED

### Описание

```
EVENT_NAVIGATOR_FOLLOWED_CHANGED
```

Событие присылается каждый раз, когда меняется статус `device.HasNavigatorFollowedMarker()`. Работает только для активного (используемого главным игроком) устройства навигатора.

### Список параметров

Параметры отсутствуют.

## EVENT_NAVIGATOR_TARGET_CHESTS_CHANGED

### Описание

```
EVENT_NAVIGATOR_TARGET_CHESTS_CHANGED
```

Событие присылается каждый раз, когда меняется список сундуков во вражеской сокровищнице, увиденных с помощью специального предмета через навигатор корабля главного игрока.

### Список параметров

Параметры отсутствуют.
