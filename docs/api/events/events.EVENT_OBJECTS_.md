## EVENT_OBJECTS_HEALTH_CHANGED

### Описание

```
EVENT_OBJECTS_HEALTH_CHANGED
```

Событие присылается при изменении здоровья и состояния неуязвимости объектов.

### Список параметров

- **`table`** (`table`) - индексированный с 1 список идентификаторов объектов, у которых изменилось состояние здоровья и неуязвимости.
