## EVENT_OBJECT_BUFF_ADDED

### Описание

```
EVENT_OBJECT_BUFF_ADDED
```

Событие присылается каждый раз, когда у объекта появляется новый баф. Если обновляются параметры существующего, то приходит `EVENT_OBJECT_BUFF_CHANGED`. Для срабатывания данного события требуется активация персонального эвента по носителю бафа, см. `common.RegisterEventHandler`, `common.EnablePersonalEvent`.

### Список параметров

- **`objectId`** (`ObjectId`) - идентификатор объекта, на который повесили баф.

- **`buffName`** (`WString`) - имя бафа.

- **`buffId`** (`ObjectId`) - идентификатор бафа.

- **`sysName`** (`string`) - системное название бафа.

- **`resourceId`** (`ObjectId`) - идентификатор ресурса бафа.

- **`isNeedVisualize`** (`boolean`) - нужно ли отображать данный бафф.

- **`interfacePriority`** (`number`(`ENUM_UIBuffPriority`)) - интерфейсный приоритет. Значения соответствуют перечислению `ENUM_UIBuffPriority`.

EVENT_OBJECT_BUFF_CHANGED

Для срабатывания данного события требуется активация персонального эвента по носителю бафа, см. `common.RegisterEventHandler`, `common.EnablePersonalEvent`.

- **`buffName`** (`WString`) - имя бафа.

- **`buffId`** (`ObjectId`) - идентификатор бафа.

- **`sysName`** (`string`) - системное название бафа.

- **`resourceId`** (`ObjectId`) - идентификатор ресурса бафа.

## EVENT_OBJECT_BUFF_REMOVED

### Описание

```
EVENT_OBJECT_BUFF_REMOVED
```

Событие присылается каждый раз, когда у объекта пропадает баф. Нельзя использовать `buffId` из данного события для получения информации о бафе. После отправки события экземпляр бафа уничтожается и его id инвалидируется. Для срабатывания данного события требуется активация персонального эвента по носителю бафа, см. `common.RegisterEventHandler`, `common.EnablePersonalEvent`.

### Список параметров

- **`objectId`** (`ObjectId`) - идентификатор объекта, у которого пропал баф.

- **`buffName`** (`WString`) - имя бафа.

- **`buffId`** (`ObjectId`) - идентификатор бафа.

- **`sysName`** (`string`) - внутреннее имя бафа (может быть использовано для специальной обработки), соответствующее поле в базе для бафа - `sysUIScriptName`.

- **`resourceId`** (`ObjectId`) - идентификатор ресурса бафа.

- **`isNeedVisualize`** (`boolean`) - нужно ли отображать данный бафф.

- **`interfacePriority`** (`number`(`ENUM_UIBuffPriority`)) - интерфейсный приоритет. Значения соответствуют перечислению `ENUM_UIBuffPriority`.

## EVENT_OBJECT_BUFFS_ELEMENT_CHANGED

### Описание

```
EVENT_OBJECT_BUFFS_ELEMENT_CHANGED
```

Событие присылается не чаще одного раза в кадр, если в данном кадре у какого-либо из объектов вокруг игрока меняется информация о каком-либо буфе. Является агрегированной версией `EVENT_OBJECT_BUFF_CHANGED`.

### Список параметров

- **`objects`** (`table`) - индексированная по `ObjectId` таблица таблиц.
    - **`key`** (`ObjectId`) - идентификатор объекта.
    - **`value`** (`table`) - таблица, индексированная по идентификаторам изменившихся бафов.
        - **`key`** (`ObjectId`) - идентификатор бафа.
        - **`value`** (`boolean`) - всегда содержит `true` у проиндексированных элементов.

Событие содержит собранную информацию о всех таких объектах и идентификаторах всех изменившихся бафов по каждому юниту. По индексу идентификатора объекта в полученной таблице можно получить таблицу изменившихся бафов этого юнита. В этой второй таблице во всех элементах по индексам идентификаторов изменившихся бафов прописано `true`. То есть, можно узнать, изменился ли баф `buffId` у юнита с идентификатором `unitId`:

```lua
local isBuffChanged = params.objects[unitId] and params.objects[unitId][buffId] or false
```

## EVENT_OBJECT_HEALTH_CHANGED

### Описание

```
EVENT_OBJECT_HEALTH_CHANGED
```

Событие присылается при изменении процентного значения здоровья интерактивных объектов и числового значения здоровья для персонажа игрока. Для срабатывания данного события требуется указание идентификатора объекта `ObjectId` в качестве параметра функции `common.RegisterEventHandler`.

### Список параметров

- **`id`** (`ObjectId`) - идентификатор объекта.

- **`healthDelta`** (`number` | `nil`) - на сколько изменилась точная величина здоровья, если такая информация доступна для этого объекта.

- **`healthLimitDelta`** (`number` | `nil`) - на сколько изменилась максимальная величина здоровья, если такая информация доступна для этого объекта.

- **`healthPercentsDelta`** (`number` | `nil`) - на сколько изменилась относительная величина здоровья, если такая информация доступна для этого объекта.

- **`additionalDelta`** (`number` | `nil`) - на сколько изменилась точная величина дополнительного здоровья (поглощение), если такая информация доступна для этого объекта.

- **`additionalPercentsDelta`** (`number` | `nil`) - на сколько изменилась относительная величина дополнительного здоровья (поглощение), если такая информация доступна для этого объекта.

- **`isInvulnerableChanged`** (`boolean`) - поменялся ли `isInvulnerable` (состояние неуязвимости).

## Смотрите также

- [object.GetHealthInfo](/api/category/object/function.object.GetHealthInfo.md)
