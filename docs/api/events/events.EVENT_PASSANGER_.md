## EVENT_PASSANGER_STATE_CHANGED

### Описание

```
EVENT_PASSANGER_STATE_CHANGED
```

Событие присылается каждый раз, когда персонаж становится или перестаёт быть пассажиром, к примеру, на двухместном маунте.

### Список параметров

- **`passangerState`** (`boolean`) - является ли персонаж пассажиром, к примеру, на двухместном маунте.
