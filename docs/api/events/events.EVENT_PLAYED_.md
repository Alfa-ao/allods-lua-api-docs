## EVENT_PLAYED_COMMAND_RESPONSE

### Описание

```
EVENT_PLAYED_COMMAND_RESPONSE
```

Событие, которое приходит после выполнения слеш-команды (в чате) `/played`. Возвращает время, проведённое в игре.

### Список параметров

- **`time`** (`table`) - сколько времени игрок провёл в игре.
    - **`d`** (`number`) - дней.
    - **`h`** (`number`) - часов.
    - **`m`** (`number`) - минут.
    - **`s`** (`number`) - секунд.
