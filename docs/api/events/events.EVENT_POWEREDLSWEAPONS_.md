## EVENT_POWEREDLSWEAPONS_CHANGED

### Описание

```
EVENT_POWEREDLSWEAPONS_CHANGED
```

Событие присылается при открытии или закрытии контейнера прокачанного оружия.

### Список параметров

Параметры отсутствуют.

## EVENT_POWEREDLSWEAPONS_ITEM_ADDED

### Описание

```
EVENT_POWEREDLSWEAPONS_ITEM_ADDED
```

Событие, возникающее при добавлении предмета в прокачанное оружие. В случае неудачного добавления предмета в прокачанное оружие вместо данного события возникает `EVENT_EQUIP_FAILED`.

### Список параметров

- **`itemId`** (`ObjectId`) - идентификатор добавленного предмета.

- **`slot`** (`number`) - номер слота.
