## EVENT_PREMIUM_BONUS_STAGE_CHANGED

### Описание

```
EVENT_PREMIUM_BONUS_STAGE_CHANGED
```

Событие присылается при изменении бонусной стадии премиума.

### Список параметров

- **`stage`** (`number`) - бонусная стадия премиума.
