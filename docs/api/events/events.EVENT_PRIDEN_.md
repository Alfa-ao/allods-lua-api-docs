## EVENT_PRIDEN_FACTION_CHOICE

### Описание

```
EVENT_PRIDEN_FACTION_CHOICE
```

Событие присылается при старте изменения фракции (прайденов).

### Список параметров

- **`isLevelUp`** (`boolean`) - специальный флаг для донатного повышения уровня прайдена после выбора фракции.

- **`noDiscard`** (`boolean`) - если `true`, то запрещено отвергать выбор, интерфейс выбора не должен закрываться без принятия решения.
