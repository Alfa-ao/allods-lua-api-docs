## EVENT_PROFICIENCY_ADDED

### Описание

```lua
EVENT_PROFICIENCY_ADDED
```

Событие присылается, когда главный игрок может пользоваться новой профессией (в данный момент это способность носить вещи определенного класса). На этапе загрузки персонажа событие не присылается.

### Список параметров

- **`id`** (`ObjectId`) - Идентификатор объекта профессии.

---

## EVENT_PROFICIENCY_REMOVED

### Описание

```lua
EVENT_PROFICIENCY_REMOVED
```

Событие присылается, когда главный игрок больше не может пользоваться профессией (в данный момент это способность носить вещи определенного класса).

### Список параметров

- **`id`** (`ObjectId`) - Идентификатор объекта профессии.
