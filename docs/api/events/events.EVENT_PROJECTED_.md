## EVENT_PROJECTED_OBJECTS_CHANGED

### Описание

```lua
EVENT_PROJECTED_OBJECTS_CHANGED
```

Событие присылается один раз в кадр, если произошло изменение проецированной 2D координаты (или других параметров) некоторых объектов из списка проецируемых объектов.

### Список параметров

- **`objectIds`** (`table`) - Индексированный с 0 список `ObjectId` объектов.
