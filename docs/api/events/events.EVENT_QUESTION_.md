## EVENT_QUESTION_ADDED

### Описание

```lua
EVENT_QUESTION_ADDED
```

Событие присылается при появлении нового вопроса.

### Список параметров

- **`id`** (`ObjectId`) - Идентификатор появившегося вопроса.
