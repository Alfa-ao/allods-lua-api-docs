## EVENT_QUEST_ABANDONED

### Описание

```lua
EVENT_QUEST_ABANDONED
```

Событие присылается при удалении задания сервером из журнала заданий (например, при отсутствии условий выполнения задания).

### Список параметров

- **`name`** (`WString`) - Название задания.

---

## EVENT_QUEST_FIND_NEXT_RESULT

### Описание

```lua
EVENT_QUEST_FIND_NEXT_RESULT
```

Событие присылается, когда с сервера приходит ответ на запрошенную игроком подсказку «какой следующий квест делать» (вызовом `avatar.FindNextQuest`).

### Список параметров

- **`questId`** (`QuestId` | `nil`) - Идентификатор выданного квеста, если в ответ на запрос сервер выдал квест-подсказку; `nil`, если подходящий квест не найден.

## Смотрите также

- [avatar.FindNextQuest](/api/category/avatar/function.avatar.FindNextQuest.md)

## EVENT_QUEST_OBJECTIVE_UPDATED

### Описание

```lua
EVENT_QUEST_OBJECTIVE_UPDATED
```

Событие присылается каждый раз, когда произошло изменение состояния одного из подзаданий квеста.

### Список параметров

- **`questId`** (`QuestId`) - Идентификатор ресурса квеста.
- **`objectiveId`** (`ObjectId`) - Идентификатор счетчика квеста.
- **`objectiveNumber`** (`number`) - (OBSOLETE) Номер подзадания в списке `objectives`, возвращаемого функцией `avatar.GetQuestProgress`.

