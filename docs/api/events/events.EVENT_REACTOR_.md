## EVENT_REACTOR_COUNTDOWN

### Описание

```lua
EVENT_REACTOR_COUNTDOWN
```

Событие присылается каждый раз, когда у транспортного средства игрока до взрыва реактора осталось определённое время.

### Список параметров

- **`timeMs`** (`number`) - Оставшееся время в миллисекундах.

---

## EVENT_REACTOR_COUNTDOWN_CANCELLED

### Описание

```lua
EVENT_REACTOR_COUNTDOWN_CANCELLED
```

Событие присылается каждый раз, когда у транспортного средства игрока отменено самоуничтожение реактора.

### Список параметров

Параметры отсутствуют.
