## EVENT_READY_CHECK_ENDED

### Описание

```lua
EVENT_READY_CHECK_ENDED
```

Событие присылается при завершении опроса о готовности группы или рейда.

### Список параметров

Параметры отсутствуют.

---

## EVENT_READY_CHECK_INFO_CHANGED

### Описание

```lua
EVENT_READY_CHECK_INFO_CHANGED
```

Событие присылается каждый раз, когда меняется состояние готовности игрока в группе или рейде (для текущего активного опроса). На начало и окончание опроса приходят отдельные события, данное событие в этих случаях не присылается.

### Список параметров

Параметры отсутствуют.

---

## EVENT_READY_CHECK_STARTED

### Описание

```lua
EVENT_READY_CHECK_STARTED
```

Событие присылается при начале опроса о готовности группы или рейда.

### Список параметров

- **`initiatorId`** (`UniqueId`) - Уникальный идентификатор игрока, активировавшего опрос.

---

## EVENT_READY_FOR_FINALLY_RESPAWN

### Описание

```lua
EVENT_READY_FOR_FINALLY_RESPAWN
```

Событие присылается, если игрок готов к окончательному воскрешению из чистилища. Искра уже пришла к нему.

### Список параметров

Параметры отсутствуют.
