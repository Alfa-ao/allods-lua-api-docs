## EVENT_REFORGE_RESULT

### Описание

```lua
EVENT_REFORGE_RESULT
```

Событие присылается при завершении reforge-крафта вещи, после чего можно запрашивать доступные варианты.

### Список параметров

Параметры отсутствуют.

---

## EVENT_REFORGE_RESULT_FAIL

### Описание

```lua
EVENT_REFORGE_RESULT_FAIL
```

Событие присылается, когда reforge-крафт вещи завершён неудачно и выбранный вариант предмета не получен.

### Список параметров

Параметры отсутствуют.

---

## EVENT_REFORGE_RESULT_READY

### Описание

```lua
EVENT_REFORGE_RESULT_READY
```

Событие присылается при завершении reforge-крафта вещи, когда выбранный вариант предмета получен.

### Список параметров

- **`itemId`** (`ObjectId`) - Идентификатор полученного предмета.
