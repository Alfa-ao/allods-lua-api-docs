## EVENT_REVIVAL_ROLL_RESULT

### Описание

```
EVENT_REVIVAL_ROLL_RESULT
```

Событие присылается как результат попытки пригласить игрока вернуться в игру. Содержит статус `ENUM_CreateRevivalRollResultStatus`.

### Список параметров

- **`status`** (`string`(`ENUM_CreateRevivalRollResultStatus`)) - Статус; строковая константа. Значения соответствуют перечислению `ENUM_CreateRevivalRollResultStatus`.
