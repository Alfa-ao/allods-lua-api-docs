## EVENT_RUNE_OPERATION_RESULT

### Описание

```
EVENT_RUNE_OPERATION_RESULT
```

Событие присылается как уведомление о результате взаимодействия с руной.

### Список параметров

- **`sysResult`** (`string`(`ENUM_RuneOperationResult_...`)) - Код результата. Значения соответствуют перечислению `ENUM_RuneOperationResult_...`.
