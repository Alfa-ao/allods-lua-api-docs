## EVENT_SECOND_TIMER

### Описание

```
EVENT_SECOND_TIMER
```

Событие присылается раз в секунду. Работает в стейтах `MainMenu` и `Mission`.

### Список параметров

- **`timeMs`** (`number`) - Сколько миллисекунд прошло после начала отсчета (1 января 1970 года).

- **`elapsedMs`** (`number`) - Сколько миллисекунд прошло после последнего события `EVENT_SECOND_TIMER`.
