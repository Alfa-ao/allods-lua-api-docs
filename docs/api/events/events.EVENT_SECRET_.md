## EVENT_SECRET_CLOSED

### Описание

```
EVENT_SECRET_CLOSED
```

Событие присылается как оповещение о раскрытии всех компонент тайны мира. Теперь главное задание тайны мира можно сдать.

### Список параметров

- **`id`** (`ObjectId`) - Идентификатор тайны мира.

---

## EVENT_SECRET_COMPONENT_CLOSED

### Описание

```
EVENT_SECRET_COMPONENT_CLOSED
```

Событие присылается как оповещение о завершении компоненты тайны мира. Сдан завершающий квест по этой компоненте.

### Список параметров

- **`id`** (`ObjectId`) - Идентификатор тайны мира.

- **`componentIndex`** (`number`) - Индекс завершенной компоненты.

---

## EVENT_SECRET_FINISHED

### Описание

```
EVENT_SECRET_FINISHED
```

Событие присылается как оповещение о завершении тайны мира. Задание сдано, награда получена.

### Список параметров

- **`id`** (`ObjectId`) - Идентификатор тайны мира.

---

## EVENT_SECRET_FINISHER_STATUS_CHANGED

### Описание

```
EVENT_SECRET_FINISHER_STATUS_CHANGED
```

Событие присылается как оповещение об изменении статуса тайны мира, которую может принять интерактивный объект. Происходит, если интерактивный объект есть в реплике и изменился статус (не сделан/сделана/сдана) какой-то тайны мира. В этом случае, например, можно поменять знак над головой этого объекта.

### Список параметров

- **`id`** (`ObjectId`) - Идентификатор интерактивного объекта.

---
