## EVENT_SHIELD_REGEN_IN_PROGRESS_CHANGED

### Описание

```
EVENT_SHIELD_REGEN_IN_PROGRESS_CHANGED
```

Событие присылается каждый раз, когда у щита корабля меняется регенерация.

### Список параметров

- **`id`** (`ObjectId`) - Id устройства.

## EVENT_SHIELD_STRENGTH_CHANGED

### Описание

```
EVENT_SHIELD_STRENGTH_CHANGED
```

Событие присылается каждый раз, когда у щита корабля меняется сила (само значение или максимальная величина).

### Список параметров

- **`id`** (`ObjectId`) - Id устройства.

- **`strengthDelta`** (`number`) - Изменение силы.
