## EVENT_SHOW_ITEMS_INFO

### Описание

```
EVENT_SHOW_ITEMS_INFO
```

Сообщение приходит, когда по каким-либо причинам необходимо показать информацию по определенным предметам. В сообщении приходит список `ValuedObject` - объектов, в которых содержится информация о предметах. Эти объекты можно добавлять в какой-либо `ValuedText`.

::: warning Замечание
Сообщение приходит только в `UIState`.
:::

### Список параметров

- **`items`** (`table`) - Индексированный с 0 список объектов, содержащий информацию о предметах.

- **`reason`** (`number`(`ENUM_ShowItemsInfoReason_...`)) - Причина, из-за которой необходимо показать информацию. Значения соответствуют перечислению `ENUM_ShowItemsInfoReason_...`.

::: info Перечисления
(HELP)
Значения соответствуют перечислению `ENUM_ShowItemsInfoReason_...`:

- `ENUM_ShowItemsInfoReason_Unknown` - причина неизвестна.

- `ENUM_ShowItemsInfoReason_XRayLootChest` - спец. устройство прислало список предметов в астральном сундуке.

:::

## EVENT_SHOW_SUBTITLES

### Описание

```
EVENT_SHOW_SUBTITLES
```

Событие присылается, когда настало время показать субтитры в катсцене.

### Список параметров

- **`subtitles`** (`table`) - Таблица, индексированная начиная с 1, каждый элемент которой является таблицей с полями:
    - **`text`** (`WString`) - Текст субтитров.
    - **`delayMs`** (`number`) - Время демонстрации субтитров.
