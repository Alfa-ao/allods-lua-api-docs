## EVENT_SOS_FINISHED

### Описание

```
EVENT_SOS_FINISHED
```

Событие присылается при исчезновении в зоне главного игрока объекта `SOS`, запущенного другим игроком той же фракции.

### Список параметров

- **`id`** (`ObjectId`) - Идентификатор объекта `SOS`.

---

## EVENT_SOS_STARTED

### Описание

```
EVENT_SOS_STARTED
```

Событие присылается при появлении в зоне главного игрока объекта `SOS`, запущенного другим игроком той же фракции.

### Список параметров

- **`id`** (`ObjectId`) - Идентификатор объекта `SOS`.
