## EVENT_STABLE_FOOD_CHANGED

### Описание

```
EVENT_STABLE_FOOD_CHANGED
```

Событие присылается каждый раз, когда у главного игрока меняется количество еды для ездовых животных.

### Список параметров

Параметры отсутствуют.

## EVENT_STABLE_MOUNT_ADDED

### Описание

```
EVENT_STABLE_MOUNT_ADDED
```

Событие присылается каждый раз, когда у главного игрока появляется ездовое животное в конюшне.

### Список параметров

- **`id`** (`ObjectId`) - Идентификатор ездового животного.

---

## EVENT_STABLE_MOUNT_CHANGED

### Описание

```
EVENT_STABLE_MOUNT_CHANGED
```

Событие присылается каждый раз, когда у одного из ездовых животных главного игрока меняются характеристики (опыт, максимум здоровья, максимум времени насыщения и т.п.).

### Список параметров

- **`id`** (`ObjectId`) - Идентификатор ездового животного.

## EVENT_STABLE_MOUNT_REMOVED

### Описание

```
EVENT_STABLE_MOUNT_REMOVED
```

Событие присылается каждый раз, когда у главного игрока исчезает ездовое животное из конюшни. Получаемый идентификатор уже не валиден и по нему нельзя получить информацию об исчезнувшем животном.

### Список параметров

- **`id`** (`ObjectId`) - Идентификатор ездового животного.
