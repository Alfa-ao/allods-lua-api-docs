## EVENT_TAKE_ITEMS_FAILED

### Описание

```
EVENT_TAKE_ITEMS_FAILED
```

Событие присылается как уведомление о неудачном взятии предмета в инвентарь.

### Список параметров

- **`cause`** (`number`(`TAKE_ITEMS_RESULT_...`)) - Код результата. Значения соответствуют перечислению `TAKE_ITEMS_RESULT_...`.
