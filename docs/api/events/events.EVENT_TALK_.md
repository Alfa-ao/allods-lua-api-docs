## EVENT_TALK_STARTED

### Описание

```
EVENT_TALK_STARTED
```

Событие присылается, когда аватар начинает разговор с NPC. Приходит после вызова `avatar.StartInteract()`.(HELP)

### Список параметров

Параметры отсутствуют.
