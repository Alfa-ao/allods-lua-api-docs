## EVENT_TARGET_POS_CHANGED

### Описание

```
EVENT_TARGET_POS_CHANGED
```

Событие присылается при изменении координат цели главного игрока.

### Список параметров

- **`unitId`** (`ObjectId`) - Id юнита.
