## EVENT_TRACK_ADDED
### Описание
```
EVENT_TRACK_ADDED
```
Событие присылается, если в зоне действия аватара появился отслеживаемый объект Track.

### Список параметров
- **`id`** (`ObjectId`) - Идентификатор объекта.

---

## EVENT_TRACK_OBJECT_CHANGED
### Описание
```
EVENT_TRACK_OBJECT_CHANGED
```
Событие присылается, если отслеживаемый объект Track изменился (поле `objectId` в ответе функции objects.GetTrackInfo( trackId )).(HELP)

### Список параметров
- **`id`** (`ObjectId`) - Идентификатор трека.

---

## EVENT_TRACK_REMOVED
### Описание
```
EVENT_TRACK_REMOVED
```

### Список параметров
