## EVENT_TRAINER_LEARN_ERROR
### Описание
```
EVENT_TRAINER_LEARN_ERROR
```
Событие приходит, если нельзя выучить заклинание или умение у тренера. Возвращаются коды всех найденных ошибок. Список ошибок может быть пуст, если произошла неизвестная системная ошибка.

### Список параметров
- **`errors`** (`table` of `number`(`LEARN_ERROR_...`)) - Индексированный с 0 список ошибок. Значения соответствуют перечислению `LEARN_ERROR_...`.
