## EVENT_UNITS_CHANGED

### Описание

```
EVENT_UNITS_CHANGED
```

Событие присылается раз в кадр, если за этот кадр в зоне действия аватара появляется или исчезает юнит.

### Список параметров

- **`spawned`** (`table` of `ObjectId`) - Индексированная с 1 таблица идентификаторов появившихся юнитов.
- **`despawned`** (`table` of `ObjectId`) - Индексированная с 1 таблица идентификаторов исчезнувших юнитов.
