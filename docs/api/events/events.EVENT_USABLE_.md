## EVENT_USABLE_DEVICES_CHANGED
### Описание
```
EVENT_USABLE_DEVICES_CHANGED
```
Событие присылается раз в кадр, если за этот кадр в зоне действия аватара появляется или исчезает корабельное устройство.

### Список параметров
- **`spawned`** (`table` of `ObjectId`) - Индексированная с 1 таблица идентификаторов появившихся устройств.
- **`despawned`** (`table` of `ObjectId`) - Индексированная с 1 таблица идентификаторов исчезнувших устройств.
