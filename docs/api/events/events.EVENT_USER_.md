## EVENT_USER_SCREENSHOT
### Описание
```
EVENT_USER_SCREENSHOT
```
Событие присылается при сделанном снимке экрана, удачном или неудачном.

### Список параметров
- **`success`** (`boolean`) - Успешно или нет сделан снимок экрана.
- **`filePath`** (`WString`) - Полный путь до файла со снимком экрана.
- **`fileName`** (`WString`) - Краткое имя файла со снимком экрана.
- **`isPostpone`** (`boolean`) - Было ли снятие скриншота отложено на несколько кадров.
