## EVENT_VARIABLE_ADDED

### Описание
```
EVENT_VARIABLE_ADDED
```
Событие присылается при появлении у главного игрока значения геймдизайнерской переменной.

### Список параметров
- **`id`** (`VariableId`) - идентификатор переменной.

- **`sysName`** (`string`) - псевдоним переменной.

## EVENT_VARIABLE_VALUE_CHANGED

### Описание
```
EVENT_VARIABLE_VALUE_CHANGED
```
Событие присылается при изменении значения геймдизайнерской переменной главного игрока.

### Список параметров

- **`id`** (`VariableId`) - идентификатор переменной.

- **`sysName`** (`string`) - псевдоним переменной.

- **`delta`** (`number`) - число, на которое изменилось значение переменной (может быть как положительным, так и отрицательным).
