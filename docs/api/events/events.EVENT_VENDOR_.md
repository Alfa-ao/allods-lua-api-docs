## EVENT_VENDOR_BUY_NOT_ENOUGH_PLACE

### Описание
```
EVENT_VENDOR_BUY_NOT_ENOUGH_PLACE
```
Событие присылается, если не хватает места для покупки. Если была попытка покупки в определенный слот, то проверяется, не пуст ли он, и, если не пустой, то можно ли увеличить количество товара в нём на заданную величину. Если слот не был задан, то значит подходящего слота вообще нет.

### Список параметров
Параметры отсутствуют.

## EVENT_VENDOR_ITEM_NOT_FOR_SALE

### Описание
```
EVENT_VENDOR_ITEM_NOT_FOR_SALE
```
Событие присылается при невозможности продать предмет (предмет не продается).

::: warning Замечание
Попытка продажи такого предмета, вообще говоря, ошибочна.
:::

### Список параметров
- **`itemId`** (`ObjectId`) - идентификатор предмета, который не удалось продать.
