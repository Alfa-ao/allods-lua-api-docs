## EVENT_VETERANRANKS_COMMAND_RESPONSE

### Описание
```
EVENT_VETERANRANKS_COMMAND_RESPONSE
```
Событие присылается после выполнения слеш-команды `/veteran` в чате. Возвращает прогресс ветеранского ранга и таблицу всех рангов.

### Список параметров
- **`value`** (`number`) - текущий прогресс.

- **`rewards`** (`table`) - таблица рангов, индексация [0..]:
    - **`value`** (`number`) - значение прогресса для достижения ранга.
    - **`name`** (`WString`) - название ранга.
