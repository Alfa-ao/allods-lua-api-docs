## EVENT_WISHMASTER_CHANGED

### Описание
```
EVENT_WISHMASTER_CHANGED
```
Событие присылается при изменении информации о Волшебной лампе.

### Список параметров
Параметры отсутствуют.

## EVENT_WISHMASTER_MULTIPLYING

### Описание

```
EVENT_WISHMASTER_MULTIPLYING
```

Событие присылается с результатами и возможностями улучшения Волшебной лампы.

### Список параметров

- **`resourceId`** (`WishmasterResourceId`) - идентификатор Волшебной лампы.
