# table.clone

Глубокое копирование (Deep Copy).

<Badge type="success" text="15.0.01.00" />

## Описание

```lua
table.clone( tab: table ): table
```

Создает и возвращает глубокую (рекурсивную) копию исходной таблицы `tab`. Функция полностью обходит всю структуру таблицы, создавая новые независимые экземпляры для всех вложенных таблиц. Метатаблицы также рекурсивно копируются и привязываются к новым вложенным таблицам, сохраняя всю исходную структуру и поведение объектов.

::: warning
Глубокое копирование - крайне ресурсоемкая операция.
:::

## Список параметров

- **`tab`** (`table`) - Исходная таблица, полную копию которой необходимо создать.

## Возвращаемые значения

- **`copy`** (`table`) - Новая таблица, являющаяся полной независимой копией исходной, включая все вложенные таблицы и метатаблицы.

## Примеры

### Глубокое копирование с метатаблицами

```lua
local mt = { __index = function() return "default" end }
local original = {
    a = 1,
    nested = { x = 10 }
}

setmetatable( original, mt )

local copy = table.clone( original )

copy.a = 99
copy.nested.x = 20

LogInfo( original.a )        -- Выведет: 1
LogInfo( original.nested.x ) -- Выведет: 10 (вложенная таблица полностью независима)

-- Проверка метатаблицы
local copy_mt = getmetatable( copy )
LogInfo( copy_mt == mt )     -- Выведет: false (метатаблица скопирована)
LogInfo( copy[999] )         -- Выведет: "default" (метаметод __index работает в копии)
```
