# table.nkeys

Подсчет всех ключей.

<Badge type="success" text="15.0.01.00" />

## Описание

```lua
table.nkeys( tab: table ): number
```

Подсчитывает и возвращает полный размер таблицы `tab`. В отличие от стандартного оператора длины `#`, который работает только с непрерывной массивной частью и может возвращать некорректные значения при наличии "дырок" (значений `nil`), `table.nkeys` честно итерирует всю таблицу. Функция считает абсолютно все пары ключ-значение, где значение не равно `nil`.

::: tip Аналог функции GetTableSize

```lua
function GetTableSize( t )
	if not t then
		return 0
	end
	local count = 0
	for k, v in pairs( t ) do
		count = count + 1
	end
	return count
end
```

:::

## Список параметров

- **`tab`** (`table`) - Таблица, полный размер которой необходимо вычислить.

## Возвращаемые значения

Возвращает целое число (`number`), представляющее общее количество непустых пар ключ-значение в таблице.

## Примеры

### Подсчет ключей в смешанной таблице

```lua
local mixedTable = {
    "apple",       -- ключ 1
    "banana",      -- ключ 2
    [5] = "orange", -- ключ 5 (создает "дырку" для оператора #)
    name = "Fruit", -- строковый ключ
    color = "red"   -- строковый ключ
}

-- Массив неиндексируемый
LogInfo( #mixedTable ) -- Оператор # выведет: 2

-- table.nkeys всегда вернет точное кол-во
LogInfo( table.nkeys( mixedTable ) ) -- Выведет: 5
```
