# table.sclone

Поверхностное копирование (Shallow Copy).

<Badge type="success" text="15.0.01.00" />

## Описание

```lua
table.sclone( tab: table ): table
```

Создает и возвращает новую таблицу, копируя в нее все пары ключ-значение из исходной таблицы `tab`. Копирование производится нерекурсивно (поверхностно): если значением является таблица, функция или userdata, копируется только ссылка на нее. Метатаблица исходной таблицы не копируется (у результата она будет равна `nil`).

::: warning
Так как копирование нерекурсивное, вложенные таблицы копируются по ссылке. Изменение вложенной таблицы в копии автоматически изменит её и в оригинале.
:::

## Список параметров

- **`tab`** (`table`) - Исходная таблица, копию которой необходимо создать.

## Возвращаемые значения

- **`copy`** (`table`) - Новая таблица, содержащая скопированные пары ключ-значение. Метатаблица у возвращаемой таблицы отсутствует.

## Примеры

### Базовое поверхностное копирование

```lua
local original = {
    a = 1,
    b = "text",
    nested = { x = 10 }
}

local copy = table.sclone( original )

copy.a = 99
copy.nested.x = 20

LogInfo( original.a )           -- Выведет: 1 (скалярное значение не изменилось)
LogInfo( original.nested.x )    -- Выведет: 20 (вложенная таблица изменилась, так как копируется по ссылке)
LogInfo( getmetatable( copy ) ) -- Выведет: nil (метатаблица не скопировалась)
```
