# CurrencyCategoryId

Идентификатор категории альтернативной игровой валюты. Один из типов группы `ResourceId`. (В настоящее время идентификатор категории альтернативной игровой валюты - идентификатор его ресурса в базе).

Поля, доступные в `CurrencyCategoryId:GetInfo()`

```
name: WString - название категории
description: string - описание категории
sysName: string - системное имя категории
```
