# FactionId

Идентификатор фракции. Один из типов группы `ResourceId`.

Поля, доступные в `FactionId:GetInfo()`

```
name: WString - локализованное название фракции
sysName: string or nil - системное название фракции
hide: boolean - отображать ли фракцию в интерфейсе
hideNotification: boolean - скрывать нотификацию связанную с этой фракцией
```
