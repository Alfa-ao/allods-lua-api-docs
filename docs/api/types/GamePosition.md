# GamePosition

Позиция в игре (координаты на карте).

```
-- Описание типа:
Таблица, имеющая следующие поля:
    posX: number (double) - координата по X
    posY: number (double) - координата по Y
    posZ: number (double) - координата по Z

Пример:

local pos = {}
pos.posX = 10234
pos.posY = 512
pos.posZ = 10
```
