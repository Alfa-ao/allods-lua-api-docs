# ItemClassId

Идентификатор класса предмета. Один из типов группы `ResourceId`.

Поля, доступные в `ItemClassId:GetInfo()`

```
["hideDPS"] => boolean(true)
["name"] => WString(15) "Драконье Оружие"
["sysName"] => string(17) "DragonRelicWeapon"
```
