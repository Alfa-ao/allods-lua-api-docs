# LifestyleCategoryId

Идентификатор категории гардероба. Один из типов группы `ResourceId`. (В настоящее время идентификатор категории гардероба - идентификатор его ресурса в базе).

Поля, доступные в `LifestyleCategoryId:GetInfo()`

```
name: WString - название категории
description: string - описание категории
```
