# LifestyleCollectionId

Идентификатор коллекции гардероба. Один из типов группы `ResourceId`. (В настоящее время идентификатор коллекции гардероба - идентификатор его ресурса в базе).

Поля, доступные в `LifestyleCollectionId:GetInfo()`

```
name: WString - название коллекции
description: string - описание коллекции
```
