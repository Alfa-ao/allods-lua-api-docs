# LootGroupId

Идентификатор ресурса, определяющего вариант выпадения лута на астральных островах. Один из типов группы `ResourceId`.

Поля, доступные в `LootGroupId:GetInfo()`

```
name: WString - название варианта
image: TextureId или nil - (только в UIState) идентификатор текстуры для иконки, может отсутствовать
```
