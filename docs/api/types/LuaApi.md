# Используемые типы в Lua API

## Описание

В LuaApi используются встроенные Lua типы и пользовательские типы. Как правило, пользовательские типы определены в коде. Уточнение: пользовательские типы не обязательно являются `userdata` / `lightuserdata` из Lua, реализация каждого типа описана отдельно.

## Базовые типы Lua

- **`nil`** - отсутствие значения.

- **`number`** - реальные (с плавающей запятой) числа.

- **`number (integer)`** - целое число.

- **`number (enum)`** - перечисление. Константы целочисленные, оговариваются особо в каждом случае.

- **`string`** - встроенная строка Lua. Не локализуемая. Для локализованных строк используется `WString`.

- **`boolean`** - логическое значение (`true` или `false`).

- **`table`** - таблица Lua.

- **`userdata`** - позволяет хранить любые пользовательские данные, переданные из C в переменных Lua.

- **`list`** - список значений (конструкция языка, а не тип).

## Пользовательские типы

Различные пользовательские типы, определенные в коде:

- **`ObjectId`** - идентификатор объекта (в настоящее время `number (integer)` или `nil`).

- **`UniqueId`** - Уникальный постоянный (кросс-серверный) идентификатор аватара.

- [**`ResourceId`**](/api/category/ResourceId/) - группа типов, являющихся идентификаторами ресурсов из базы. Идентификаторы можно сравнивать, используя [`ResourceId:IsEqual( resource )`](/api/category/ResourceId/method.IsEqual.md).

    - **`QuestId`** - идентификатор квеста.
        - Поля, доступные в [`ItemId:GetInfo()`](/api/category/ResourceId/method.GetInfo.md)
        
        ```
        finishText: WString - финальное описание
        startText: WString - стартовое описание
        goal: WString - описание рекомендации
        image: TextureId - иконка
        name: WString - имя
        isAutomatic: boolean - true если это дейлик, иначе false
        questCategory: Number(ENUM_QuestCategory) - категория квеста
        ```
        
        - [`ENUM_QuestCategory`](/api/enums/enums.ENUM_QuestCategory.md)
        
    - **`SpellId`** - идентификатор умения (spell).

    - **`ItemCategoryId`** - идентификатор категории предмета.

    - **`TextureId`** - идентификатор текстуры из базы.

    - **`VisObjectId`** - идентификатор визуального объекта из базы.

    - **`AliasVisObjectId`** - Идентификатор визуального объекта-обвязки представляет ресурс объекта в базе. Служит для реализации автоматической подмены ресурсов (для коллекционных изданий и т.п.).

    - **`Sound2DId`** - идентификатор звука из базы.
    
    - и т.д.

- **`Color`** - цвет в виде таблицы с полями `a`, `r`, `g`, `b` типа `number (float)`. Диапазон значений `[0..1]`. Пример: `{ r = 1, g = 0, b = 0, a = 0.2 }`.

- **`GamePosition`** - игровые координаты.

- **`RelatedTextsLua`** - группа текстовых ресурсов.

- **`RelatedTexturesLua`** - группа текстурных ресурсов.

## Типы виджетов

Различные типы виджетов, определенные в коде:

- **`WidgetsSystemSafe`** - система виджетов в целом.

- **`WidgetSafe`** - базовый тип для виджетов. Можно сравнивать, используя [`ResourceId:IsEqual( resource )`](/api/category/ResourceId/method.IsEqual.md).

- **`ButtonSafe`** - кнопка.

- **`Control3DSafe`** - 3D контрол (кукла и тому подобное).

- **`EditLineSafe`** - строка ввода текста.

- **`FormSafe`** - форма.

- **`PanelSafe`** - панель.

- **`TextViewSafe`** - контрол просмотра текста.

- **`ScrollableContainerSafe`** - контрол для группировки разнородных элементов.

## Работа с текстом

- [**`WString`**](/api/category/WString/) - локализуемая строка.

- [**`ValuedText`**](/api/category/ValuedText/) - размеченный текст с подстановками.

- [**`ValuedObject`**](/api/category/ValuedObject/) - обертка игрового объекта для подстановки в `ValuedText`.
