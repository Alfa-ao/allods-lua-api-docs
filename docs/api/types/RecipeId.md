# RecipeId

Идентификатор рецепта. Один из типов группы `ResourceId`. (В настоящее время идентификатор рецепта - идентификатор его ресурса в базе).

Поля, доступные в `RecipeId:GetInfo()`

```
name: WString - имя (локализованое)
description: WString - описание (локализованое)
image: UITexture - иконка
```
