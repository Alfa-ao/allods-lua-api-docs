SocketId
Идентификатор ресурса предмета для дерева талантов души. Пользовательский тип данных (см. также LuaApiTypes). Один из типов группы ResourceId. Идентификатор ресурса достижения в базе.

Поля, доступные в SocketId:GetInfo()

  gemSlot: Number(ENUM_GemSlot) - идентификатор слота в дереве талантов души
  quality: - качество предмета
