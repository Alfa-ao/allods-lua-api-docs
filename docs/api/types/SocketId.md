# SocketId

::: danger DEPRECATED
Это мертвая фича. Не используется.
:::

Идентификатор ресурса предмета для дерева талантов души. Один из типов группы `ResourceId`. Идентификатор ресурса достижения в базе.

Поля, доступные в `SocketId:GetInfo()`

```
gemSlot: Number(ENUM_GemSlot) - идентификатор слота в дереве талантов души
quality: - качество предмета
```
