# UITextureId

Идентификатор интерфейсной текстуры. Пользовательский тип данных, см. также LuaApiTypes. Один из типов группы `ResourceId`. (В настоящее время идентификатор текстуры - идентификатор ее ресурса в базе).

В отличие от `TextureId` хранит `UISingleTexture` и, соответственно, не теряет значение `permanentCache`.

Во всех API (если явно не указано обратное) взаимозаменяем с `TextureId`, может быть тривиально к нему приведен.
