# UnlockCategoryId

Идентификатор категории анлоков. Один из типов группы `ResourceId`. (В настоящее время идентификатор категории анлоков - идентификатор его ресурса в базе).

Поля, доступные в `UnlockCategoryId:GetInfo()`

```
name: string - Название категории
sysName: string - Системное название категории. Возможно использовать для реализации уникального поведения категории.
```
