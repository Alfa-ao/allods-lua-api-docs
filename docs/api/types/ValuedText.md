# ValuedText

`ValuedText` – это объект (форматированная строка с подстановочными значениями), задача которого - получение, хранение и использование форматированного текста.

Форматированный текст представляет собой:
1. **Форматную строку с тегами подстановки.** Это `WString`, содержащий правильно форматированную строку XHTML, возможно, с CSS-тегами и тегами подстановки значений:
   - подстановка текстовых значений `<r name="..."/>`
   - подстановка CSS-класса `<rs class="...">...</rs>`
2. **Подстановочные значения**, подставляемые в теги `<r/>` и `</rs>`.

Поддерживаются:
- **Базовые теги:** `<default/>`, `<span/>`, `<p/>`
- **CSS-теги** (полный список см. в [`common.GetCSSList()`](/api/category/common/function.common.GetCSSList.md)).

В скриптах `ValuedText` - это специальный вариант `userdata`.

---

## Создание и использование в скриптах

`ValuedText` создаётся с помощью функции [`common.CreateValuedText( values )`](/api/category/common/function.common.CreateValuedText.md).

::: warning Важно
Lua работает с `userdata` по ссылке, а не по значению. Поэтому для создания отдельной копии `ValuedText` нужно пользоваться специальной функцией [`ValuedText:CreateCopy`](method.CreateCopy.md).
:::

**Перегруженные операции:**
- `#` - взятие длины `ValuedText`. Считается по числу отображаемых символов, длина тегов оформления не учитывается.

## Подстановка значений

Новые значения подставляются с помощью следующих методов:
- [`ValuedText:SetTextValues( values )`](method.SetTextValues.md)
- [`ValuedText:SetVal( key, value )`](method.SetVal.md)
- [`ValuedText:SetClassVal( key, value )`](method.SetClassVal.md)
- [`ValuedText:SetTagAttributes( isRTag, tagName, tagAttributes )`](method.SetTagAttributes.md)

::: warning Не рекомендуется использовать
- [`ValuedText:SetFormat( format )`](method.SetFormat.md)
- [`ValuedText:SetPlainText( text )`](method.SetPlainText.md)
:::

Для подстановки используются только теги `<r/>` и `<rs>...</rs>`.
- В качестве подстановочных значений для тега `<r/>` можно использовать `WString`, объекты `ValuedText` или `ValuedObject`.
- В тег `<rs>...</rs>` можно подставлять только имеющиеся CSS-классы (их названия типа `string`).

Поиск тега подстановки производится по значению атрибута `name` для тега `<r/>` или `class` для тега `<rs>...</rs>`. Эти теги не должны содержать лишних атрибутов. Если необходимый тег `<r/>` не найден, подстановочное значение сохраняется и будет подставлено позже, если у `ValuedText` появится такой тег.

**Пример создания:**
```lua
local valuedText = common.CreateValuedText{
    format = common.GetAddonRelatedText( "FormatText" ),
    value01 = common.FormatInt( 2, "%d" ),
    class01 = "header"
}
```
*Форматирующий текст (related-текст аддона "FormatText"):*
```xml
<html> <header> text1 </header> <rs class="class01"> text2 <r name="value01"/> </rs> </html>
```

::: tip Совет
Использование `ValuedText:SetTextValues()` крайне рекомендовано в случаях подстановки 3 и более значений, чтобы сделать это за один раз.
:::

Текстовики можно заводить ресурсно, создав и подключив его в необходимом аддоне. При создании через ресурсы кодировка текста **СТРОГО должна быть UTF-16LE**.
Отдельно стоит отметить, что переопределять поле `format` не рекомендуется после его изначального определения.

## Встроенные теги и правила работы с ними

### Базовые теги
- `<r>` - тег подстановки текстовых значений.
- `<rs>` - тег подстановки стиля оформления.
- `<t>` - тег для повторного использования текстов в ресурсе.
- `<object>` - тег объявления `ValuedObject` в ресурсе.
- `<span>` - тег подстановки стилей текста.

### Тег `<r>`
Структура:
```xml
<r name="value" [parsing="no/yes/smart"]></r>
```
Является тегом подстановки для динамической части текста.

**Атрибуты:**
- `name` - **ОБЯЗАТЕЛЬНЫЙ** параметр, имя подстановочной переменной в виде строки.
- `parsing` - тип разбора значения переменной (по умолчанию `smart`).
    - `"no"` - подстановочное значение не является XHTML текстом.
    - `"yes"` - подстановочное значение является XHTML текстом и подлежит рекурсивному разбору.
    - `"smart"` - делается попытка разобрать значение как XHTML без вывода сообщений об ошибках.

::: warning Замечание
Рекомендуется ставить `parsing="no"`, если известно, что в тег НЕ БУДУТ подставляться `ValuedText`. Тег НЕ ИМЕЕТ и НЕ ПОДДЕРЖИВАЕТ атрибуты оформления в текстовиках (однако поддерживает в рантайме), стиль оформления задается родительским тегом.
:::

**Примеры:**
Простая замена:
```xml
<r name="text1"/>
```
Вложенность:
```xml
<h1 class="red"><r name="mob1"/></h1>
```

### Тег `<span>`
Служит для изменения стиля текстовиков, сам по себе не выполняет никакой функции кроме ХРАНЕНИЯ атрибутов стиля.
```xml
<span attribute1="value" ... attributeN="value">Text</span>
```
Вместо `Text` можно вставить любой текст или тег, например `<r>`.

### Тег `<rs>`
Служит для динамической смены стиля оформления текста после разбора XHTML.
```xml
<rs class="name"></rs>
```
- `class` - идентификатор стиля в таблице стилей.

**Правильное использование:**
```xml
<rs class="tagstyle"><r name="text"/></rs> <!-- верно -->
```
**Неправильное использование:**
```xml
<rs class="text"><r name="text"/></rs> <!-- конфликт имен переменных -->
```

### Тег `<t>`
Используется для повторного использования одинаковых кусков текста из разных файлов.
```xml
<t href="FilePath.txt"/>
```
**Пример:**
Файл `/Planets/Sun/text1.txt` содержит слово `Солнце`.
```xml
<html>Сегодня встало красное <t href="/Planets/Sun/text1.txt"/></html>
<header>Вчера было необычайно яркое <t href="/Planets/Sun/text1.txt"/></header>
```

### Теги пользователя
- `<username/>` - подстановка имени текущего персонажа.
- `<classname/>` - подстановка класса текущего персонажа.

**Примеры:**
```xml
<html><p>Добро пожаловать в Новоград, <username/>!</p></html>
<!-- Результат: Добро пожаловать в Новоград, Вася! -->

<html>Мой друг, тоже <classname/>, как и ты...</html>
<!-- Результат: Мой друг, тоже Паладин, как и ты... -->
```

### Гендерные теги
Позволяют отображать фрагменты текста в зависимости от пола персонажа.
- `<m>` - для мужских персонажей.
- `<f>` - для женских персонажей.

**Пример:**
```xml
<html>Ты <m>мой лучший друг</m><f>моя лучшая подруга</f>!</html>
```

### Расовые теги
Позволяют отображать текст в зависимости от расы персонажа.
**Простые теги:**
`<elf>`, `<ork>`, `<undead>`, `<hadagan>`, `<gibberling>`, `<priden>`, `<aed>`, `<kania>`
И их отрицания: `<not_elf>`, `<not_ork>`, и т.д.

**Пример:**
```xml
<html>
  <elf>Добро пожаловать домой</elf>
  <ork>Вы в прекрасной форме</ork>
  <not_elf>Эта земля принадлежит эльфам, тебе здесь не рады</not_elf>
</html>
```
Допускается вложение тегов друг в друга.

### Составной расовый тег `<race>`
Позволяет комбинировать условия показа текста.
**Атрибуты:**
- `name` - **ОБЯЗАТЕЛЬНЫЙ**. Перечисление рас через разделитель (пробел, табуляция, перенос строки, `.`, `,`, `:`, `|`).
- `not="true"` - задает отрицание для аргумента в `name`.

**Примеры:**
```xml
<!-- Только эльф ИЛИ аэд -->
<race name="elf,aed">Только истинный эльф ИЛИ аэд увидит эту надпись</race>

<!-- НЕ эльф -->
<race name="elf" not="true">Только истинный эльф НЕ увидит эту надпись</race>
```

::: danger Ошибки при использовании
- Не используйте `not_*` в качестве аргумента в теге `<race>`. Используйте их как самостоятельные теги `<not_*>`.
- Избегайте избыточности условий, например `<race name="not_elf;not_orc">` покажет текст всем расам, а с `not="true"` скроет ото всех.
:::

### Фракционные теги
- `<empire>` - для персонажей из Империи.
- `<league>` - для персонажей из Лиги.

### Теги типа сервера
- `<p2p>` - для подписочного сервера.
- `<f2p>` - для бесплатного сервера.

### Общие атрибуты тегов
Данные атрибуты можно использовать в любом существующем теге, но **не стоит** использовать их в тегах подстановки.

| Атрибут | Описание | Значения |
|---|---|---|
| `color` | Цвет текста | `int` / `hexint` |
| `outline` | Толщина обводки | `int[0-2]` |
| `outlinecolor` | Цвет обводки | `int` / `hexint` |
| `shadow` | Наличие и толщина тени | `int[0-10]` |
| `shadowcolor` | Цвет тени | `int` / `hexint` |
| `fontsize` | Размер шрифта | `int[>0]` |
| `fontname` | Имя шрифта | `string` |
| `alignx` | Выравнивание по горизонтали | `"center"` / `"left"` / `0` |
| `alignY` | Выравнивание по вертикали | `"top"` / `"middle"` / `"bottom"` |
| `paragraph` | Обрамление текста переносами | `"false"` / `"true"` |
| `before` | Отступ абзаца сверху | `int[>=0]` (работает при `paragraph="true"`) |
| `worldWrap` | Перенос по словам | `"false"` / `"true"` |
| `linespacing` | Межстрочный интервал | `float` |
| `right to left` | Перевернуть текст | `"0"` / `"1"` |
| `offset` | Смещение | `int` |

## Стили и работа с ними (CSS)

Основное достоинство применения CSS в XHTML - разделение данных от оформления.

Создать свой стиль можно, создав новый CSS файл (`.xdb`, желательно с `.WidgetCss` в названии).
Структура файла:
```xml
<?xml version="1.0" encoding="UTF-8" ?>
<WidgetCss>
    <Id>Sample</Id>
    <Selectors>
        <Item>
            <Name>header_sample</Name>
            <Items>
                <Item>
                    <Key>fontsize</Key>
                    <Value>50</Value>
                </Item>
                <Item>
                    <Key>color</Key>
                    <Value>0xffffe65e</Value>
                </Item>
                <!-- Другие свойства -->
            </Items>
        </Item>
    </Selectors>
</WidgetCss>
```

После создания файл нужно подключить в аддоне (в файле типа `UIAddon` с расширением `.xdb`, в теге `<styleSheets>`).

```xml
<?xml version="1.0" encoding="UTF-8" ?>
<UIAddon>
    <!-- ... -->
	<styleSheets>
		<Item href="Widgets/Css/Example.(WidgetCss).xdb" />
	</styleSheets>
</UIAddon>
```

Использовать в коде:

```lua
local valuedText = common.CreateValuedText {
    ...
    class01 = "header_sample"
}
```

::: warning Важные правила для стилей
1. Обязательно указывайте атрибут `<Name>` в виде строки.
2. Имя создаваемого стиля **ДОЛЖНО БЫТЬ ГЛОБАЛЬНО УНИКАЛЬНЫМ**. Переопределять существующие стили НЕЛЬЗЯ.
3. Стиль, созданный в аддоне, виден всем аддонам, пока загружен его создатель, и может быть использован в любых других аддонах.
:::

::: success Более подробно можно ознакомиться:
`Аллоды Онлайн\data\Mods\Docs\ModdingDocuments.zip\ModdingDocuments\ResourceSystem`
:::

## Особенности работы в скриптах

При работе с `ValuedText` в скриптах следует учитывать, что это неиндексируемая `userdata`, то есть Lua видит её как ссылку.

**Переопределенные операции:**
- **Сравнение** - сравнивается по лексикографической массе слов.
- **Длина** (`#`) - количество отображаемых символов.
- **Равенство** (`==`) - сравнивается по значению, а не по ссылке.
