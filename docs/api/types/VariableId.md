# VariableId

Идентификатор ресурса геймдизайнерской переменной (например, количество Сил Льда у мага). Один из типов группы `ResourceId`.

Поля, доступные в `TutorialCategoryId:GetInfo()`

```
["name"] => WString - Название
["sysName"] => string - Системное имя
```
