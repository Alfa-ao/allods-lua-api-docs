# VoteId

Идентификатор голосования. Один из типов группы `ResourceId`. (В настоящее время идентификатор голосования - идентификатор его ресурса в базе).

Поля, доступные в `VoteId:GetInfo()`

```
marker: CurrencyId - альтернативная ценность
questions - table of tables или nil - nil если вопросов нет; иначе список (индексируемый с 0) таблиц, каждая из которых описывает отдельный вопрос в формате:
  description: WString - описание вопроса,
  answersCount: number(int) - количество вариантов на вопрос, 0 - если неограниченно
    answers - table of tables или nil - nil если ответов нет; иначе список (индексируемый с 0) таблиц, каждая из которых описывает отдельный вариант ответа в формате:
      description:WString - вариант ответа
```
