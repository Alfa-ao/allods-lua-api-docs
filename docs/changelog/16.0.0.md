### common.RegisterFrameHandler {#16.0.0-common.RegisterFrameHandler}

:::: success VERSION: <Badge type="warning" text="16.0.00.49" /> <Badge type="success" text="Release" />
Новое API:

- [common.RegisterFrameHandler](/api/category/common/function.common.RegisterFrameHandler.md)
- [common.UnRegisterFrameHandler](/api/category/common/function.common.UnRegisterFrameHandler.md)
- [common.HitFrameHandler](/api/category/common/function.common.HitFrameHandler.md)

`common.RegisterFrameHandler( handlerFunction, requireHit )` - регистрирует функцию как хендлер фрейма. В аддоне может быть только один такой хендлер. Второй параметр определяет когда будет вызываться данная функция: `false` - каждый кадр, `true` - каждый кадр, если в аддоне хотя-бы раз за этот кадр была вызвана `common.HitFrameHandler()`.

В функцию передается 2 аргумента:
- elapsedMs - время прошедшее с прошлого кадра. 
- timeMs - общий глобальный таймер (абстрактный).

::: warning Для пользовательских аддонов имеются ограничения
Внутри FrameHandler нельзя слать эвенты, писать в лог, работать с конфигом.
:::

::: warning Для пользовательских аддонов 
При `requireHit == false` имеется ограничение: время исполнения хендлера не должно превышать `3мс`, если это правило будет нарушено `100` раз фича будет залочена для аддона до рестарта игры.
:::

`common.UnRegisterFrameHandler` - удалить зарегистрированный хендлер фрейма (наличие не проверяется, если такового не было не делает ничего).

`common.HitFrameHandler()` - выставить флаг потребности в вызове хендлера фрейма. Нельзя вызывать будучи внутри хендлера фрейма. Наличие хендлера не проверяется, при отсутствии флаг будет выставлен, но не возымеет никакого эффекта.
::::
