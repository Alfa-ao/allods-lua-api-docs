- [TextViewSafe:SetTextStyle](/api/category/widget/TextView/method.SetTextStyle.md)

```lua:line-numbers
wtTextView:SetTextStyle {
    align = 1,                       -- enum [0:2] <Align>ALIGNY_DEFAULT</Align>
    blendEffect = 2,                 -- enum [0:4] ?? (HELP)
    lineSpacing = 1.5,               -- float <lineSpacing>0</lineSpacing>
    wrapText = true,                 -- bool <wrapText>true</wrapText>
    showClippedSymbol = false,       -- bool <showClippedSymbol>false</showClippedSymbol>
    showClippedLine = true,          -- bool <showClippedLine>true</showClippedLine>
    multiline = true,                -- bool <multiline>false</multiline>
    ellipsis = false,                -- bool <ellipsis>true</ellipsis>
    allowSpacesInLineBegin = false   -- bool ?? (HELP)
}
```

### common.DelayedCall {#17.0.0-common.DelayedCall}

::: success VERSION: <Badge type="warning" text="17.0.01.41" /> <Badge type="success" text="Release" />
Новое API:

- [common.DelayedCall](/api/category/common/function.common.DelayedCall.md)
- [common.GetDelayedCalls](/api/category/common/function.common.GetDelayedCalls.md)
- [common.CancelDelayedCall](/api/category/common/function.common.CancelDelayedCall.md)

Возможность вызвать произвольную функцию с произвольным набором аргументов с некоторой задержкой. 
Фактическая задержка может быть больше заданной на время до двух кадров. Запланированный вызов можно отменить по id.
:::

```lua:line-numbers
-- Отменяет предыдущий таймер, если он уже был запланирован
if self._state.taskRefs.funcAlchemyItemPlaced ~= nil then
    common.CancelDelayedCall( self._state.taskRefs.funcAlchemyItemPlaced )
end

-- Запланировать новый отложенный вызов и сохранить его идентификатор
self._state.taskRefs.funcAlchemyItemPlaced = common.DelayedCall( 100, funcGetMessage )
```
