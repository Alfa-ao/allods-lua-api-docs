::: tip VERSION: <Badge type="warning" text="^18.0.0" /> <Badge type="tip" text="Pre-release" />

```lua
    GetChildChecked( "MainFrame" )
```

### UIAddon

::: tip VERSION: <Badge type="warning" text="^17.1.*" /> <Badge type="warning" text="^18.0.0" /> <Badge type="warning" text="Process" />

Если в процессе запуска аддона происходят ошибки, то аддон будет автоматически выгружен (с соответствующим уведомлением). Распространяется только на ошибки в процессе запуска, логика обработки ошибок в процессе работы не изменяется.

- Для предотвращения дедлоков когда сломанный аддон ломает запуск.

:::

::: tip VERSION: <Badge type="warning" text="17.0.01.46" /> <Badge type="success" text="Release" />

Новые методы для TextViewSafe и ButtonSafe:

- [`TextViewSafe:SetTextStyle`](/api/category/widget/TextView/method.SetTextStyle.md)
- [`TextViewSafe:GetTextStyle`](/api/category/widget/TextView/method.GetTextStyle.md)
- [`ButtonSafe:SetTextStyle`](/api/category/widget/Button/method.SetTextStyle.md)
- [`ButtonSafe:GetTextStyle`](/api/category/widget/Button/method.GetTextStyle.md)

Задать стиль текста в виджете. Работа аналогична полю TextStyle в ресурсе.

Геттер отдает а сеттер принимает таблицу. В сеттере можно указать не все поля таблицы, неуказанные поля сохранят свое текущее значение (аналогично Placement).

:::

```lua
-- Список полей:

wtTextView:SetTextStyle {
    align = 1,                       -- enum [0:2] <Align>ALIGNY_DEFAULT</Align>
    blendEffect = 2,                 -- enum [0:4] ??
    lineSpacing = 1.5,               -- float <lineSpacing>0</lineSpacing>
    wrapText = true,                 -- bool <wrapText>true</wrapText>
    showClippedSymbol = false,       -- bool <showClippedSymbol>false</showClippedSymbol>
    showClippedLine = true,          -- bool <showClippedLine>true</showClippedLine>
    multiline = true,                -- bool <multiline>false</multiline>
    ellipsis = false,                -- bool <ellipsis>true</ellipsis>
    allowSpacesInLineBegin = false   -- bool ??
}
```
